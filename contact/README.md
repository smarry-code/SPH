## Как передать в следующий запуск

1. Ответить на вопросы в [02-decisions.md](02-decisions.md) — или ничего не делать,
   тогда применяются рекомендованные варианты (`D1=A, D2=A, D3=A, D4=A, D5=A, D6=A`).
2. Стартовый промпт:

   > Внедри контактные силы по плану `contact/01-plan.md`. Решения: D1=A, D2=A, D3=A,
   > D4=A, D5=A, D6=A. Выполняй шаги по порядку, каждый шаг — отдельный коммит,
   > после каждого шага прогоняй проверку из его раздела. Шаг 6 не выполняй.

## Ключевое, что нужно знать до старта

- `Report_SPH_contact.md` **не описывает этот репозиторий**: модели Wang, ADR-011,
  `test_contact.cpp`, ограничителя шага и контактной конфигурации здесь нет.
  Опираться на него как на описание базы нельзя — только `01-plan.md`.
- Проект **не собирается на macOS** до шага 0 (три блокера: `param.hpp:12`,
  `main.cpp:13`, флаги OpenMP для Apple Clang). Исправления проверены — после них
  сборка проходит полностью.
- Внедряются три силы из статьи (типы 1–3). Тип 0 означает «контакт выключен» и
  остаётся значением по умолчанию: поведение существующих кейсов не меняется.
