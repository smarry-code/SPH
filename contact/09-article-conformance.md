# Запрос: сверка реализации со статьёй (кейс BC2)

Документ предназначен для передачи инстансу Claude, у которого есть доступ
к статье, послужившей источником эталонного профиля скорости для кейса BC2
(удар по карбиду бора).

Ниже описано, что **фактически** делает наша реализация, с конкретными числами.
Задача адресата — сверить каждый пункт со статьёй и указать расхождения.

Поводом послужило расхождение расчёта с эталоном, разобранное в
[08-phase-shift.md](08-phase-shift.md): волна приходит к монитору на ~1,09 мкс
раньше, пик 1002 м/с против 1317,5 м/с. Численный разбор объяснил амплитуду
(недостаточное разрешение) и лишь 0,18 мкс из 1,09 мкс фазового сдвига.
Остальное должно найтись в постановке.

## 3. Материалы и уравнения состояния

**3.1. B4C** — у нас полиномиальное УРС модели JH-2:

```
p = K1·μ + K2·μ² + K3·μ³        (μ = ρ/ρ₀ − 1 ≥ 0)
p = K1·μ                        (μ < 0, с отсечкой по прочности на разрыв T)
```

со значениями `K1 = 233` ГПа, `K2 = −593` ГПа, `K3 = 2800` ГПа,
`T = 0,26` ГПа, `ρ₀ = 2510` кг/м³, `G = 197` ГПа.

Отсюда объёмная скорость звука `sqrt(K1/ρ₀) = 9635` м/с и продольная
`sqrt((K1 + 4G/3)/ρ₀) = 14 053` м/с.

Сверь все шесть констант и обе скорости звука со статьёй.

**3.2. LiF** — у нас УРС вида

```
p = A·((ρ/ρ₀)^Z − 1)
```

с `A = 1,6659·10¹⁰` Па, `Z = 4,272`, `ρ₀ = 2638` кг/м³, `G = 5,5·10¹⁰` Па,
что даёт скорость звука 5194 м/с.

Какое УРС для LiF использует статья — такое же степенное, Ми–Грюнайзена,
ударную адиабату `U_s = c₀ + s·u_p`? Приведи коэффициенты. Если ударная
адиабата — приведи `c₀` и `s`.

**3.3. Полиуретан 626** — то же степенное УРС, `A = 3,0227·10⁸` Па,
`Z = 3,5`, `ρ₀ = 626` кг/м³, `G = 4·10⁸` Па, скорость звука 1300 м/с.
Сверь.

**3.4.** Использует ли статья вообще тот же тип УРС, или это подгонка под
другую форму? Если формы разные, приведи форму из статьи целиком.

## 5. Численная схема

Если статья приводит собственный расчёт — сверь; если только эксперимент,
отвечай `НЕТ В СТАТЬЕ` и переходи к §6.

**5.1.** Метод: SPH. Ядро — кубический сплайн, носитель `2h`.

**5.2.** Длина сглаживания: `h = 1,3·(m/ρ)^(1/dim)`, пересчитывается каждый
шаг. При `Δx = 0,2` мм это `h = 0,26` мм, носитель 0,52 мм.

**5.3.** Разрешение: `Δx = 0,2` мм, то есть **46 частиц поперёк
9-миллиметровой мишени**, 34 163 частицы всего. Какое разрешение использует
статья?

**5.4.** Плотность — из уравнения неразрывности (не суммированием).

**5.5.** Искусственная вязкость Монагана, `α = 1,0`, `β = 1,0`, `η² = 0,01`.

**5.6.** XSPH-усреднение скоростей с `ε = 0,25`.

**5.7.** Шаг по времени из условия Куранта, `CFL = 0,1`.

**5.8.** Приводит ли статья результаты сеточной сходимости — как меняется
профиль при измельчении? Это прямо относится к нашей проблеме: мы подозреваем,
что при `Δx = 0,2` мм фронт размазывается сильнее, чем длится импульс.

## 10. Контекст: что уже измерено с нашей стороны

Чтобы адресат понимал, что уже исключено, и не тратил силы на это.

* **Удар смоделирован верно.** Скорость частиц сразу за фронтом — 1112,8 м/с

  отсюда, по нашей версии, заниженная амплитуда.
