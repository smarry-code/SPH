# Дизайн: упруго-пластичность, скоростная зависимость и вязкоупругое демпфирование нити

Статус: реализовано на ветке `plastic` (этапы 1-5, раздел 10; не закоммичено, PR нет). Ссылки `файл:строка` в разделах 0-1 относятся к исходной ветке `fiber_new` (до реализации). Литература — [elastoplastic-fibers-papers.md](elastoplastic-fibers-papers.md); многие DOI и детали формул там не проверены, поэтому здесь они используются только как ориентир по постановке, а не как источник уравнений. Все уравнения ниже выведены заново и проверяются тестами из раздела 8.

## 0. Главное

**Принятое ограничение (по указанию заказчика):** сопротивление нити изгибу в расчёте не предусмотрено и в рамках этого дизайна не вводится. Нить — только одноосная связь на растяжение; приложение А (изгиб) справочное и не входит в план. Код по условию не меняется.

1. **Исходное состояние отличается от «нити по Meyer».** В коде нет изгиба (eq. 17 Meyer не реализована) и нет углового разрыва. `Fiber-Bond` — это одноосная пружина «только на растяжение»: `F = E·A·max(l/l0 − 1, 0)` (`include/interactions/fiber_bond.hpp:77-101`), разрыв по длине `l > l_break = (1+ε_break)·l0` в Postprocessing (`include/interactions/postprocessing.hpp:162-190`), см. ADR-008, решения Р6 и Р7. Поэтому дизайн строится на одноосной связи; изгиб вынесен в приложение А.
2. **Все три эффекта ложатся в одну одноосную реологическую схему на связь** (раздел 1): пружина в серии с пластическим элементом, параллельно ей ветвь Максвелла и демпфер Кельвина. Из неё разом получаются упруго-пластика, зависимость от скорости деформации (через предел текучести и вязкие ветви) и вязкоупругость.
3. **Внутренние переменные хранятся в связи, обновляются в Postprocessing, а не в RHS.** Это ровно то, как уже устроены `apply_material_strength` (возврат по Мизесу после шага решателя) и разрыв связей. Решает проблему «`dt` считается после RHS» (раздел 4).
4. **Обратная совместимость побитовая:** без новых директив в `.fib` все новые поля нулевые, ветки отключены, результат прежний.
5. **Главный риск:** шаг по времени при жёстком демпфере и локализация деформации в одной связи (зависимость от числа бусин). Оба разобраны в разделах 5 и 9, у каждого есть тест.

## 1. Постановка (одноосная связь)

Обозначения: связь `(i,j)`, `x_ij = x_j − x_i`, `l = |x_ij|`, `n = x_ij/l`, `ε = l/l0 − 1` (как в коде сейчас), `ε̇ = ((v_j − v_i)·n)/l0`, `A = πd²/4`. Сила на бусину `i` от `j`: `F = A·σ·n`, на `j` — `−F`.

Реология:

```
σ = σ_ep + σ_M + σ_η

σ_ep = E (ε − ε_p)                  пружина E в серии с пластическим элементом
σ_M  = q,  q̇ = E1 ε̇ − q/τ          ветвь Максвелла (пружина E1 + демпфер η1 = E1·τ)
σ_η  = η_v ε̇                       демпфер Кельвина параллельно всему
```

Затем «только растяжение» (как сейчас): связь провисла, если `σ_ep ≤ 0`, то есть `ε ≤ ε_p`. Сила

```
F = A · max(σ, 0)   если ε > ε_p,   иначе F = 0
```

Из второй строки следуют два важных эффекта: (а) после пластического удлинения нить «помнит» его — её натянутая длина `l_p = l0(1+ε_p)`, и нить не толкается при `l < l_p`; (б) демпфер не может создать тянущую силу при быстрой разгрузке (клип `max(·,0)`), он только гасит.

Что получается при выключении слагаемых: `ε_p ≡ 0`, `E1 = 0`, `η_v = 0` — ровно текущий закон.

### 1.1 Пластический элемент

Растяжение монотонно и сжатие не передаётся (связь провисает), поэтому пластическая деформация одна и не убывает: `ε_p ≥ 0`, накопленная пластическая деформация `ε̄_p = ε_p`. Отдельная переменная для накопленной деформации не нужна (при добавлении сжатия или кинематического упрочнения нужна, см. 1.4).

Функция текучести (только растяжение):

```
f = σ_ep − σ_y(ε_p, ε̇_p)
ε̇_p ≥ 0,  f ≤ 0,  ε̇_p·f = 0      (условия Куна-Таккера)
σ_y = σ_s(ε_p) · R(ε̇_p)
```

Статическое упрочнение `σ_s(ε_p)` — на выбор:

| Тип | Формула | Параметры |
|---|---|---|
| линейное (по умолчанию) | `σ_s = σ_y0 + H·ε_p` | σ_y0, H |
| степенное | `σ_s = σ_y0 + K·ε_p^n` | σ_y0, K, n |
| таблица | кусочно-линейная по `(ε_p, σ_s)`, как у Ding и др. (п. 8 подборки) | N точек |
| идеальная пластичность | H = 0 | — |

Скоростной множитель `R(ε̇_p)` (каждый вариант с `R = 1` при `ε̇_p → 0`, монотонно растёт):

| Модель | Формула | Параметры |
|---|---|---|
| Cowper-Symonds | `R = 1 + (ε̇_p/C)^{1/p}` | C [1/с], p |
| Johnson-Cook | `R = 1 + c_jc·ln(max(ε̇_p/ε̇_0, 1))` | c_jc, ε̇_0 |
| Perzyna (сверхнапряжение) | `σ_y = σ_s + η_p·ε̇_p^m`, то есть `R` аддитивный | η_p, m |

Для высокоскоростного удара (баллистика) стандартна Cowper-Symonds или Johnson-Cook; Perzyna удобна для ползучести и релаксации. Выбор: `RATE` в `.fib` (раздел 6). Значения параметров для конкретных волокон из подборки не берутся: в проверенных источниках (п. 7 и 8) их нет в нужной форме, их надо подгонять по экспериментам на растяжение при разных скоростях.

### 1.2 Возврат на поверхность текучести (в конце шага)

Дано: `ε^{n+1} = l^{n+1}/l0 − 1`, `ε_p^n`, `dt`. Пробное напряжение `σ_tr = E (ε^{n+1} − ε_p^n)`.

1. Если `σ_tr ≤ σ_s(ε_p^n)` (то есть при `ε̇_p = 0`) — упруго: `ε_p^{n+1} = ε_p^n`.
2. Иначе найти приращение `Δ ≥ 0` из скалярного уравнения
   ```
   g(Δ) = σ_tr − E·Δ − σ_s(ε_p^n + Δ)·R(Δ/dt) = 0
   ```
   `g` строго убывает по `Δ`, так как `E>0`, а `σ_s` и `R` не убывают; корень единственный. Для линейного упрочнения без скоростной зависимости: `Δ = (σ_tr − σ_y0 − H·ε_p^n)/(E+H)`. Для остальных — Ньютон с защитой (метод деления отрезка, если шаг выходит за скобку `[0, σ_tr/E]`), 3–6 итераций.
3. `ε_p^{n+1} = ε_p^n + Δ`; рассеянная пластическая работа на связь `ΔW_p = A·l0·∫σ_ep dε_p`; в реализации -- трапеция `ΔW_p = A·l0·(σ_start + σ_end)/2·Δ` (`σ_start` -- напряжение на начало пластического течения в шаге, `σ_end = σ_y^{n+1}`; для линейного упрочнения без RATE точна), в `BondState::w_p` хранится на единицу объёма, `w_p += (σ_start + σ_end)/2·Δ` (`fiber_plasticity.hpp`). Диагностика, на динамику не влияет.

Скоростная зависимость входит через `Δ/dt` — скорость **пластической**, а не полной деформации. Она заметно глаже полной скорости (раздел 9, риск 3).

### 1.3 Вязкоупругость

**Ветвь Максвелла** хранит напряжение `q` и обновляется в конце шага точно (при линейном ходе деформации на шаге):

```
q^{n+1} = e^{−dt/τ}·q^n + E1·Δε·(τ/dt)(1 − e^{−dt/τ}),     Δε = ε^{n+1} − ε^n
```

Безусловно устойчиво и точно для релаксации (тест Т7). При `dt ≪ τ` переходит в явный Эйлер. Несколько ветвей (ряд Прони) — массив `(E1_k, τ_k)`, на первую версию достаточно одной; поле `q` тогда становится массивом.

**Уточнение (провисшая связь, реализовано на этапе 1).** Связь работает только на растяжение, поэтому при `ε ≤ ε_p` все элементы разгружены. В формулах выше вместо `Δε` берётся приращение деформации «натянутой части» `Δε_eff = max(ε^{n+1}, ε_p^{n+1}) − max(ε^n, ε_p^n)`: при провисании в начале и конце шага `Δε_eff = 0` (q только релаксирует экспонентой, диссипация Кельвина не копится), переход через границу провисания непрерывен. Диссипация Кельвина: `η_v·Δε_eff²/dt`.

**Демпфер Кельвина** `σ_η = η_v·ε̇` — единственный член, зависящий от скорости в RHS. Задаётся либо в Па·с (`η_v`), либо безразмерно через долю критического демпфирования связи:

```
c = η_v·A/l0 = 2ξ·sqrt(k·m_red),    k = E_inst·A/l0,    m_red = m_i m_j/(m_i+m_j)
```

Вторая форма удобна, потому что `ξ` не зависит от дискретизации (число бусин, массы), а `η_v` зависит: при удвоении числа бусин `m_red` падает вдвое, `k` растёт вдвое, `c` растёт как `√(k·m_red)` — константа. Для физических расчётов выбирать `η_v`; `ξ` — для численного демпфирования колебаний бусин (аналог искусственной вязкости).

### 1.4 Что осознанно не входит в первую версию

- Пластика при сжатии и эффект Баушингера — связь на сжатие не работает, это не нужно. Если появится изгиб или контакт-сжатие, придётся вводить кинематическое упрочнение и знаковую `ε_p` (приложение А).
- Повреждение, размягчение (см. раздел 9, риск 2: без регуляризации размягчение локализуется в одной связи).
- Нагрев от пластической работы (адиабатическое размягчение). Энергии нити как отдельной подсистемы в расчёте нет: накопленные `w_p`, `w_v` (Дж/м^3) -- только диагностические поля состояния связи, на динамику не влияют; в баланс монитора Guo они пока не включены (раздел 9, п. 7).
- Ползучесть и релаксация при больших временах — Perzyna и Максвелл покрывают, но параметры отдельно.
- Большие деформации. Для `ε < 0.1` инженерная деформация и аддитивное разложение достаточны, и совпадают с текущей `ε = l/l0 − 1`. Нейлон и подобные тянутся на 20–40%, тогда нужна логарифмическая деформация `ε_H = ln(l/l0)` и напряжение Коши `σ = F/A_cur` (с условием несжимаемости `A_cur = A·l0/l`). Формулы возврата не меняются, меняется только подстановка `ε → ε_H` и перевод напряжения в силу. Переключатель `STRAIN=eng|log` в `.fib` — задел на вторую версию.

## 2. Переменные состояния связи

Добавить в `fiber::FiberBond` (`include/fiber/fiber_system.hpp:93-98`) **в конце** (агрегатная инициализация `FiberBond{i, j, l0, l_break}` продолжает компилироваться, по тому же приёму, что и поля `mu_ff`, `mu_fs` у материала):

| Поле | Смысл | Когда меняется |
|---|---|---|
| `eps_p` | пластическая деформация (`= ε̄_p`) | Postprocessing |
| `q` | напряжение ветви Максвелла | Postprocessing |
| `eps_prev` | `ε` предыдущего шага (для `Δε`) | Postprocessing |
| `w_p`, `w_v` | накопленная рассеянная пластическая и вязкая энергия, Дж | Postprocessing (диагностика) |

Реализовано (этап 2) как поле `FiberBond::st` типа `fiber::BondState` (энергии `w_p`, `w_v` — Дж/м³, энергия связи = `w·A·l0`). Состояние держим **внутри `FiberBond`**, а не в отдельном массиве, потому что `apply_fiber_break_events` пересобирает `topology.bonds` фильтром (`postprocessing.hpp:286-296`) — при разрыве состояние оставшихся связей переедет вместе с ними без дополнительной синхронизации. Ничего не переиндексируется. Стоимость: 5 лишних `double` на связь (40 байт). Для сцены Guo 2019 — порядка десятков тысяч связей, пренебрежимо.

## 3. Силовое ядро (RHS)

`compute_fiber_bond_contributions` остаётся только читающим ядром (требование «kernel только читает», шапка `fiber_bond.hpp:12-17`): состояние связи читается (`eps_p`, `q`), не пишется. Меняется только вычисление `coeff`:

```
ε   = l/l0 − 1
если ε > ε_p:
    σ = E (ε − ε_p) + q + η_v · ((v_j − v_i)·n)/l0
    σ = max(σ, 0)
    coeff = A · σ / l
иначе coeff = 0
```

Тем самым при `ε_p = q = η_v = 0` формула совпадает с текущей `E·A·ε/l` и условием `l > l0`. Сила действует вдоль связи, третий закон Ньютона сохраняется (оба `dv` — одна `F`, противоположные знаки) — сохранение импульса не нарушается ни пластикой, ни демпфером. Скорости `v` читаются из `FiberState::vx` в момент вызова RHS (это предсказанные скорости решателя, см. раздел 5).

## 4. Postprocessing: обновление внутренних переменных

Новый проход `apply_fiber_bond_constitutive(exec, state, topology, materials, dt)` ставится в `run_time_integration` после `advance` и **перед** поиском разрыва, рядом с `apply_material_strength` (`src/time_integration.cpp`, блок Postprocessing). Порядок такой:

1. `advance` даёт `x^{n+1}`, `v^{n+1}`.
2. Для каждой связи (параллельно, каждая связь пишет только в себя — гонок нет): `ε^{n+1}` → возврат (1.2) → обновить `ε_p`, `q` (1.3), `eps_prev`, энергии.
3. Поиск и применение разрывов — по критериям раздела 7.

Почему так, а не в RHS: `dt` вычисляется **после** RHS (`time_integration.cpp`, «Общий шаг … min(CFL, контакт, dt_limit)»), а возврат и экспонента Максвелла требуют `dt`. Переносить обновление в RHS означало бы брать `dt_prev`, что вносит рассогласование и усложняет схему. В Postprocessing `dt` точно известен, позиции `x^{n+1}` уже финальные, а следующий RHS вычисляется в тех же `x^{n+1}` (предиктор `pc_predict_velocity_half_step` двигает только скорость), поэтому `σ_ep = E(ε − ε_p^{n+1})` совпадает с результатом возврата. Это тот же принцип, что у Solid-напряжений (Мизес после шага).

**Первый шаг (этап 2, исправлено).** Нулевое `eps_prev` годится только для связи в ненагруженной конфигурации (`l = l0`). Связь, созданная при `l ≠ l0` (предварительное натяжение, сцена со сдвигом бусин, тесты), дала бы на первом шаге фиктивное приращение `Δε = ε − 0`, а с ним скачок `q`, огромную `w_v` и вязкую силу. Поэтому в начале `run_time_integration` (до цикла) вызывается `interactions::init_fiber_bond_state(fb, topology, materials)`: для связей неупругих материалов `eps_prev = l/l0 − 1` по начальной конфигурации; `eps_p`, `q`, `w_p`, `w_v` остаются нулевыми (мгновенная упругая нагрузка), упругие связи не трогаются. Драйверы с ручным шагом (тесты) вызывают её сами перед первым шагом. Повторный вызов безвреден, если `x` не менялись после последнего шага. Тест: `test_init_eps_prev` и вторая сцена `test_full_loop` в `tests/test_fiber_plasticity_integration.cpp`.

**Где вызывается проход.** `apply_fiber_bond_constitutive` встроен в `interactions::run_fiber_topology_postprocessing(exec, state, topology, materials, dt, buffers)` (сначала внутренние переменные, потом поиск и применение разрыва), поэтому любой драйвер, вызывающий обёртку (боевой цикл, `tests/fiber_t0_dump.cpp`), обновляет состояние автоматически. Драйверы, которые вызывают `find_fiber_break_events`/`apply_fiber_break_events` напрямую (`tests/test_fiber_break.cpp`), конститутивный проход пропускают: им нужен явный вызов (для упругих материалов он и так no-op). Боевой цикл покрыт тестом `test_full_loop`.

**Идемпотентность.** Если шаг повторяют или откатывают (в коде этого нет), состояние нужно хранить дважды. Сейчас не актуально.

## 5. Шаг по времени и устойчивость

Текущий лимит (`fiber_bond.hpp:152-175`): `dt = 0.8/ω`, `ω = sqrt(k/m_red)`, `k = E·A/l0`. Изменения:

1. **Жёсткость.** Для ветви Максвелла мгновенная жёсткость `E_inst = E + E1` (в начале нагрузки ветвь не успела расслабиться). Лимит считать по `E_inst`. Пластичность лимит **не ужесточает** (касательный модуль `E_t ≤ E`, а возврат неявный), поэтому `E` остаётся консервативной оценкой.
2. **Демпфер Кельвина — явный и ужесточает шаг.** Схема проекта — не центральные разности, а предиктор-корректор: демпфер в RHS берёт скорость предиктора `v + h/2·a_prev` (запаздывающую), поэтому критерий Белычко для центральных разностей здесь не работает. Для линейной пары (`h = ω·dt`, `a = −ω²s − 2ξω·v_pred`, `v' = v + h·a`, `s' = s + h·v'`) спектральный радиус матрицы шага 3×3 выходит на 1 через −1, и критический шаг в замкнутой форме равен
   ```
   h_кр(ξ) = 2·(sqrt(1+4ξ²) − 2ξ) = 2/(sqrt(1+4ξ²) + 2ξ)
   ```
   то есть формула Белычко с удвоенным ξ. Числа: 2.00 (ξ=0), 1.64 (0.1), 1.355 (0.2), 1.133 (0.3), 0.829 (0.5), 0.472 (1), 0.246 (2), 0.0998 (5), асимптотически `h_кр·ξ → 1/2`. Сверено прямым расчётом спектрального радиуса.

   **Цепочка, а не пара (исправление после ревью этапа 2).** Лимит считается по каждой связи как по паре, но связи сидят в цепочке: бусина в двух связях, старшая мода чередующаяся, `ω_цепи = √2·ω_пары`, а так как `c ∝ k`, то и `ξ_цепи = √2·ξ_пары`. Первая версия (`dt = 0.8/ω·(sqrt(1+ξ²)−ξ)`, по паре) при `ξ ≳ 1.2` давала неустойчивую цепочку даже при `0.9·dt_lim` (рост 4e6…8e6; ревьюер, 12 бусин, концы `m/2`). Принято
   ```
   dt_bond = min( 0.8/ω_inst ,  0.8 · h_кр(√2·ξ) / (√2·ω_inst) ),     ξ = c / (2·sqrt(k_inst·m_red))
   ```
   Множитель 0.8 — тот же запас, что в упругом лимите; `min` с упругим `0.8/ω_inst` гарантирует, что демпфер лимит никогда не ослабляет (при малых ξ значение прежнее). При больших ξ `dt_bond → 0.2/(ξ·ω) = 0.4·m_red/c` — порядок `m_red/c`, как у явного демпфера.

   **Проверка (Т9, цепочка из 12 бусин, ξ = 0.5, 1, 1.2, 2, 5; рост возмущения = max|s−s_eq|/δ0).** Цепочка с половинными концевыми массами (старшая мода строго чередующаяся; лимит задаёт концевая связь с `m_red = m/3`, поэтому запас лишний в `sqrt(3/2)`): 0.9·dt_bond — рост 1, 2.0·dt_bond — 1.5e7…4e7. Цепочка с одинаковыми массами: 0.9 и 1.25·dt_bond — рост 1 (1.25 = 1/0.8 — предел формулы), 1.5·dt_bond — 1e7…3e7, то есть лимит почти точен, а не чрезмерно консервативен. Пара: 0.9·dt_bond — 1, 3.0·dt_bond — 1e7…5e7 (на паре запас 2.5 — цена учёта цепочки). Прежние числа «1.5·dt_bond неустойчиво при ξ ≥ 2» (пара, первая версия формулы) более не относятся к принятому лимиту.
3. **Если нужен сильный демпфер (`ξ ≳ 1`) и лимит становится слишком жёстким:** перенести демпфер на уровень скоростей, как сделано для трения (`fiber_friction_projection.md`, единая стадия после вычисления `dt`, использует `fiber_velocity_update` решателя). Для пары: относительная осевая скорость после упругого шага `u_tr`, затем `u⁺ = u_tr/(1 + h·c/m_red)`, где `h` — коэффициент обновления скорости решателя. Безусловно устойчиво. Бусина в середине нити участвует в двух связях, поэтому применяется mass splitting (счётчик `c_k = 2`), как в `compute_friction_counts`. Это отдельный этап, в первую версию не включать.
4. **Ветвь Максвелла и пластика** сами по себе устойчивости шага не ограничивают.
5. **Эйлер** (`EulerSolver`) остаётся неустойчивым на упругих связях (ADR-008), демпфер Кельвина его не лечит при `ξ<1`; тесты порядка сходимости остаются на упругом случае.

## 7. Разрыв связи

Сейчас разрыв по полной деформации `l > l_break` (`postprocessing.hpp:183`). С пластикой остаются:

1. **Старый критерий** (по умолчанию): `ε > eps_break` — так что включённый `PLASTIC` с «большим» `eps_break` даёт пластическое течение до разрыва.
2. **По накопленной пластической деформации:** `ε_p ≥ FAILURE.EPS_P`.
3. **По напряжению:** полное напряжение `σ_full = E(ε − ε_p) + q ≥ FAILURE.SIGMA_U` (хрупкий предел при слабой пластике; `q` -- напряжение ветви Максвелла, ненулевое только при `VISCO E1>0`; член Кельвина `η·ε̇` НЕ входит -- он численное демпфирование). Без Максвелла `q = 0` и критерий совпадает с прежним `σ_ep ≥ SIGMA_U` побитово. Следствие: больше `E1` -- выше напряжение на фронте и раньше разрыв.
4. Любой из включённых критериев ведёт к разрыву; пустые параметры выключены. Скоростная зависимость предельной деформации — по Johnson-Cook `ε_f = ε_f0·(1 + c_f·ln ε̇*)`, не в первой версии.

Критерий проверяется после возврата в том же проходе Postprocessing (раздел 4), так что лишних вызовов нет, а разрыв срабатывает по конечному состоянию шага.

**Реализация (этап 4, выполнено).** `interactions::find_fiber_break_events(exec, state, topology, materials, buffers)` (перегрузка с материалами; прежняя без материалов оставлена и видит только `l > l_break`) проверяет в одном параллельном чтении: `l > l_break` (причина `Strain`), `st.eps_p >= EPS_P` (`PlasticStrain`), `E·(ε − st.eps_p) + st.q >= SIGMA_U` (`Stress`, полное напряжение без Кельвина); порядок проверки фиксирован, первое сработавшее задаёт причину в новом поле `FiberBreakEvent::reason` (диагностика, на применение не влияет). `run_fiber_topology_postprocessing` вызывает новую перегрузку после `apply_fiber_bond_constitutive`, то есть по конечному состоянию шага. Отклонения и решения:

* **`inelastic()` и `has_failure()`.** `FiberMaterial::inelastic()` не менялась (пластика/Максвелл/Кельвин) и по-прежнему управляет быстрой упругой веткой RHS, dt-лимитом и проходом состояния. Добавлена `has_failure()` (`EPS_P > 0` или `SIGMA_U > 0`), которая используется только в поиске разрыва. Материал с одним `FAILURE` остаётся упругим для ядра (побитово прежние силы), его `st` нулевой, поэтому `σ_full = E·ε`, а `EPS_P` без пластики не срабатывает.
* Равенство порогу (`>=`) рвёт связь; `l > l_break` остаётся строгим, как раньше.
* Для упругих материалов без `FAILURE` проверка `any_failure` ложна, дополнительных операций на связь нет; результат побитово прежний (`fiber_t0_dump`).
* `topology.version` по-прежнему растёт один раз на проход; состояние уцелевших связей переезжает вместе с `FiberBond` при пересборке `bonds`.
* Тест Т14: `tests/test_fiber_plasticity_integration.cpp::test_t14_failure_criteria` (EPS_P, SIGMA_U с пластикой и без, `eps_break` при пластике; предсказание проверяется на каждом шаге, версия топологии, побитовое сохранение `eps_p/q/eps_prev/w_p/w_v` у соседей, причина разрыва).
* `RATE PERZYNA`: `ETA > 0` (ETA = 0 вырождает модель в статическую и запрещён; чтобы не использовать скоростную зависимость, не задают `RATE`).

(2) Нет артефактов дискретизации: при одинаковых связях `ε_p` одинакова по всем связям (допуск ±1 %, фактически лучше 1e-4); само по себе это тривиально (все связи одинаковы), поэтому добавлена содержательная проверка. С Cowper-Symonds множитель `R` у связей различается, аналитика приближённая: наблюдается 0.87 от неё (допуск 35 %); локализации тоже нет. Без размягчения пластическая деформация не локализуется и от числа бусин не зависит; средние `ε_p` 10 и 40 бусин отличаются на 0.02-0.04 % (разные `dt`).

## 9. Риски и открытые вопросы

1. **Шаг по времени при жёстком демпфере** (раздел 5): явный Кельвин ограничивает `dt` как `m_red/c`; запасной путь — стадия на уровне скоростей по образцу трения.
2. **Локализация деформации.** *Проверено на этапе 5 (Т13): при однородных связях `ε_p` одинакова по связям при 10 и 40 бусинах; кривая `σ-ε` не зависит от дискретизации (0.34 % во всём диапазоне, 0.03-0.1 % в пластической части); дефект `σ_y` одной связи на 1 % при `H > 0` не локализует `ε_p` (разность `0.01·σ_y/H`, как в аналитике, отклонение 2e-8 без RATE). Риск остаётся для размягчения/`FAILURE` по энергии, которых в первой версии нет; регуляризацию не проверяли.* Если после пика напряжение падает (размягчение, `FAILURE` по энергии), вся деформация сосредоточится в одной связи, и поглощённая энергия будет зависеть от числа бусин. Как защита: без размягчения в первой версии; при необходимости — энергия разрушения на единицу длины `G_f`, а критическая пластическая деформация `ε_p,f = G_f/(σ_u·l0)` (регуляризация типа Хиллерборга). Тест Т13.
3. **Шум скорости деформации.** *Наблюдение этапа 5 (Т12 с RATE CS, ударная волна на цепочке 800 бусин): шума нет, `ε_p` гладка (шероховатость связь-к-связи 2e-6), потому что `R` считается по пластической скорости `Δ/dt`; фильтр `ε̇_f` для Кельвина не проверялся (в Т12 `η_v = 0`). Остаётся открытым: сильный Кельвин в волне.* В ударной волне на цепочке бусин `ε̇` на связи осциллирует (дисперсия). Скоростные формулы с полной `ε̇` усиливают шум. Поэтому `R` считается по пластической скорости `Δ/dt` (глаже), а для `η_v` можно добавить экспоненциальный фильтр `ε̇_f`. Выбор — по результатам Т12.
4. **Лаг предиктора и баланс энергии (Т10, этап 2).** RHS при вычислении демпфера использует скорости предиктора (полушаговые), а внутренние переменные — позиции конца прошлого шага. Невязка баланса `E_кин + E_упр + W_p + W_v` против работы внешних сил разобрана на отдельных прогонах (только пластика, только Максвелл, только Кельвин, всё вместе; цикл нагрузка–разгрузка на 5 бусинах, шаги 0.4…0.05 от лимита) и состоит из двух частей, обе — свойства схемы/модели, не ошибка учёта энергии:
   * **O(dt).** Сила берётся по `x^n`, Кельвин по скорости предиктора, энергии связи считаются по `x^{n+1}` (трапеция). Невязка убывает пропорционально `dt` (вдвое меньше шаг — вдвое меньше невязка; у пластики и Кельвина это вся невязка: 0.46% → 0.23% → 0.12% → 0.06% пика внешней работы у пластики для 0.4, 0.2, 0.1, 0.05).
   * **Не зависит от dt: односторонность связи.** Сила вдоль связи не бывает отрицательной, `σ = max(σ_модели, 0)`. При быстрой разгрузке ветвь Максвелла (`q < 0`) и Кельвин (`η·ε̇ < 0`) делают `σ_модели < 0` при `ε > ε_p`: внутренние ветви отдают энергию, а бусинам сила не передаётся — энергия «теряется» на отсечке. Это и есть остаток ~0.2–0.7% у Максвелла и «всё вместе», не убывающий при уменьшении шага. Драйвер теста считает потерю отдельно (`Σ σ_модели·Δε·V` по шагам с отсечкой, ~2.1e-4 Дж у Максвелла из 7.2e-3 Дж работы): за вычетом неё невязка снова убывает пропорционально `dt` (Максвелл 0.68% → 0.34% → 0.16% → 0.08%). Физически это следствие модели «только растяжение» (дизайн, раздел 1.3); если понадобится строгий баланс, нужна либо диссипация на отсечке в `w_v`, либо модель без отсечки при `ε > ε_p`. В первой версии оставлено как есть и задокументировано; `W_p, W_v ≥ 0` и монотонность выполняются.
   * **Лог энергии на сцене Guo (SPH_ENERGY_LOG), разбор невязки «вязкая нить + разрывы» (тест E5, `tests/test_energy_log.cpp`).** Невязка 1T smoke, Максвелл (E1 = 0.2 E, τ = 2 мкс) + Кельвин (η = 2e3 Па·с) + пластика, eps_break = 0.005 (8 порванных связей), была max|residual| = 0.077 % E0 при W_p + W_v = 0.12 % E0 (без разрывов ≤ 0.035 % E0). Разложение по гипотезам:
     * **(а) Максвелл при разрыве — учёт верен.** D_break = ½E(ε−ε_p)²·A·l0 + ½q²/E1·A·l0 по состоянию ПОСЛЕ конститутивного прохода шага разрыва; приращения w_p, w_v этого шага берутся в канал до удаления связи (двойного счёта нет, пропуска нет). Прогон с Максвеллом без Кельвина, Кельвином без Максвелла и пластикой без вязкости с теми же разрывами даёт ту же невязку (−0.073 %, −0.072 %, −0.18 % E0 до исправления) — причина не в вязкости. Упругая нить с разрывами eps_break = 0.003 тоже давала −0.074 % E0.
     * **Причина — потенциал Герца порвавшегося сегмента (канал, которого не было).** Сегмент (связь) — примитив контактного поиска Fiber-Fiber/Fiber-Solid; при удалении связи его контакты исчезают, а `object_id` j-стороны меняется и перестраивает фильтр соседей. Потенциал `U_hertz` (2/5·F·δ) скачет без работы: на шагах разрыва скачок −1.5·10⁻³ Дж, −1.3·10⁻³ Дж при накопленном D_break 1.7·10⁻⁵ Дж на связь (разрывы в зоне сильного контакта). Изолированные разрывы вне контакта (шаги 288, 330) дают скачок невязки ≈ 0 (−2·10⁻⁶, +6·10⁻⁶ Дж). Исправление: новый столбец `D_break_contact` = Σ (U_Герца до − U_Герца после) удаления (контактный поиск считается дважды на шагах с разрывами, `FiberEnergyTap::contact_potential`); на E5 он равен 0.057 % E0 против D_break 0.014 % E0, невязка падает до max 0.0205 % E0 (final −0.0200 %). Для упругой нити (eps_break = 0.003): −0.074 % → +0.013 % E0.
     * **(б) Отсечка σ ≥ 0 — реальна, но мала.** Столбец `clip_loss` = Σ σ_модели·Δε·A·l0 по связям с ε > ε_p и σ_модели < 0 (RHS-ядро возвращает σ_модели в side-массив, проход Postprocessing умножает на Δε): E5 1.0·10⁻⁵ E0 (1 % W_v), без разрывов 1.2·10⁻⁵ E0. От dt не зависит (при dt/64 те же 1.2·10⁻⁵ E0), знак корректный: с вычетом clip остаток при dt/64 меньше (5.3·10⁻⁶ против 1.06·10⁻⁵ E0). Для пластики без вязкости — ровно 0.
     * **(в) Кельвин по скорости предиктора — O(dt), не ошибка учёта.** Кельвин без пластики и Максвелла на той же сцене: max|residual| 6.4·10⁻⁴ E0 (dt лога), 8.8·10⁻⁵ (dt/4) — убывает.
     * **(г) Работа на шаге разрыва** уже входит: W_p/W_v берутся до удаления, D_break — по состоянию конца шага (x^{n+1}), как и запас в соседних строках лога.
     * **Сходимость E5 с разрывами по dt** (глобальный шаг, умноженный на коэффициент; max|residual|/E0): 1 → 2.05·10⁻⁴; 1/2 → 1.0·10⁻⁴; 1/4 → 8.7·10⁻⁵; 1/8 → 4.3·10⁻⁵; 1/16 → 2.1·10⁻⁵; 1/32 → 1.1·10⁻⁵; 1/64 → 5.3·10⁻⁶ (~ пропорционально dt, остаток — O(dt) схемы). Допуск теста E5: 0.35·(W_p + W_v) = 0.043 % E0 (запас 2×); без W_p + W_v невязка 0.14 % E0, без D_break_contact 0.078 % E0 — оба контроля выходят за допуск.
     * **Не разобрано до конца.** На сценах БЕЗ разрывов (eps_break = 1) невязка с пластикой/Максвеллом не уходит в ноль при уменьшении шага: пластика ~6.6·10⁻⁵ E0 (dt/16), Максвелл + Кельвин ~6.7·10⁻⁵ E0 (dt/64), Кельвин + пластика ~1.5·10⁻⁴ E0 (при W_v = 2.9·10⁻³ E0), тогда как упругая нить сходится (1.9·10⁻⁴ → 3.0·10⁻⁵ при dt/16). Это 1–2 % W_p + W_v, т. е. в пределах допуска E5 (0.1·W), и не связано с разрывами и отсечкой; вероятный источник — хаотичность сцены (трение/контакт меняют траекторию при смене dt) плюс явная пластическая работа на сильно текущих связях; отдельно не разбиралось.
     * **Монитор W_p меньше лога на 22 %** (E5: 0.340 мДж против 0.416 мДж) — не ошибка лога: монитор хранит W_p порвавшихся связей по ключу (i,j), но не видит приращение на шаге разрыва (связь уже удалена). Проверено: разность лог − монитор равна сумме приращений w_p·A·l0 порвавшихся связей на их шагах разрыва (7.5706·10⁻⁵ против 7.5707·10⁻⁵ Дж с Максвеллом; пластика без вязкости, 20 разрывов: 1.8547·10⁻⁴ против 1.8547·10⁻⁴ Дж). Связи рвутся в фазе активного течения, поэтому доля большая.
5. **Трение и контакт.** Контакты нить-нить и нить-Solid используют текущие длины сегментов, а не `l0` (`fiber_contact.hpp:107`, `fiber_contact_common.hpp:31`), поэтому пластическое удлинение их не ломает. Но массы бусин постоянные при растяжении (масса из ненагруженной конфигурации), при пластической вытяжке на десятки процентов диаметр и площадь `A` реально уменьшаются; для больших деформаций нужен пересчёт `A` (см. 1.4).
6. **Данные.** Параметры пластики и скоростной зависимости для нужного волокна не взяты из литературы (в подборке они не проверены). Нужен ввод от пользователя: какое волокно (арамид, СВМПЭ, полиамид, металлическая нить) — от этого зависит, что действительно нужно: арамид и СВМПЭ почти хрупкие, и им важнее вязкоупругость и скоростное упрочнение, чем пластика.
7. **Слияние с Guo2T и энергобаланс монитора Guo.** `tests/test_fiber_plasticity_guo.cpp` зависит от API `tests/guo2019_scene.hpp` / `guo2019_monitor.hpp` / `guo2019_case.hpp` (`build_guo_scene`, `MonitorOptions`, `GuoShotMonitor`, `RunGuard`, `GuoScene` и др.), которые параллельно правятся в ветке Guo2T; при слиянии возможны конфликты и поломка сборки этого теста (в ветке `plastic` эти файлы не менялись). Энергобаланс монитора Guo для пластичной нити не завершён: `clamp_e2e::bond_energy` уже учитывает `ε_p` и пружину Максвелла, но сам монитор (`guo2019_monitor.hpp`) не включает накопленные `ΣW_p + ΣW_v` в баланс `E_tot` (добавить после слияния). Пока `E_tot` монитора для неупругой нити непригоден.

## Приложение А. Пластичность при изгибе (если будет добавлен изгиб по Meyer)

Для изгиба в код нужно сначала вернуть угловую жёсткость (eq. 17 Meyer: `M_b = EI(θ − θ0)/(½(‖x_i(i−1)‖+‖x_i(i+1)‖))`, силы `F^b_ij = ½ M×x_ij/‖x_ij‖²`, eq. 18) — сейчас её нет. Пластику изгиба можно строить аналогично связи: внутренняя переменная `θ_p` (вектор), упругий момент `M = k_θ(θ − θ_p)`, пластический момент `M_p = σ_y·d³/6` (полностью пластическое сечение круглой нити; начало текучести — `M_y = σ_y·π d³/32`), возврат по модулю вектора `M` с радиальным масштабированием, критерий разрыва по углу `θ_c` (из Meyer) или по накопленному `θ_p`. По смыслу близко к Discrete Elasto-Plastic Rods (п. 3 подборки, не проверено). Для баллистических задач, где доминирует растяжение, на первой версии это не нужно.
