## 0. Цель и границы

**Сделать:**
1. Прочность Джонсона-Кука для твёрдых SPH-частиц: Y = [A + B·ε_p^n]·[1 + C·ln ε̇*]·[1 − T*^m].
2. Температуру частицы и адиабатический нагрев.
3. Разрушение Джонсона-Кука: ε_f = [D1 + D2·exp(D3·σ*)]·[1 + D4·ln ε̇*]·[1 + D5·T*], накопление D = ΣΔε_p/ε_f, поведение разрушенной частицы.
4. Библиотеку из 4 материалов с константами Autodyn (сталь 4340, сталь 1006, Al 7039, Al 5083-H116) и нужные им УРС (Linear, Shock).
5. Тесты: unit, интеграционные, сквозные, регрессия.

**Не делать (вне объёма):**
- удаление (эрозию) частиц — SPH-частица не удаляется, разрушенная лишь теряет сдвиговую прочность и сопротивление растяжению;
- Zerilli-Armstrong, Steinberg-Guinan и прочие модели со слайда;
- изменение существующих материалов `itype` 1–11 и их поведения. Эталоны BC2/BC6 и регрессионные снимки должны остаться побитово-допусково теми же.

**Решения, принятые в плане (агенту не пересматривать без Mary):**
- Р1. JC-материалы получают **новые** `itype` 12–15, а не заменяют Мизес у `itype` 4 (алюминий). Так старые эталоны не трогаются.
- Р2. Скорость деформации в множителе прочности — **полная эквивалентная девиаторная** ε̇_eq = √(2/3 ė′:ė′) (как LS-DYNA `*MAT_015` при VP=0 и Autodyn). Опционально — пластическая (флаг материала, см. §2.1).
- Р3. Температура из внутренней энергии: T = T_r + u/c_p (как в Autodyn: при `u = 0` температура равна T_r). Пластическая работа уже входит в `u` через уравнение энергии (член s:ė/ρ в `solid_sph.hpp:~995`), поэтому отдельный источник тепла не нужен. Коэффициент Тейлора-Куинни — опция §2.4.
- Р4. Множитель скорости: ε̇* = max(ε̇/ε̇_0, 1), то есть при ε̇ < ε̇_0 множитель = 1 (как в `fiber_plasticity.hpp:210`, Autodyn «1st Order»).
- Р5. Разрушенная частица (D ≥ 1): девиатор = 0, Y = 0, давление ограничено снизу нулём (не держит растяжение). Повреждение до 1 на прочность **не** влияет (стандартный JC без связи, как в Autodyn).
- Р6. Значение `1.01e20` (заглушка Autodyn) или флаг `damage_enabled = false` означает «разрушение выключено».

## 2. Физика и численная схема (то, что реализуем)

### 2.1 Предел текучести

```
Y(ε_p, ε̇, T) = [A + B·ε_p^n] · R(ε̇) · Θ(T)
R  = 1 + C·ln(max(ε̇/ε̇_0, 1))           — "1st Order" (по умолчанию)
R  = max(ε̇/ε̇_0, 1)^C                     — "Exponential" (опция rate_form)
T* = (T − T_r)/(T_m − T_r)
Θ  = 1                 при T* ≤ 0
Θ  = 1 − T*^m          при 0 < T* < 1
Θ  = 0                 при T* ≥ 1  (расплав: девиатор обнуляется)
```
`ε̇` — по Р2: ε̇_eq = √(2/3·ė′:ė′), ė′ — девиатор скорости деформации из `sys.exx..eyz` (для `dim=1` и осесимметрии — по тем же правилам, что в `solid_sph.hpp`; вынести в одну функцию). Опция `rate_source = plastic`: ε̇ = Δε_p/dt с предыдущего шага (явно, без итерации по скорости).

Внимание на запись со слайда лекции: там `[1 − T/T0]^m`. Это **не** формула JC; реализуем оригинал (см. `jc-analysis.md`, раздел 7).

### 2.2 Возврат на поверхность текучести (radial return с упрочнением)

На шаге после корректора (там же, где сейчас Мизес):
1. Пробный девиатор s^tr уже посчитан решателем; σ_eq^tr = √(3·J2(s^tr)).
2. Y_0 = Y(ε_p^n, ε̇, T^n). Если σ_eq^tr ≤ Y_0 — упруго, выход.
3. Иначе найти Δε_p ≥ 0 из скалярного уравнения
   `f(Δ) = σ_eq^tr − 3G·Δ − Y(ε_p^n + Δ, ε̇, T^n) = 0`.
   Функция монотонно убывает; корень на `[0, σ_eq^tr/(3G)]`.
   **Обязательно** безопасный Ньютон с откатом на бисекцию: при n < 1 производная dY/dε_p = n·B·ε_p^(n−1) бесконечна в нуле. Допуск |f| ≤ 1e-12·Y_0 или 50 итераций; при неудаче — бисекция до 1e-14 относительных.
4. s = s^tr · (Y_new/σ_eq^tr), где Y_new = σ_eq^tr − 3G·Δ; ε_p += Δ.
5. Обновить `sys.e_pl[i] = ε_p` (это накопленная деформация, а не скорость — у JH-2 там иначе, см. `jc-analysis.md` §2; для JC хранить именно ε_p).

Температура на шаге берётся с начала шага (явная связь), этого достаточно при CFL-шагах.

### 2.3 Температура и нагрев

`T = T_r + u/c_p`, где `u` — `sys.u[i]` (удельная внутренняя энергия, Дж/кг, стартует с 0). Пересчитывать в начале `apply_material_strength` для JC-частиц и хранить в новом поле `sys.T` (для вывода и разрушения). Оговорка в документации: при сильном сжатии `u` содержит и «холодную» энергию сжатия, поэтому T завышается; так же поступает Autodyn.

### 2.4 Опция: Тейлор-Куинни
Флаг материала `heating = energy` (по умолчанию, Р3) | `taylor_quinney`. Во втором режиме T ведётся отдельным полем: `T += χ·Y·Δε_p/(ρ·c_p)`, χ = 0.9 по умолчанию; `u` не меняется. Делать после основной части, отдельным коммитом.

### 2.5 Разрушение

```
σ_eq = √(3·J2(s)),  σ* = −p/σ_eq          (p > 0 при сжатии)
ε_f  = [D1 + D2·exp(D3·σ*)] · [1 + D4·ln(max(ε̇/ε̇_0f, 1))] · [1 + D5·T*]
ε_f  = max(ε_f, eps_f_min),  eps_f_min = 1e-6 по умолчанию
ΔD   = Δε_p / ε_f,   D = min(D + ΔD, 1)
```
- Если σ_eq < 1e-12·A (нет сдвига) — повреждение на шаге не накапливаем (Δε_p всё равно 0).
- Опция `damage_rate_form = borvik`: множитель скорости `(1 + ε̇*)^D4` — нужен для набора 5083-H116 (Grytten et al. 2006, модифицированный критерий Børvik).
- В разделе Failure у Autodyn свои T_m и ε̇_0 (по умолчанию T_m = 0 — его надо задать, иначе T* не определена). В структуре материала держать отдельные `Tm_f`, `edot0_f`; если `Tm_f ≤ 0` — брать T_m из прочности и писать предупреждение.
- Хранить в `sys.D[i]` (то же поле, что у JH-2; материалы не пересекаются).

### 2.6 Разрушенная частица (D ≥ 1)
- в `apply_material_strength`: девиатор = 0, ε_p больше не растёт;
- в УРС (`solid_eos` и `urs`): `p = max(p, 0)` для JC-материалов с `D ≥ 1` (аналог `Hydro (Pmin)` в Autodyn);
- в законе Гука (`solid_sph.hpp:~1001`): для разрушенной частицы `G_ = 0` (девиатор не набирается заново). `shear_modulus_by_itype` при этом **не** менять: она даёт табличный G для контакта (см. комментарий в `materials.hpp` про неповреждённые константы). Сделать отдельную функцию `effective_shear_modulus(mats, sys, i)`.

### 3.3 УРС (новые функции в `src/eos.cpp` / `include/eos.hpp`)
- **Linear:** μ = ρ/ρ0 − 1, p = K·μ, c = √(K/ρ0). (Autodyn Linear не зависит от энергии.)
- **Shock (Ми-Грюнайзен по ударной адиабате Us = c0 + S1·up, как в Autodyn):**
  при μ > 0: p_H = ρ0c0²·μ(1+μ)/[1 − (S1−1)μ]², e_H = ½·(p_H/ρ0)·μ/(1+μ);
  при μ ≤ 0: p_H = ρ0c0²·μ, e_H = 0;
  p = p_H + Γ0·ρ0·(u − e_H).
  c² = ∂p/∂ρ|_u + (p/ρ²)·Γ0·ρ0; производную взять аналитически, проверить конечной разностью в тесте. Если c² ≤ 0 — c = c0 (как защита в существующих УРС, но с c0, а не 100).
- для разрушенных частиц — `p = max(p, 0)` (§2.6).

## 6. Риски и на что обратить внимание

1. **n < 1 в нуле** — бесконечная производная; без бисекции Ньютон расходится (U9).
2. **Две реализации УРС** (`urs` и `solid_eos`) — расширять обе, иначе старый и новый путь разойдутся. Добавить тест, что для itype 12–15 они дают одно и то же.
3. **`e_pl` у JH-2 хранит интеграл скорости** (`ppochnost.cpp:173`), у JC — накопленную деформацию. Не унифицировать в этой задаче, но записать в ADR.
4. **Температура из `u`** завышается при сильном сжатии (холодная энергия). Для E2–E4 это несущественно; отразить в документации.
5. **Растяжение в SPH** (tensile instability) может давать ложное разрушение в E3. Если ворота E3 нестабильны — не подгонять константы; зафиксировать в отчёте и обсудить с Mary.
6. **Сдвиг столбцов вывода** — только дописывать в конец.
7. **Не менять** константы `itype` 1–11 и эталоны.
