# Отчёт: пробитие 1T и 2T на уровне `base`: значение трения μ = 0.3 и его варьирование

**Дата:** 2026-10-09/10, ветка `Guo2T` (код не закоммичен). **Статья:** Guo et al., IJIE 127 (2019) 1–16.
**Состояние:** отчёт промежуточный. Для 2T при μ = 5.0 подбор скорости ещё идёт на сервере, для μ = 2.2 и 3.0 он не доведён до ширины отрезка 6 м/с. Результаты будут добавлены.
Правила: числа только измеренные (из `shots.csv`, `shot.txt`, `monitor.csv`), оценки помечены словом «оценка». Все выстрелы использовали уровень `base`, решатель PC, `contact_force_type = 1`, `OMP`, 8 потоков, если не указано иное (повторы на 4 потоках), `n_mon = 10`, `n_diag = 100`.

---

## 1. Что и как считалось

### 1.1. Как в коде задаётся трение

- Значение по умолчанию `kMuDefault = 0.3` (`tests/guo2019_case.hpp:192`). В статье коэффициент трения не приведён, поэтому 0.3 — оценка проекта.
- `build_guo_scene` (`tests/guo2019_scene.hpp`) записывает `mu_ff = mu_fs = μ` в единственный материал нитей (строка `MATERIAL 0 … μ_ff μ_fs` в `.fib`). Ключ `--mu=<μ>` у `guo2019_shot` меняет оба.
- `μ_ff` — трение нить–нить (внутри слоя и между слоями 2T), `μ_fs` — нить–Solid (шар).
- В ядре трение — проекция на уровне скоростей с пределом импульса μ·N·h (`include/interactions/fiber_friction.hpp`), один коэффициент для статического и кинематического; при μ = 0 стадия не выполняется.

### 1.2. Как определялся порог (диапазон «есть пробитие / нет пробития»)

Для каждой пары (конфигурация, μ) нужно найти пару скоростей: наибольшая без пробития (`lo`) и наименьшая с пробитием (`hi`). Исход берёт сама программа: пробит, если шар вылетел с обратной стороны; не пробит, если вернулся. Исход «не определён» — шар к `t_max` ещё в ткани.
- При μ = 0.3: адаптивный подбор `base_driver2/3.py` (деление отрезка пополам по исходам программы).
- При других μ: `mu_driver.py` (1T), `mu_driver_2T.py` и `vbl_fixed_mu.py` (2T).
- `t_max` на `base`: 1T 1.5 мс, 2T 1.2 мс (с повтором 2.4 / 3.0 мс при «не определён» в драйверах μ-подбора). V_BL модели записан как середина отрезка [lo; hi].

## 5. Общие выводы (промежуточные)

1. **1T:** порог по V_BL при μ = 0.3 на 13 % ниже статьи (66.3 против 76). Трение μ ≈ 1.8 переносит порог к 76–79 м/с, но разрывов становится в 6–7 раз больше, чем в статье, а V_R у порога остаётся выше опытной. Значение 1.8 — калибровка.
2. **2T:** порог при μ = 0.3 на 22 % ниже статьи. Рост μ до 5.0 пробитие при 144 м/с не снимает, V_R при 144 м/с выходит на плато 30–41 м/с, то есть эффект трения насыщается уже около μ = 2.6. Одним коэффициентом трения расхождение для 2T не закрывается (оценка по доступным данным; определение порога при μ = 5.0 не завершено).
3. **Разброс у порога:** остаточная скорость при почти одинаковых скоростях может различаться в десятки раз (1T при μ = 1.8: 79 м/с дал пробит и не пробит на 8 и 4 потоках; 2T при μ = 0.3: V_R = 1.3 и 41.1 м/с при 117.8 м/с). Исход «пробит / не пробит» в 1T при 79 м/с зависит от потоков. Определять порог нужно по исходу и с повторами.
4. **Постоянное в расхождении с опытом:** число порванных нитей выше статьи при всех μ; прогиб при первом разрыве на `base` 25–26.4 мм совпадает со статьёй (25–27), на `scaled` занижен (6.5–7 мм).
5. **Возможные причины, не проверявшиеся:** толщина слоя модели вдвое больше реальной (0.858 мм против 0.4), слои без сдвига в плоскости, предельная деформация нити ε_b = 0.03 (оценка), единое μ внутри слоя и между слоями (в статье межслойное трение названо причиной сверхлинейности), особенности контакта нить–нить.
