## 1. Почему не явный закон Кулона

Первая версия этого плана предлагала $\mathbf F_t = -\mu_{fs}N\,\hat{\mathbf v}_t$ внутри kernel нормального контакта. Это ровно та модель, которая дала дребезг у нить–нить (`fiber/friction_chattering_analysis.md`): как только $\mu N\,\Delta t\,W > \|\mathbf v_t\|$, скорость перебрасывается через ноль, трение перестаёт рассеивать энергию, а в схеме PC ещё и смещается. Для нити, лежащей на пластине, медленное скольжение — основной режим, поэтому дребезг здесь проявится сильнее, чем при скрещивании нитей.

Поэтому трение Fiber–Solid реализуется **той же проекцией на уровне скоростей** и **в той же стадии**, что трение нить–нить (п. 5).

## 3. Кинематика и знаки (по текущему коду)

В `compute_fiber_solid_contact_geometry` нормаль

$$
\mathbf n = \frac{\mathbf x_s - \mathbf q}{\|\mathbf x_s - \mathbf q\|}
$$

направлена **от нити к Solid**. Нормальная сила: на Solid $+N\mathbf n$, на нить $-N\mathbf n$, распределённая как $(1-\lambda)$ на $a$ и $\lambda$ на $b$. Эту конвенцию не менять.

Относительная скорость (нить относительно Solid) в точке контакта:

$$
\mathbf u = \big[(1-\lambda)\tilde{\mathbf v}_a + \lambda\tilde{\mathbf v}_b\big] - \tilde{\mathbf v}_s,
\qquad
\mathbf u_t = \mathbf u - (\mathbf u\cdot\mathbf n)\mathbf n,
$$

где $\tilde{\mathbf v}$ — пробные скорости (п. 4). Сила трения $\mathbf F_t$ действует на **нить** и распределяется $(1-\lambda)\mathbf F_t$ на $a$, $\lambda\mathbf F_t$ на $b$. На Solid действует $-\mathbf F_t$.

Итог для проверки знаков:

| кто | нормальная часть | трение |
|---|---|---|
| бусина $a$ | $-(1-\lambda)N\mathbf n$ | $+(1-\lambda)\mathbf F_t$ |
| бусина $b$ | $-\lambda N\mathbf n$ | $+\lambda\mathbf F_t$ |
| Solid $s$ | $+N\mathbf n$ | $-\mathbf F_t$ |

Для точечного primitive (`has_b == false`) вся доля нити приходится на $a$.

## 4. Пробная скорость Solid

Проекция должна знать скорость, которую частица Solid получит после `advance()`. У Solid в схеме PC к ней добавляется поправка XSPH (`pc_finalize_velocity_position_with_av`):

$$
\mathbf v_s^{n+1} = \mathbf v_s^{\mathrm{base}} + h\,\mathbf a_s + \mathbf{av}_s .
$$

Добавить в оба решателя, по аналогии с `fiber_velocity_update` из задачи 3:

```cpp
struct SolidVelocityUpdate
{
    const std::vector<double>* base[dim];          // v^base
    double h;                                       // коэффициент при dvx
    const std::vector<std::vector<double>>* av;     // поправка XSPH; nullptr -- нет
};
SolidVelocityUpdate solid_velocity_update(const ParticleSystem& sys, double dt) const;
```

| решатель | состояние | база | $h$ | `av` |
|---|---|---|---|---|
| PredictorCorrector | первый шаг | `sys.vx` | `dt / 2` | `&solid_rhs.av` |
| PredictorCorrector | шаг $n \ge 2$ | `v_min_` | `dt` | `&solid_rhs.av` |
| Euler | любой | `sys.vx` | `dt` | `nullptr` |

Коэффициент брать из того же места, что `correct_solid` (общий приватный метод), а не дублировать выражение `fs ? dt / 2.0 : dt`.

Пробная скорость: $\tilde{\mathbf v}_s = \mathbf v_s^{\mathrm{base}} + h\,\mathbf a_s^{\text{без трения}} + \mathbf{av}_s$. В $\mathbf a_s$ уже входят SPH-силы тела, Solid-Solid-Contact и нормальный Fiber–Solid-Contact: частицу держат её соседи, и проекция это видит.

Для нити — `fiber_velocity_update` из задачи 3 без изменений.

## 5. Единая стадия трения

Трение нить–нить и нить–Solid считаются **одним проходом Якоби** в стадии из задачи 3. Два последовательных прохода не допускаются: каждый читал бы ускорения без трения другого, и бусина, одновременно касающаяся нити и пластины, получила бы двойную поправку.

### 5.1. Слоты Fiber–Solid

`compute_fiber_solid_contact_contributions` (только нормальная сила, как сейчас) дополнительно заполняет вектор слотов, по одному на primitive, запись по индексу `k`:

```cpp
struct FiberSolidFrictionContact   // POD
{
    bool active = false;           // contact && mu > 0
    rhs::index_t a = 0; long long b = -1;   // b = -1 -- точечный контакт
    rhs::index_t s = 0;
    double lambda = 0.0;
    double n[dim] = {};            // от нити к Solid, как в геометрии
    double N = 0.0;
    double mu = 0.0;
};
```

Размер выставляет вызывающая сторона, вектор переиспользуется между шагами (как слоты нить–нить).

### 5.2. Mass splitting — теперь обязательно

В задаче 3 проход Якоби оставлен без защиты от нескольких контактов на одной бусине: для одиночного скрещивания нитей их нет. Для Fiber–Solid это **обычная** ситуация: сегмент на пластине касается сразу нескольких частиц (примерно $l_0/\Delta x + 1$), каждая бусина входит в два сегмента, а частица Solid может касаться нескольких сегментов. Без защиты суммарная поправка на бусину превышает нужную в несколько раз, и дребезг возвращается.

Поэтому в этой задаче стадия получает mass splitting для **обоих** видов контактов:

1. Перед проходом посчитать $c_k$ — число активных контактов (обоих видов), в которых бусина $k$ имеет ненулевой вес, и $c_s$ — то же для частиц Solid. Считать через contributions + reduce с маленьким типом Delta (`FiberCountDelta`/`SolidCountDelta { double c; operator+= }`), без atomics.
2. В эффективной массе каждого контакта заменить $1/m_k$ на $c_k/m_k$:

$$
W = \sum_{k\in\text{нить}} \frac{c_k\,\alpha_k^2}{m_k} \;+\; \frac{c_s}{m_s}
\quad\text{(Fiber–Solid)},
\qquad
W = \sum_{k\in A}\frac{c_k\alpha_k^2}{m_k} + \sum_{k\in B}\frac{c_k\beta_k^2}{m_k}
\quad\text{(нить–нить)}.
$$

Остальные формулы проекции (пробная скорость, $J_\text{stick}$, $J = \min(\mu N h, J_\text{stick})$, $\mathbf F_t$) — без изменений из задачи 3.

Свойства:
- если все $c = 1$, умножение на `1.0` точное, и результат побитово совпадает с задачей 3;
- каждый контакт рассчитывает импульс так, будто ему доступна только своя доля массы бусины, поэтому суммарная поправка не перескакивает через ноль в типичных конфигурациях. Цена — возможное недокомпенсирование: в узле с многими контактами прилипание достигается не за один шаг, а за несколько, с медленной остаточной ползучестью. Точное решение требует итераций (записать как дальнейшую работу, не реализовывать).

Раздел «Известное ограничение» из задачи 3 (шапка `fiber_friction.hpp`, `SPH.md`, `PLAN.md`) обновить: перескок устранён mass splitting, осталось возможное недокомпенсирование.

### 5.3. Вклады и место в шаге

- нить: `FiberDelta`, `interaction_type` 5 (трение Fiber–Solid, сторона нити; 4 — трение нить–нить);

### 5.4. Кинематическое Solid-тело (только для тестов)

В `test_e2e_fiber_solid` пластина неподвижна: вклад в Solid вычисляется и отбрасывается, скорость Solid не интегрируется. Чтобы проекция была точной и в таком тесте, стадия принимает флаг `solid_kinematic` (по умолчанию `false`): при `true` считать $c_s/m_s = 0$ (бесконечная масса) и не эмитировать вклады в Solid. В боевом цикле флаг всегда `false`.

## 6. Известные ограничения (записать в документацию)

1. **Момент импульса.** Трение приложено в точке $\mathbf q$ на нити и в центре частицы $\mathbf x_s$ на Solid. Эти точки разнесены по нормали на $D$, так что пара сил $\pm\mathbf F_t$ создаёт момент $D\,\|\mathbf F_t\|$. У SPH-частиц нет вращательных степеней свободы, поэтому момент импульса системы трением не сохраняется. Нормальная сила направлена вдоль $\mathbf n$ и такого момента не создаёт. Линейный импульс сохраняется точно.
2. **Скорость поверхности Solid** берётся как скорость одной частицы, без интерполяции по соседям.
3. **Газ и вода** (`elastic_by_itype` не определён): нормальный контакт не формируется, трения тоже нет.
4. **Остаточное недокомпенсирование** в узлах со многими контактами (п. 5.2).

## 7. Тесты

### 7.1. Модульные (`tests/test_fiber_friction.cpp`)

Одиночный контакт Fiber–Solid, $0 < \lambda < 1$, разные массы:
- **прилипание:** после обновления касательная относительная скорость точки контакта равна нулю (относительно $10^{-12}$), $\|\mathbf F_t\| < \mu N$;
- **скольжение:** $\|\mathbf F_t\| = \mu N$, направление $-\hat{\mathbf u}_t$, $\mathbf u_t$ не сменила знак;
- **статическое трение:** базовая относительная скорость ноль, в `dv` бусин задано тянущее касательное ускорение; ниже порога $\mu N$ — прилипание, выше — скольжение с $\mu N$;
- **XSPH:** ненулевой `av` у частицы Solid учитывается в пробной скорости (прилипание точное с учётом `av`);
- **знаки:** таблица п. 3 — нормальная и тангенциальная части на $a$, $b$, $s$;
- **касательность:** $\mathbf F_t\cdot\mathbf n = 0$;
- **импульс:** $m_a\mathbf a_a + m_b\mathbf a_b + m_s\mathbf a_s = 0$;
- **диссипация:** 1000 случайных контактов, кинетическая энергия после трения не больше, чем без него;
- **$\mu_{fs} = 0$:** стадия не вызывается, `dv` и `dvx` побитово не изменились;
- **кинематическое тело:** при `solid_kinematic = true` вклад в Solid не эмитируется, прилипание точное относительно заданной скорости Solid.

Mass splitting:
- сегмент на трёх частицах Solid, общее скольжение, все контакты в режиме прилипания: после шага касательная скорость в каждой точке контакта **не сменила знак** (нет перескока) и уменьшилась;
- то же без mass splitting (временный флаг в тесте или прямой вызов формулы с $c = 1$) даёт перескок — самопроверка сцены;
- бусина одновременно в контакте нить–нить и нить–Solid: перескока нет;
- одиночные контакты ($c = 1$): результат побитово совпадает с формулой задачи 3.

Интерфейс решателя: `advance()` даёт `sys.vx`, побитово равную `base + h * dvx + av` из `solid_velocity_update`, для PC (первый шаг и $n \ge 2$) и Euler.

### 7.2. Сценарные (`tests/test_e2e_fiber_solid.cpp`)

Сцена `test_fiber_falls_on_plate` (кинематическая пластина), нити добавлена касательная скорость $v_{t0}$ вдоль $x$:
- **(a) $\mu_{fs} = 0$:** касательная скорость нити контактом не меняется (допуск на наклон нормали, как в `test_e2e_cross_friction` (a));
- **(b) быстрое скольжение:** $v_{t0}$ много больше ёмкости прилипания; касательная скорость уменьшается, торможение по порядку величины равно $\mu\,|\Delta v_n|$;
- **(c) медленное скольжение:** ёмкость прилипания больше $v_{t0}$ (напечатать её; при необходимости поднять $\mu$ и записать это в комментарий). Нить прилипает: $\|\mathbf u_t\|$ в каждой точке контакта после первого шага прилипания не больше $10^{-9} v_{t0}$, пока `stick_count > 0`; $\max\|\mathbf u_t\| \le v_{t0}$; импульс, переданный трением, при $\Delta t$ и $\Delta t/5$ отличается не более чем на 10 %;
- **(d) свободная пластина:** та же сцена, пластина интегрируется (не кинематическая, малая масса). Суммарный линейный импульс нити и пластины сохраняется с допуском проекта; пластина получает касательный импульс, равный и противоположный импульсу нити.
