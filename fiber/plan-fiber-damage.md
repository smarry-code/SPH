# План: повреждённость нити с разупрочнением (DAMAGE), по умолчанию выключена

Решение владельца (2026-10-22): делать в ветке `fiber_contact_damped`, без новой ветки. Модель
выключена по умолчанию: без строки `DAMAGE` в файле нити результат побитово прежний. Расчёты Guo —
на законе 3 без выталкивания, шаг ×0,5 (как серия `~/vbl1T_law3_dt05_nopush`).

## 1. Зачем

Сейчас связь рвётся мгновенно при σ = σ_u, без затраты энергии. Под шаром 6–8 одинаковых нитей
рвутся пачкой: нагрузка порванной нити сразу переходит на соседей, которые уже на пределе, плюс
ударный заброс от мгновенной разгрузки. В статье рвутся 3 нити.

Простое накопление D += |Δε_p|/ε_f с разрывом при D = 1 ничего не изменит: до разрыва связь держит
полную нагрузку, это тот же мгновенный разрыв (так уже работает `FAILURE EPS_P`). Нужно
**разупрочнение**: после достижения σ_u связь теряет силу постепенно, на конечном участке деформации,
с затратой энергии. Физически — нить как пучок ~1000 филаментов, рвущихся не одновременно.

## 2. Модель

Внутренние переменные связи (`BondState`, `include/fiber/fiber_plasticity.hpp:120`) дополняются:
`D` — повреждённость [0, 1], `kappa` — наибольшая достигнутая деформация после начала повреждения,
`eps0` — деформация в момент начала, `w_d` — работа разупрочнения.

1. **Начало повреждения.** Когда напряжение без повреждения σ_eff = E(ε − ε_p) + q достигает σ_u
   (та же величина, что в нынешнем критерии `SIGMA_U`), запоминаются ε0 = ε и σ_u. Пластика после
   начала повреждения замораживается (ε_p не растёт).
2. **Огибающая разупрочнения — линейная:**
   $$\sigma_{env}(\kappa)=\sigma_u\Big(1-\frac{\kappa-\varepsilon_0}{\Delta\varepsilon_f}\Big),\qquad \kappa=\max_t\varepsilon .$$
3. **Повреждённость** из огибающей, необратима:
   $$D=1-\frac{\sigma_{env}(\kappa)}{E(\kappa-\varepsilon_p)+q_\kappa},\qquad D^{n+1}=\max(D^n, D).$$
4. **Напряжение:** σ = (1 − D)·(E(ε − ε_p) + q) + η_v ε̇. Разгрузка и повторная нагрузка идут по секущей
   к ε_p с жёсткостью (1 − D)E. При сжатии связь, как и сейчас, не работает (σ ≥ 0), и D не растёт.
5. **Разрыв:** при D ≥ 1 (κ ≥ ε0 + Δε_f) связь удаляется прежним кодом топологии
   (`apply_fiber_break_events`, `postprocessing.hpp:505`). Критерий `SIGMA_U` при включённой
   повреждённости **не срабатывает** (иначе связь рвалась бы в момент начала повреждения). Критерии
   `EPS_P` и страховочный `eps_break` остаются.
6. **Энергия.** Работа разупрочнения w_d — новый канал `W_d_fiber` в логе энергии, рядом с
   `W_p_fiber`. При полном разрушении запасённая энергия связи равна нулю.
7. **Шаг по времени** не меняется: при разупрочнении жёсткость падает, предел шага по неповреждённой
   жёсткости остаётся консервативным.
8. **Независимость от сетки (опция GF).** Разупрочнение сосредотачивается в одной связи, и энергия
   разрушения пропорциональна её длине l₀. Поэтому вместо Δε_f можно задать энергию разрушения
   G_f (Дж/м²); тогда для каждой связи Δε_f = 2 G_f / (σ_u l₀).
9. **Угловой критерий θ_c (опция, по умолчанию выключена).** Если угол между соседними связями в
   бусине больше θ_c, удаляется более нагруженная из двух (при равенстве — с меньшим индексом).
   Изгибной жёсткости в модели нет, нить у края шара изламывается сильно, поэтому θ_c может дать
   ложные разрывы; включать только для проверки.

## 3. Как включать

Строка в файле неупругости нити (тот же файл, что `PLASTIC` и `FAILURE`, ключ `--fiber-inelastic`):

```
PLASTIC 0 SY=2.04e9 H=100e9
FAILURE 0 SIGMA_U=2.5e9
DAMAGE  0 DEPS_F=0.01                 # линейное разупрочнение на участке 1 %
# или
DAMAGE  0 GF=2000                     # энергия разрушения, Дж/м²; Δε_f = 2 GF/(σ_u l0) для каждой связи
# опция
DAMAGE  0 DEPS_F=0.01 THETA_C=2.6     # + угловой критерий, рад
```

Проверки разбора (ошибка, а не молчаливое значение по умолчанию):
- `DAMAGE` без `FAILURE SIGMA_U` — ошибка (нет напряжения начала повреждения);
- одновременно `DEPS_F` и `GF`, или ни одного — ошибка;
- отрицательные или нулевые значения, нечисловой хвост — ошибка.

Пример запуска (Guo 1T, закон 3 без выталкивания, шаг ×0,5):

```
guo2019_shot --config=1T --level=base --v0=73 --mu=0.1 --fs-contact=3 --ff-contact=3 --dt-scale=0.5 \
  --fiber-inelastic=twaron_s25_dmg1.fib --eps-break=0.05 --fiber-E=8e10 \
  --save-t=2e-5 --energy-log=100 --frames=off --repeat=1 --no-bracket --t-max=1.5e-3 --out=...
```

В `shot.txt` добавляются поля `damage_deps_f`, `damage_gf`, `damage_theta_c`, `n_bonds_damaged`
(связей с D > 0), `W_d`. В кадрах нити в строку связи добавляется последний столбец D (в конец, чтобы
не сломать разбор существующими скриптами).

## 4. Тесты

### A. Модульные (новый `tests/test_fiber_damage.cpp`)

| № | Что | Критерий |
|---|---|---|
| A1 | одна связь, монотонное растяжение | σ(ε) упруго-пластично до σ_u, затем линейно до 0 при ε0 + Δε_f; совпадение с формулой до 10⁻¹² |
| A2 | разгрузка и повторная нагрузка на участке разупрочнения | разгрузка по секущей к ε_p, повторная нагрузка по секущей до огибающей; D не убывает |
| A3 | энергия | работа внешней силы = упругая + W_p + W_d; после полного разрушения запасённая = 0; W_d = ½ σ_u Δε_f · A l₀ |
| A4 | опция GF, независимость от сетки | цепочки одной длины с l₀ и l₀/2: энергия разрыва одинакова (до 1 %) |
| A5 | разрыв | связь удаляется ровно при D = 1; `SIGMA_U` не срабатывает раньше; `eps_break` срабатывает |
| A6 | вместе с Максвеллом и Кельвином | q масштабируется на (1 − D); энергия не создаётся |
| A7 | θ_c | прямая цепочка не рвётся; излом больше θ_c рвёт выбранную связь; меньше — нет |
| A8 | разбор строки `DAMAGE` | верные строки принимаются, неверные (§3) дают ошибку |
| A9 | сжатие | при сжатии D не растёт, связь не работает |
| A10 | детерминизм | порядок и набор разрывов не зависят от числа потоков |

### D. Расчёты Guo (сервер)

1T base, закон 3 без выталкивания, шаг ×0,5, E = 80 ГПа, μ = 0,1, 73 м/с; Δε_f = 0,5 %, 1 %, 2 %.
Сравнение с базой без повреждённости — выстрел N73 той же серии (`~/vbl1T_law3_dt05_nopush`).

Метрики: число разрывов (цель 3 / 0), прогиб к первому разрыву (25–27 мм), исход и V_R, W_d,
длительность разрушения нити (от начала повреждения до D = 1), невязка баланса.

Оговорка: закон 3 без выталкивания пропускает нити друг сквозь друга, и результат зависит от шага.
Лучший вариант Δε_f стоит повторить на законе 4.
