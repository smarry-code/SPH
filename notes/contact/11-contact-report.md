## 1. Коротко

* **Что внедрено.** Три штрафные контактные силы из статьи — тип 1 «пинбол»
  Белицко, тип 2 Свигла, тип 3 импульсная — плюс тип 0 «контакт выключен».
  Сила действует между двумя частицами **разных материалов**, вдоль линии их
  центров, когда частицы перекрываются.
* **Где.** Формулы — в новом заголовке
  [`include/contact_force.hpp`](../../include/contact_force.hpp) (чистые функции без
  зависимостей). Поиск пар, геометрия и приложение силы — в
  [`src/ext_force.cpp`](../../src/ext_force.cpp), в функции внешних сил. Ограничение
  шага по времени — в [`src/time_integration.cpp`](../../src/time_integration.cpp).
  Ключи конфигурации — в `SimulationConfig` и разборе `Initial_Conditions.txt`.
* **Чем управляется.** Три ключа: `contact_force_type` (0–3),
  `contact_penalty_scale` = $K_p$ (типы 1–2), `contact_impulse_gamma` = $\gamma$
  (тип 3). Косвенно — числом Куранта, длиной сглаживания, шагом решётки,
  модулем сдвига и скоростью звука материалов.
* **Как ведёт себя.** По умолчанию контакт выключен, и расчёт совпадает с
  доконтактным бит в бит. Все четыре типа устойчивы на обоих сквозных кейсах.
* **Что он даёт результату.** На кейсах BC2 и BC6 — почти ничего: пик меняется
  в пределах 0,15 % (BC2) и 2,5 % (BC6). Причина структурная: SPH-суммы между
  материалами не отключены, и границы тел передают напряжение через обычные
  уравнения сохранения; контактная сила лишь добавляется сверху (§9.3).
* **Главные отступления от статьи** (все обоснованы, §6): приведённая масса
  вместо $\varrho R^3$; без множителя $p$ в формуле типа 1; радиус тела из
  объёма частицы, а не $h/2$; потолок силы Свигла; тип 3 на нормальной
  составляющей скорости с долей гашения $\gamma$.

## 2. Что делает контактный алгоритм и зачем он нужен

### 2.1. Проблема

В классическом SPH два тела, пришедшие в соприкосновение, взаимодействуют через
те же суммы по соседям, что и частицы внутри одного тела. Статья называет три
следствия ([`notes/sources/sph-contact-article.md`](../sources/sph-contact-article.md), разд. 1):

* **проникание и перемешивание** — первые один-два ряда частиц проходят друг
  сквозь друга, потому что SPH не требует однозначности поля скоростей
  (частично лечится XSPH-сглаживанием Монагана);
* **силы растяжения**, мешающие телам разойтись;
* **касательные напряжения**, мешающие скольжению без трения.

### 2.2. Решение из статьи

Штрафной метод: если частицы разных тел перекрылись, между ними прикладывается
отталкивающая сила, растущая с глубиной перекрытия $p$ и/или скоростью
сближения $\dot p$. Выбран вариант **«частица–частица»**: каждая частица —
окружность (в 2D) заданного радиуса, контакт — пересечение двух окружностей,
сила — вдоль линии центров. Вариант не требует ни поверхности тела, ни
нормалей, одинаково записывается в 1D, 2D и 3D.

### 2.3. Основные величины

| Величина | Смысл | Формула в коде |
|---|---|---|
| $r$ | расстояние между центрами | $\lVert x_i - x_j\rVert$ |
| $R_i$ | радиус частицы как тела | $\tfrac12\,(m_i/\varrho_{\mathrm{eff}})^{1/\mathrm{dim}}$, $\varrho_{\mathrm{eff}} = \max(\varrho_i, \varrho_{0,i})$ |
| $p$ | глубина проникания | $(R_i + R_j) - r$; контакт при $p > 0$ |
| $\dot p$ | скорость проникания | $-\,(x_i - x_j)\cdot(v_i - v_j)/r$; $>0$ при сближении |
| $m_{ij}$ | приведённая масса | $m_i m_j/(m_i + m_j)$ |
| $c_{ij}$ | скорость звука пары | $\min(c_i, c_j)$ |
| $G_{\mathrm{eff}}$ | эффективный модуль сдвига | $G_i G_j/(G_i + G_j)$; 0, если $G$ неизвестен |
| $R_{\mathrm{eff}}$ | эффективный радиус | $R_i R_j/(R_i + R_j)$ |
| $\Delta t_{\mathrm{ref}}$ | локальный CFL-шаг пары | $\min_{k\in\{i,j\}} \mathrm{CFL}\cdot h_k/(c_k + \lVert v_k\rVert)$ |
| $\Delta t$ | применяемый шаг расчёта | глобальный, из интегратора |

### 2.4. Четыре типа контакта

| Тип | Название | Сила в коде | От чего зависит |
|---|---|---|---|
| 0 | выключен | 0 | — |
| 1 | «пинбол» Белицко | $F = K_p\min(F_1, F_2)$, $F_1 = m_{ij}\dot p/\Delta t_{\mathrm{ref}}$ при $\dot p>0$, иначе 0; $F_2 = G_{\mathrm{eff}}\sqrt{R_{\mathrm{eff}}}\,p^{3/2}$ (Герц) | $p$, $\dot p$, $G$ |
| 2 | Свигл | $F = K_p\min\big(\max(F_1,F_2),\,F_{\mathrm{cap}}\big)$ при $\dot p>0$; $F_1 = m_{ij}p/\Delta t_{\mathrm{ref}}^2$, $F_2 = 2m_{ij}c_{ij}p/(\Delta t_{\mathrm{ref}}\,r)$, $F_{\mathrm{cap}} = m_{ij}\dot p/\Delta t_{\mathrm{ref}}$ | $p$, $\dot p$, $c$ |
| 3 | импульсный | $F = \gamma\,m_{ij}\dot p/\Delta t$ при $\dot p > 0$ | $\dot p$, $\Delta t$ |

Сила всегда **только отталкивает** (при $\dot p \le 0$ у типов 2–3 она равна
нулю; у типа 1 при $\dot p \le 0$ обнуляется $F_1$ и с ней минимум) и
прикладывается к обеим частицам с равными и противоположными импульсами —
импульс пары сохраняется точно.

**Смысл каждой формулы.**
* Тип 1, $F_1$ — сила, останавливающая пару относительно друг друга за шаг
  (идеально пластическое соударение); $F_2$ — упругий контакт двух сфер по
  Герцу. Берётся меньшая: Герц работает при малом проникании, «остановка» —
  при быстром сближении.
* Тип 2, $F_1$ — «вытолкнуть накопленное проникание за один шаг»; $F_2$ —
  «вязкое» приближение через скорость звука (аналог $\sigma = \varrho c v$).
  Берётся большая, но не больше потолка $F_{\mathrm{cap}}$ (§6).
* Тип 3 — сила, гасящая долю $\gamma$ скорости сближения за применяемый шаг.
  Масштабного коэффициента нет.

заготовки; в `ext_force.cpp:179` рядом лежит закомментированная строка
`is_contact_pair_`. На работу не влияет.

## 4. Путь данных за один шаг расчёта

```
Initial_Conditions.txt
   │  parse_sph_config()                      src/input.cpp:341-377
   ▼
SimulationConfig cfg                           include/simulation_config.hpp:35-42
   contact_force_type, contact_penalty_scale, contact_impulse_gamma
   │
   ▼
time_integration()  ── цикл по шагам ─────────────────────────────── src/time_integration.cpp
   │  1. предиктор: v += dt/2·dvx (с прошлого шага)                  стр. 141
   │  2. single_step(..., dt, ..., wb)                               стр. 159
   │        ├─ поиск соседей → список пар (pair_i, pair_j), niac
   │        ├─ int_force, art_visc  (SPH-силы, пары НЕ фильтруются по материалу)
   │        ├─ ext_force(cfg, sys, dt, ntotal+nvirt, ntotal, …, exdvxdt, wb)
   │        │     wb.reset_contact()
   │        │     для каждой пары (i, j):
   │        │        is_contact_material_pair?  разные itype, обе реальные
   │        │        R_i, R_j ← particle_radius;  p = R_i + R_j − r
   │        │        если p > 0:
   │        │           pdot, m_red, c_pair, G_eff, R_eff, dt_ref
   │        │           res = contact::penalty_force(type, g, pr, Kp, dt, γ)
   │        │           dvxdt[i] += F·n/m_i;  dvxdt[j] −= F·n/m_j
   │        │           wb: pair_count++, max_delta, min_dt_contact
   │        └─ dvx = indvxdt + exdvxdt + ardvxdt
   │  3. dt = compute_cfl_timestep();  dt = min(dt, wb.min_dt_contact)   стр. 160-161
   │  4. корректор: v = v_min + dt·dvx + av  (XSPH)                   стр. 255
   ▼
следующий шаг
```

**Важная деталь порядка.** Сила считается в `single_step` с шагом `dt`,
вычисленным **на предыдущем** шаге, а применяется в корректоре с шагом,
пересчитанным **после** `single_step` (стр. 160–161). Для типов 1–2 это не
существенно: их жёсткость строится от $\Delta t_{\mathrm{ref}}$, а не от
применяемого шага. Для типа 3 импульс за шаг равен
$\gamma m_{ij}\dot p\cdot\Delta t_{\mathrm{new}}/\Delta t_{\mathrm{old}}$; на
BC6 шаг при типе 3 меняется от шага к шагу на 0,38 %, так что эффект
пренебрежим (у типа 2, где срабатывает ограничитель, — до 24 %).

**Вторая деталь.** Интегратор — предиктор-корректор: к моменту вычисления силы
скорость уже сдвинута на полшага прошлым ускорением. Для типа 3 это означает,
что сближение гасится как бы в 1,5 раза сильнее заданного: эффективный
коэффициент ≈ $1{,}5\gamma$. Отсюда рабочее $\gamma = 0{,}5$ на BC6 (§8.2).

## 5. Подробно по коду

### 5.1. `include/contact_force.hpp` — математика

**Константы** (стр. 13–16):

| Имя | Значение | Смысл |
|---|---|---|
| `kNoLimit` | `1e30` | «ограничения шага нет»; совместимо с `min()` в интеграторе |
| `kOscSafety` | `0.8` | запас устойчивости явной схемы: $\Delta t\,\omega < 2$ заменено на $0{,}8\cdot 2$ |

**Структуры** (стр. 18–47):

* `ForceType { Off = 0, Pinball = 1, Swegle = 2, Impulse = 3 }`;
* `PairGeom` — геометрия пары: `r`, `p`, `pdot`, `v_rel` (полная
  относительная скорость; справочная, силу не определяет);
* `PairProps` — свойства пары: `m_red`, `c_pair`, `g_eff`, `r_eff`, `dt_ref`;
* `Result` — выход: `fn` (модуль нормальной силы, Н, ≥ 0) и `dt_limit`
  (ограничитель шага, по умолчанию `kNoLimit`).

Функции возвращают только **модуль** силы. Направление и раскладку по осям
делает оркестратор — поэтому заголовок не зависит от размерности задачи.

**`pinball_force` — тип 1** (стр. 51–81):

1. Ранний выход с нулевой силой, если $p \le 0$, $m_{ij} \le 0$,
   $\Delta t_{\mathrm{ref}} \le 0$ или $K_p \le 0$.
2. $F_1 = m_{ij}\dot p/\Delta t_{\mathrm{ref}}$ при $\dot p > 0$, иначе 0.
3. $F_2 = G_{\mathrm{eff}}\sqrt{R_{\mathrm{eff}}}\,p\sqrt p$ — только если
   модуль сдвига известен ($G_{\mathrm{eff}} > 0$). Если нет, $F_2$
   **исключается из минимума**, а не подставляется нулём (иначе
   $\min(F_1, 0) = 0$ обнулил бы контакт — ошибка исходной заявки).
4. $F = K_p\min(F_1, F_2)$ (или $K_p F_1$ без Герца).
5. Ограничитель шага зависит от того, какая ветка активна:
   * Герц ($F_2 < F_1$): жёсткость $k_{\mathrm{eff}} = \mathrm dF/\mathrm dp = 1{,}5F/p$,
     предел $\Delta t_{\mathrm{lim}} = 0{,}8/\sqrt{k_{\mathrm{eff}}/m_{ij}}$;
   * вязкая ($F = c_d\dot p$, $c_d = K_p m_{ij}/\Delta t_{\mathrm{ref}}$):
     $\Delta t_{\mathrm{lim}} = 0{,}8\cdot 2\Delta t_{\mathrm{ref}}/K_p$.

**`swegle_force` — тип 2** (стр. 85–125):

1. Ранний выход при $p \le 0$, $\dot p \le 0$, $r \le 0$, $K_p \le 0$ и т. п.
2. $F_1 = m_{ij}p/\Delta t_{\mathrm{ref}}^2$,
   $F_2 = 2m_{ij}c_{ij}p/(\Delta t_{\mathrm{ref}}\,r)$ — в статье опечатка,
   обе помечены $F_1$ (формулы 2.7–2.8).
3. **Потолок** $F_{\mathrm{cap}} = m_{ij}\dot p/\Delta t_{\mathrm{ref}}$ — сила,
   гасящая сближение за опорный шаг. Итог $F = K_p\min(\max(F_1,F_2),
   F_{\mathrm{cap}})$. Зачем потолок — §6, §7 (дефект «храповик Свигла»).
4. Ограничитель: на потолке — вязкая ветка, как у типа 1,
   $0{,}8\cdot 2\Delta t_{\mathrm{ref}}/K_p$; ниже потолка — линейная пружина
   $k_{\mathrm{eff}} = F/p$, $\Delta t_{\mathrm{lim}} = 0{,}8/\sqrt{k_{\mathrm{eff}}/m_{ij}}$.

**`impulse_force` — тип 3** (стр. 161–179):

1. Ранний выход при $p \le 0$, $\dot p \le 0$, $\Delta t \le 0$, $\gamma \le 0$.
2. $F = \gamma m_{ij}\dot p/\Delta t$, где $\Delta t$ — **применяемый** шаг
   (параметр `dt_applied`, приходит из `ext_force`).
3. Ограничитель вязкой ветки $0{,}8\cdot 2\Delta t/\gamma$: при
   $\gamma \le 1{,}6$ он не строже самого шага и не срабатывает никогда; при
   $\gamma > 1{,}6$ режет шаг, от которого сама сила и зависит, — петля
   «жёсткость → шаг», поэтому $\gamma > 1{,}6$ вне рабочего диапазона.
4. Комментарий в коде (стр. 154–160) фиксирует свойство, которое γ не
   исправляет: приращение скорости за шаг $\Delta v_i = \gamma(m_{ij}/m_i)\dot p$
   от $\Delta t$ не зависит, поэтому тип 3 по шагу не сходится.

**`penalty_force`** (стр. 181–191) — диспетчер по типу; тип 0 и неизвестный
тип дают `Result{}` (сила 0, без ограничения).

### 5.2. `src/ext_force.cpp` — оркестратор

**`is_contact_material_pair(sys, i, j, nreal)`** (стр. 28–32). Пара
контактная, если:
* обе частицы **реальные** ($i, j <$ `nreal`) — зеркальные частицы у оси
  лежат в $[n_{\mathrm{real}}, n_{\mathrm{total}})$ и исключаются;
* у обеих `itype > 0` (не граничные виртуальные);
* материалы **разные** (`itype[i] != itype[j]`).

Почему исключены зеркальные: зеркальная частица — это та же частица,
отражённая относительно оси; пара «реальная + зеркальная» дублировала бы
контакт, реакция на зеркальную терялась бы (её не интегрируют), а счётчики и
ограничитель шага засорялись бы фантомными парами.

Почему «разные материалы»: в `ParticleSystem` нет номера тела — номер детали
из k-файла затирается номером материала при чтении. Отсюда главное
ограничение: **два тела из одного материала контакта не видят** (решение D2,
§10).

**`particle_radius(sys, k)`** (стр. 61–75):
$R = \tfrac12(m/\varrho_{\mathrm{eff}})^{1/\mathrm{dim}}$,
$\varrho_{\mathrm{eff}} = \max(\varrho, \varrho_0)$; при $\varrho \le 0$
возвращает 0 (пара выпадает из контакта). При массе $\varrho_0\Delta x^2$
(2D-кейсы проекта) в покое $R = \Delta x/2$, и соседние частицы касаются
ровно: $p = 0$. Сжатие радиус уменьшает, разрежение — не увеличивает (потолок
по $\varrho_0$, §7).

**`pair_dt_ref(cfg, sys, k)`** (стр. 81–87): тот же критерий Куранта, что у
глобального шага, но для одной частицы:
$\mathrm{CFL}\cdot h_k/(c_k + \lVert v_k\rVert)$. Для пары берётся минимум по
двум частицам. Так как глобальный шаг — минимум по всем частицам,
$\Delta t \le \Delta t_{\mathrm{ref}}$ всегда. Это разрывает петлю
«жёсткость ← шаг ← ограничитель», которая привела бы к коллапсу шага (тест O9).

**Контактная ветка цикла по парам** (стр. 209–265), по шагам:

1. Условие входа: тип ≠ 0 и пара контактная.
2. $\Delta x_{ij} = x_i - x_j$, $r = \lVert\Delta x_{ij}\rVert$.
3. $R_i, R_j$ → $p = R_i + R_j - r$. Дальше только при $r > 0$ и $p > 0$.
4. $\dot p = -\Delta x_{ij}\cdot(v_i - v_j)/r$, $v_{\mathrm{rel}} = \lVert v_i - v_j\rVert$.
5. $G_i, G_j$ из реестра материалов → $G_{\mathrm{eff}}$ (0, если хотя бы один
   неизвестен); $m_{ij}$, $c_{ij}$, $R_{\mathrm{eff}}$, $\Delta t_{\mathrm{ref}}$.
6. `penalty_force(type, g, pr, cfg.contact_penalty_scale, dt, cfg.contact_impulse_gamma)`.
7. Диагностика в `wb`: `contact_pair_count` (пары с $p > 0$, даже если сила
   нулевая), `contact_max_delta` = max $p$, `min_dt_contact` = min `dt_limit`.
8. Сила вдоль $n = \Delta x_{ij}/r$ (от $j$ к $i$), в виде **ускорений**:
   `dvxdt[d][i] += F·n_d/m_i`, `dvxdt[d][j] -= F·n_d/m_j` — точный баланс
   импульса.

В конце `ext_force` проверяет все ускорения на NaN/Inf и бросает исключение.

**Параллелизм.** Контактная ветка выполняется в **последовательном** цикле
(OpenMP в `ext_force` нет), поэтому гонок при записи в `dvxdt` и `wb` нет. По
измерениям на BC6 контакт на стоимость шага заметно не влияет: число шагов у
типов 0/1/3 — 1615/1615/1617; у типа 2 — 1716 (+6 %) из-за ограничителя шага.

## 6. Отступления от первоисточника

| # | В статье | В коде | Почему |
|---|---|---|---|
| 1 | масса пары через $\varrho_k R_k^3$ | $m_{ij} = m_im_j/(m_i+m_j)$ из `sys.mass` | $\varrho R^3 = m$ только в 3D; проект считает в 1D/2D (решение ADR-007) |
| 2 | тип 1: $F = K_p\,p\,\min(F_1,F_2)$ | $F = K_p\min(F_1,F_2)$ | с множителем $p$ размерность Н·м вместо Н (решение D1) |
| 3 | тип 2: обе формулы помечены $F_1$ | вторая — $F_2$ | опечатка; по (2.6) нужны две разные величины |
| 4 | $\Delta t$ в формулах типов 1–2 | локальный $\Delta t_{\mathrm{ref}}$ пары | разрывает петлю «сила → шаг → сила», иначе коллапс шага |
| 5 | тип 1 при неизвестном $G$ | $F_2$ исключается из минимума | иначе $\min(F_1, 0) = 0$ обнуляет контакт |
| 6 | радиус тела $h/2$ | $\tfrac12(m/\max(\varrho,\varrho_0))^{1/\mathrm{dim}}$ | при $h = 2\Delta x$ радиус $h/2 = \Delta x$ объявлял все пары на границах проникшими ещё в покое; тип 2 разваливал расчёт на шаге 124 |
| 7 | тип 2 без ограничения силы | потолок $F_{\mathrm{cap}} = m_{ij}\dot p/\Delta t_{\mathrm{ref}}$ | формула Свигла верна, только если $p$ накоплено за шаг; на фиктивном $p$ сила завышалась в ~6000 раз |
| 8 | тип 3 на $\lVert v_i - v_j\rVert$ | на нормальной составляющей $\dot p$ | с полной скоростью сила разрывна в точке включения и превращает скольжение в отталкивание |
| 9 | тип 3 гасит сближение полностью | доля гашения $\gamma$ | в предиктор-корректоре эффективный коэффициент ≈ $1{,}5\gamma$; при $\gamma = 1$ пила с периодом $2\Delta t$ |
| 10 | ограничитель шага не описан | `dt_limit` у каждого типа, `kOscSafety = 0,8` | устойчивость явной схемы при жёсткой пружине или вязком демпфере |

**Не реализовано из статьи** (сознательно, решение D6): контакт вдоль средней
нормали (2.2) — нет нормалей к свободной поверхности; связь свободной
поверхности с контактом (разд. 2.4) — нет граничных частиц; трение,
тепловыделение.

### 8.2. Почему именно такие диапазоны

**$K_p$.** Ограничитель вязкой ветки типов 1–2 равен
$1{,}6\,\Delta t_{\mathrm{ref}}/K_p$. Так как применяемый шаг не больше
$\Delta t_{\mathrm{ref}}$, при $K_p \le 1{,}6$ ограничитель не срабатывает
никогда; при $K_p > 1{,}6$ он режет шаг **всего** расчёта пропорционально
$K_p$. На ветке Герца предел $\propto 1/\sqrt{K_p}$. Калибровки $K_p$ нет ни в
статье, ни в проекте. Измерено на BC2 (развёртка $K_p$ = 0,5 … 10,
[experiments/2026-09-22-bc2-kp-sweep](../../experiments/2026-09-22-bc2-kp-sweep/)):

| $K_p$ | тип 1: шагов / пик | тип 2: шагов / пик |
|---|---|---|
| 0,5 | 1499 / 985,0 | 1499 / 983,4 |
| 1 | 1499 / 985,0 | 1573 / 983,8 |
| 2 | 1502 / 985,3 | 2038 / 956,5 |
| 4 | 1526 / 945,1 | 3376 / 939,3 |
| 10 | 1522 / 979,7 | 7871 / 889,0 |

Эталонный пик BC2 — 1317,5 м/с. Рост $K_p$ согласие не улучшает, а у типа 2
ухудшает (0,747 → 0,675 эталона) при впятеро большем числе шагов. Разумный
выбор — $K_p = 1$.

**$\gamma$.** Нижняя граница: $\gamma \le 0$ — ранний выход, контакта нет.
Верхняя 1,6 — порог, с которого ограничитель типа 3 начинает резать шаг, от
которого зависит сама сила. Внутри рабочего диапазона качество определяет
предиктор-корректор: эффективный коэффициент ≈ $1{,}5\gamma$, апериодичное
гашение требует $1{,}5\gamma < 1$. Измерено на BC6 (СКО численной ряби кривой
монитора по окнам 2,0–2,5 / 2,5–3,3 / 3,3–4,3 мкс, м/с):

| $\gamma$ | СКО ряби | Автокорреляция, лаг 1 | Характер |
|---|---|---|---|
| 1,00 | 0,934 / 2,189 / 2,592 | −1,00 | пила с периодом $2\Delta t$ |
| **0,50** | 0,306 / 0,197 / 0,148 | +0,83 | уровень расчёта без контакта |
| 0,25 | 0,405 / 0,189 / 0,102 | +0,83 | то же, но контакт слабее |
| контакт выключен | 0,302 / 0,168 / 0,121 | +0,87 | — |

Рекомендуемое значение — 0,5: ближайшее к буквальной формуле статьи, при
котором гашение апериодично.

| `kOscSafety` | 0,8 | `contact_force.hpp:16` | запас устойчивости ограничителя |
| `kNoLimit` | 10³⁰ | `contact_force.hpp:14` | «шаг не ограничен» |
| показатель Герца | 3/2 | `contact_force.hpp:59` | $F_2 \propto p^{3/2}$ |
| множитель в $F_2$ Свигла | 2 | `contact_force.hpp:92` | из (2.8) |

### 8.5. Характерные величины на реальном расчёте

На BC6 при Δx = 0,2 мм наибольшее проникание за весь прогон — 4,9 мкм (2,5 %
от Δx); сила Герца на нём — 0,23 Н при масштабе SPH-сил на фронте 4,2·10⁵ Н.
Это и объясняет, почему контакт почти не меняет результат (§9.3).

### 9.3. Почему контакт почти не влияет на результат

Это не дефект реализации, а устройство модели:

1. **SPH-пары между материалами не отключены.** `int_force` и `art_visc`
   обходят все пары соседей, в том числе через границу тел. Границы передают
   давление и напряжение обычными SPH-суммами — как единый континуум.
2. **Контактная сила добавляется сверху** и срабатывает только при
   перекрытии тел сверх равновесного. На BC6 проникание не превышает 2,5 % от
   Δx, а сила Герца на 6 порядков меньше SPH-сил.
3. **Статья предполагает обратное:** штрафной контакт задуман как **замена**
   взаимодействия через суммы на границе тел (разд. 1, 2.4). Отключение
   SPH-сумм между телами и связка «свободная поверхность + контакт» в эту
   итерацию не входили (решение D6).

Следствие: пока SPH-суммы через границу не выключены, выбор типа контакта
влияет на устойчивость и шум, но не на физику волны.

## 10. Ограничения и известные проблемы

**Ограничения модели** (сознательные, ADR-007):

* два тела **из одного материала** контакта не видят — нет номера тела в
  `ParticleSystem` (решение D2); на BC2 главная граница B4C/B4C невидима;
* сила — вдоль линии центров, без нормали к поверхности (2.2 не реализована);
* нет трения и тепловыделения;
* нет отключения SPH-сумм между телами и связи со свободной поверхностью
  (разд. 2.4 статьи) — поэтому контакт аддитивен (§9.3).

**Свойства отдельных типов:**

* **тип 3 не сходится по шагу** ни при каком $\gamma$: приращение скорости
  за шаг от $\Delta t$ не зависит — это свойство постановки «погасить за
  шаг»;
* **тип 2 шумит**: когерентная пила $2\Delta t$ (СКО 0,53 м/с на BC6), шаг
  меняется от шага к шагу до 24 % из-за ограничителя; не разбиралось;
* **тип 1** на обоих кейсах практически не срабатывает.

**Особенности реализации:**

* сила считается с шагом прошлого шага, применяется с новым (§4); для типа 3
  на BC6 расхождение 0,38 %;
* контактный цикл последовательный — на больших задачах может стать заметным;
* расчёт в целом недетерминирован (порядок суммирования OpenMP в SPH-части):
  после ≈ 1,7 мкс реплики BC6 расходятся до 34 м/с
  ([experiments/2026-09-23-bc6-resolution](../../experiments/2026-09-23-bc6-resolution/)).
  Контакт этого не вызывает, но сравнивать типы после 1,7 мкс по одному
  прогону нельзя.

**Расхождения документации с кодом** (найдены при подготовке отчёта):

* [ADR-007](../../docs/04-explanation/decisions/adr-007-contact-force-types.md)
  называет потолок силы Свигла «отвергнутым вариантом», а в коде он есть с
  `67a04e9`; сигнатура `is_contact_material_pair` в ADR — без `nreal`;
  перечень тестов остановился на M1–M12 / O1–O9. Требует обновления.
* Константа `is_contact_pair` в `param.hpp:270` не используется.
* В `tests/test_contact.cpp` номер O11 носили два разных теста; второй
  (нормальная составляющая типа 3, добавлен в `ed4cd3d`) переименован в
  **O12** при подготовке этого отчёта (правка не закоммичена).

## 11. Как пользоваться: рекомендации

1. **По умолчанию** — `contact_force_type = 0`: контакт на изученных кейсах
   физику не меняет, а расчёт совпадает с доконтактным бит в бит.
2. **Если нужен контакт** — тип 1 ($K_p = 1$): самый «тихий», ограничитель
   шага не срабатывает; на ветке Герца сила от шага не зависит и по шагу
   сходится (на ветке $F_1$, как и тип 3, — нет).
3. **Тип 3** — только с $\gamma < 2/3$ (рекомендуется 0,5); помнить, что по
   шагу он не сходится.
4. **Тип 2** — с осторожностью: дороже на 5–6 % по шагам и шумит.
5. **$K_p$ не поднимать** выше 1,6 без необходимости: режет шаг всего расчёта
   и, по измерениям, согласие с эталоном не улучшает.
6. Для тел **из одного материала** контакт не сработает — нужен номер тела
   (не реализован).
