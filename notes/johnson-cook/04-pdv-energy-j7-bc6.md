## 4. XSPH зависит от шага

n_r = 12, ε = 0.25, ключ `--cfl` (коммит `8639e59`):

| CFL | шагов | D_xsph/E0 | Q_av/E0 | W_plastic/E0 | невязка | L_final/L0 | R_max/R0 |
|---|---|---|---|---|---|---|---|
| 0.1 | 2051 | 12.9 % | 7.4 % | 74.4 % | −0.56 % | 0.912 | 1.178 |
| 0.05 | 3876 | 19.8 % | 6.0 % | 68.2 % | −2.37 % | 0.916 | 1.157 |
| 0.025 | 7126 | 29.5 % | 4.6 % | 59.8 % | −3.22 % | 0.924 | 1.129 |

- При CFL 0.025 тест падает по воротам «e_pl_max > 0.3».
- Причина: `av` прибавляется к скорости на каждом шаге без множителя dt (`ode_solver.hpp:83`: `vx = base + coeff*dv + av`). Поправка XSPH пропорциональна числу шагов.
- Решение владельца: зафиксировать (ADR-009), исправлять отдельной задачей. Исправление меняет все расчёты и эталоны.

## 5. J7a: Тейлор-Куинни

- Ключи в `Initial_Conditions`: `jc_heating = energy | taylor_quinney`, `jc_chi` (по умолчанию 0.9). Применяются к `cfg.mats.jc` в `parse_sph_config`, сверяются при рестарте (`visit_cfg`).
- Режим TQ: T = `sys.T` (состояние), `T += chi·Y·Δε_p/(ρ·c_p)`, `u` не меняется.
- Тест I9: u не меняется, T монотонна, `T − Tr = chi·Σ(Y·Δε_p)/(ρ·c_p)` до 1e-9 (ΔT ≈ 44 К в тесте). При chi = 0 T == Tr.
- Предупреждение при Tm_f ≤ 0: один раз на itype.
- Тест рестарта (`e638823`): сцена itype 12 + TQ, побитовое совпадение. Ограничение: пластина не нагружена (T = Tr), проверяется сохранность T / edot / r0, а не восстановление накопленного нагрева.
- G4 (`cf9133e`): `energy_mass = 2π·r0·m` в `test_axisym`.
- Проверка на сервере (`cf9133e`): быстрые тесты 112/112 в `build1/2/3`; E4 даёт те же числа (TQ по умолчанию выключен).

## 7. BC6: ворота «плато 1» и D = 0

Симптомы полных прогонов: «плато 1» 127.3 м/с при воротах [170; 190] и «D = 0 до разгрузки».

### Причина по плато 1

- Bisect не понадобился. Уже на `d194417` (коммит отчёта `notes/contact/06-e2e-bc6.md`, где записано 182.8 ✔) тест даёт 127.855 при том же пике 198.17 м/с при 0.8832 мкс.
- Виноват извлекатель `tests/e2e_staircase.hpp`: выраженность провала считалась по максимуму справа до конца записи. Хвост невоспроизводим, провал 1 (≈1.53 мкс) не находился, и ступень 1 оказывалась медианой всего хвоста 0.87–4.30 мкс.
- Член pdV на BC6 не влияет: прогоны на `9cfbf86` и `88a3b2f` дали одинаковые 127.305.

### Исправление (`ed5ac88`)

- Левый максимум берётся в пределах периода 0.88 мкс, справа ищется отскок.
- При dips == 0 окно плато от фронта: [t10 + 0.15T, t10 + 0.85T].

### Проверка без расчёта

- Эталон: те же 2 провала, ступени 171.8 / 141.3 / 115.7.
- Кривая типа 0 из SVG отчёта: плато 182.84, провал 141.9 при 1.532 мкс. Устойчиво к опусканию хвоста на 10–25 м/с.
- Типы 1–3 по SVG: 182.84 / 184.85 / 183.03.

### Ворота D = 0

- Не проходили никогда. Причина — угловая частица #11388 у оси и торца: D = 1 при 0.054 мкс, краевой артефакт.
- Решение владельца: оставить жёсткими (как решил автор отчёта, §7.4).
