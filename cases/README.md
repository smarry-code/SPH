# Опытные кейсы

Реестр физических опытов, с которыми сверяется код. Здесь хранятся **только неизменяемые исходные
данные** опыта (эталонные кривые, входные файлы старого кода) и карточка кейса. Числа постановки,
перенесённые в код, живут в `tests/<кейс>_case.hpp` / `tests/<кейс>_geometry.hpp`, параметры
решателя — в `tests/data/<кейс>_initial_conditions.txt`, расчёты нынешнего кода — в
[`experiments/`](../experiments/README.md), рабочие ТЗ и постановки — в [`notes/`](../notes/README.md).

## Правила

- Один кейс — один каталог `cases/<кейс>/`; имя кейса латиницей в нижнем регистре и совпадает со
  словом `<кейс>` в именах каталогов `experiments/ГГГГ-ММ-ДД-<кейс>-<слаг>/` (`bc2`, `bc6`, `guo2019`).
- В каталоге — `README.md` (карточка по шаблону ниже) и, если есть исходные данные, `source/`.
- Файлы `source/` не правятся: это архив опыта. Рабочие копии в формате тестов делаются в
  `tests/data/` (скриптом из `tools/`, если перенос нетривиален).
- Результаты старого кода не хранятся: они остаются в истории git.
- Текст — UTF-8.

### Шаблон карточки

1. **Опыт** — что происходит, материалы.
2. **Источник** — откуда данные, единицы; «не установлен», если неизвестно.
3. **Статус** — `в коде и тестах` / `только исходные данные` / `нет данных`.
4. **Файлы** — что лежит в `source/`.
5. **Код и тесты** — заголовки с числами постановки, цели `ctest`.
6. **Эксперименты** — каталоги `experiments/`.
7. **Постановка** — заметки `notes/`.
