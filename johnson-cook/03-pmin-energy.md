## 1. E3: предел давления p_min

`JcMaterial::p_min` — нижняя граница давления, аналог Autodyn Hydro Pmin.
`eos_jc` ограничивает p ≥ p_min. По умолчанию ограничения нет: значение
−1.01e20 означает «выключено». Для разрушенной частицы, как и раньше, p ≥ 0.

Перебор (`test_e2e_jc_plate --pmin=…`, dx = 10 мкм):

| −2 | 104 частицы, t = 3.22 мкс | −2.31h | 2.72 мкс, +1.2h | PASS |

| −4 | 82, t = 2.79 мкс | −2.31h | 2.61 мкс, −0.4h | PASS |
| −5 | 77, t = 2.81 мкс | −1.92h | 2.61 мкс, −1.9h | PASS |

- С p_min частицы с D = 1 у границы ударник/мишень пропадают: предупреждения о
  разрушении в ударнике и у тыльной поверхности нет ни в одном прогоне от −2 до −6 ГПа.
- Полоса D = 1 широкая, по x0 примерно от 3.5 до 4.4 мм. Её центр стоит в плоскости откола.

## 2. E4: откуда 20 % невязки энергии

### Что проверялось

Гипотеза из `02-e2e.md`: источник невязки — осесимметричная постановка с
«плоской» массой ρ0·dx². Для проверки тест Тейлора считает полную энергию
половины KE + U тремя способами:
- без веса, как `energy_log`;
- с весом r0/R0: масса кольца 2π·r0·m, это физическая энергия;
- с весом текущего r.

Отдельно проверен пропущенный член уравнения энергии (п. 2.2). Для этого
сделан патч, который в коммиты не входит: `~/axi_pdv.patch` на сервере,
worktree `~/SPH_jc_pdv`.

### 2.1. Лог энергии в осесимметрии меряет не физическую энергию

`energy_log` суммирует m·(v²/2 + u) с одинаковым весом всех частиц. При
плоской массе физическая масса частицы равна 2π·r0·m, поэтому сумма без веса
не является сохраняющейся величиной. Каналы лога (D_xsph и другие) тоже
посчитаны без веса. **Эта часть гипотезы подтверждена.** Ворота 2 % по
`energy_log` в осесимметрии сравнивают величину, которая и не должна
сохраняться.

Разбор лога при n_r = 24 (доли E_mech0 на момент останова):

| E_mech − E0 | D_xsph | S_u_clamp | Q_av | W_plastic | residual |
|---|---|---|---|---|---|
| +6.5 % | 15.7 % | 3.8 % | 7.2 % | 88.6 % | 18.4 % |

Невязку почти целиком даёт канал XSPH. В этом решателе XSPH сглаживает саму
скорость (`vx += av`), поэтому он действительно уносит кинетическую энергию, и
она не переходит в u.

### 2.2. В осесимметричном уравнении энергии нет −(p/ρ)·v_r/r

- `finalize_solid` (`include/interactions/solid_sph.hpp:967–1000`) добавляет
  окружной член в уравнение неразрывности (`drho −= ρ·v_r/r`) и в девиаторную
  работу (`szz·ezz`, ezz = v_r/r).
- Работы давления на окружной деформации, −(p/ρ)·v_r/r, в du нет. Парная сумма
  `he` даёт только плоскую дивергенцию.
- В 1D с `nsym` этот член есть (`ode_solver.hpp:262,303`), в 2D осесимметрии его нет.
- Так было и в старом `int_force.cpp`, который `solid_sph.hpp` переносит буквально.
- Следствие: p меняется с окружной деформацией через ρ, а u этого не чувствует.
  Термодинамика нарушена. При радиальном расширении под давлением u
  завышается, а для JC это ещё и завышенная температура T = T_r + u/c_p.

Влияние на физическую энергию (вес r0), XSPH ε = 0.25:

| n_r | исходный | с членом −(p/ρ)·v_r/r |
|---|---|---|
| 6 | −6.8 % | −13.5 % |
| 12 | −0.5 % | −11.6 % |
| 24 | +3.1 % | −9.9 % |

На L_final и R_max член почти не влияет: изменения меньше 0.05 % и 0.5 %.

### 2.3. Есть ещё один источник энергии, его маскирует XSPH

Физическая энергия при n_r = 12 и разной константе XSPH ε:

| ε | исходный | с членом −(p/ρ)·v_r/r |
|---|---|---|
| 0.25 | −0.5 % | −11.6 % |
| 0.10 | +7.8 % | −1.5 % |
| 0.05 | +12.9 % | +6.2 % |

- XSPH уносит энергию: чем меньше ε, тем выше итог.
- Даже с исправленным уравнением энергии при малом ε энергия растёт (+6 %).
  Значит, есть ещё один источник, при ε = 0.25 его гасит XSPH.
- В исходной схеме почти нулевой итог −0.5 % при n_r = 12 — случайное
  взаимное погашение трёх эффектов, а не признак консервативности.
- Вероятный кандидат — та же плоская масса. При постоянной m объём частицы m/ρ
  равен геометрической площади, умноженной на r/r0. У расширившегося торца
  (R/R0 ≈ 1.2) SPH-суммы завышают вклад частиц примерно на 20 %.
- **Это не доказано:** для проверки нужна другая формулировка, с массой на
  радиан m = ρ0·r0·dx² и суммами с 1/r.
- При ε = 0.05 ворота E4 «максимум e_pl у торца» не проходят (z = 3.1h).

### Выводы

1. Невязка 20 % складывается из трёх частей:
   - лог считает энергию без веса r0, хотя физическая энергия кольца пропорциональна r0;
   - XSPH реально рассеивает 10–15 % кинетической энергии;
   - в осесимметричном уравнении энергии нет −(p/ρ)·v_r/r.

   Кроме того, остаётся неопознанный источник энергии, заметный при малом XSPH.
2. Исходная гипотеза («плоская масса») подтверждена только для измерения
   энергии. Найдена и конкретная ошибка: пропущенный член.
3. Исправление члена меняет все 2D осесимметричные расчёты, в том числе
   эталоны регрессии BC2/BC6 и `test_axisym`. Поэтому оно не закоммичено,
   решение за владельцем. Патч из одной строки лежит в `~/axi_pdv.patch`.
4. Ворота E4 по энергии остаются в режиме «только предупреждение». Чтобы
   проверять баланс честно, лог в осесимметрии должен взвешивать энергии и
   каналы массой кольца (r0).
