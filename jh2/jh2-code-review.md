## 1. Пластическая деформация: действительно ошибка

### Что делает код
1. После радиального возврата (`sys.s*` масштабируются на `corr`) копии `sxx…` хранят напряжения до возврата, т.е. пробные (trial).
2. `dsx = (s_после − s_пробное)/dt` — это только скорость коррекции, а не скорость изменения напряжения за шаг.
3. «Упругая скорость деформации»: `eps_e_x = dsx/gem + eps_vol`.
4. `eps_p = exx − eps_e`, затем `eps_i_f` — эквивалентная скорость, `D += eps_i_f*dt/znam`.

### Почему неверно
Правильное приращение при радиальном возврате (Wilkins): Δε^p_ij = (s^trial_ij − s^new_ij)/(2G). Тензор упругой девиаторной деформации — это s/(2G), а не s/G. Кроме того, `exx − ds_корр/G`: полная скорость деформации вычитается из коррекции, которая уже содержит ее упругую часть. Если бы использовалась полная скорость напряжения (s_новое − s_предыдущего шага)/dt, то `exx − ṡ/(2G)` было бы верно. Здесь же использован вычет, и итог неверен.

Проблемы по пунктам:
- `dsx/gem` — нужно `/(2*gem)` (в самом коде, `int_force.cpp:659`, девиатор считается как `2G·e`).
- `dsx` — приращение только за счёт возврата, а не за шаг.
- `eps_vol = +drho/(3ρ)`: скорость объёмной деформации равна `−ρ̇/ρ`, знак обратный. На `eps_i_f` не влияет (диагональные компоненты входят только разностями), но вводит в заблуждение.
- Вращательные члены Яуманна (`2(sxy·rxy…)`) вычитаются из коррекции, хотя они — часть полной скорости напряжения.

### Численная проверка (1D, идеальная пластичность)
Стресс остаётся на поверхности, значит вся девиаторная деформация пластическая. Скрипт: `G=197 ГПа, ε̇=1e4 1/с, dt=1 нс`.
Код даёт эквивалентную скорость пластической деформации 17 778 1/с, правильное значение 4 444 1/с. **Завышение ровно в 4 раза**, повреждение набирается в 4 раза быстрее, чем следует по уравнениям (7)–(8) статьи. (Для 2D/3D чисто сдвигового нагружения коэффициент другой, но тоже >1.) При вязкопластическом переходе (стресс растет, пока идёт пластика) ошибка нерегулярна.

### Как исправить
Радиальный возврат даёт замкнутую формулу, тензорные компоненты не нужны:

```
sig_eq_trial = sqrt(3*J2_trial)          // J2 до возврата
sig_eq_new   = sqrt(3)*smizm_new/…        // = sigt (предел текучести)
d_eps_p_eq   = (sig_eq_trial - sigt) / (3*G)    // приращение, не скорость
D   += d_eps_p_eq / ε_f(P*)
e_pl+= d_eps_p_eq
```

Проверка в 1D: (σ_trial − σ_y)/(3G) = 2G·ε̇dt/(3G) = (2/3)ε̇dt — совпадает с эталоном. Это сразу убирает `rxy…`, `eps_vol` и `eps_e_*`.

## 2. Разрыхление: размерность и порядок в энергии

Эталон (J&H 1999, (11)–(14), файл `01-podrobny-pereskaz-ru.md`):
U = σ²/(6G), ΔU = U(D_t) − U(D_{t+Δt}), ΔP_{t+Δt} = −K1·μ + √((K1·μ + ΔP_t)² + 2βK1ΔU).

Код:
```
ripl = sqrt(sigma_i(...))            // = sqrt(J2), Па
u0   = 2*ripl/(6*gem)                // безразмерно
u1   = 2*sigma_i(...)/(6*gem)        // J2/G, Па
du   = u0 - u1
```
- `u0` линейно по `√J2` и безразмерна, `u1` квадратична и в Па. Сравнивать их нельзя.
- Верно U = σ_eq²/(6G) = 3·J2/(6G) = J2/(2G). Код имеет и лишний множитель 2, и неверную степень.
- Численно `u0 ≈ 1e-3…1e-2` (безразмерно), `u1` для B4C при J2 ~1e18 Па² — порядка 1e6 Па, поэтому `du = u0 − u1 < 0` почти всегда, условие `du > 0` не выполняется, `dp` не растёт. Разрыхление фактически выключено, модель ведёт себя как JH-2 без bulking.
- Дополнительно: условие `fabs(ds_1) >= fabs(ds_2)` вокруг присваивания `dp` не имеет оснований в (14): формула применима всегда.

## 3. Логика ΔU и накопление `dp`

- В (12) ΔU — потеря упругой энергии при **росте повреждения** при фиксированных P и ε̇, т.е. U(σ(D_t)) − U(σ(D_{t+Δt})). Код берёт разность между пробным напряжением и напряжением после возврата. Это вся работа пластики за шаг, она не связана с D и ненулевая даже для цельной керамики (D=0).
- `dp` обновляется при любом D, но в `urs_cem_JH2` применяется только при `D ≠ 0`. При первом появлении D>0 накопленное значение внезапно включается в давление.
- Рекомендация: считать `du` в `prochnost_cem_JH2` как `σ_eq(D_old)² − σ_eq(D_new)²)/(6G)` и обновлять `dp` только при `D_new > D_old`.

## 4. `sigma_i` для плоского случая

`dim==2`, не осесимметричный: `return sxx²+sxy²`. J2 в плоской деформации с `szz = −(sxx+syy)` равно `sxx²+sxx·syy+syy²+sxy²` (как в осесимметричной ветке). Формула кода верна только при `syy = −sxx, szz=0` (чистый сдвиг). Затрагивает также `prochnost_mises`. Для `dim==1` (по умолчанию в `param.hpp`) формула `0.75·sxx²` верна. Другие значения `dim` — функция без `return`, поведение не определено.

## 5. Что проверено и верно
- Нормировка и поверхности: σ_i = σ_HEL·A·(P*+T*)^N, σ_f = σ_HEL·B·P*^M, ограничение σ_f ≤ SFMAX·σ_HEL, σ = σ_i − D(σ_i − σ_f) — соответствуют (3)–(6) статьи. Множитель (1 + C·ln ε̇*) применён после повреждения ко всему σ, что эквивалентно применению к σ_i и σ_f по отдельности.
- Эквивалентная скорость деформации `eps_i = (√2/3)·√((Δ)²…+6γ²)` — верный вид для тензорных компонент.
- При P*+T* ≤ 0: σ_i = 0, D=1 — разумно.
- Константы B4C (`const_JH_2[0]`): совпадают с таблицей J&H 1999 (ρ 2510, G 197, HEL-компоненты, A 0,927, N 0,67, B 0,70, M 0,85, C 0,005, SFMAX 0,2, D1 0,001, D2 0,5, K1 233, K2 −593, K3 2800 ГПа, T 0,26 ГПа, T_n = 0,26/8,71 = 0,0299).
- Радиальный возврат масштабированием девиатора на `σ_y/σ_eq` корректен; `σ_y²/3` против J2 соответствует σ_eq = √(3J2).
- УРС: гидростата K1μ+K2μ²+K3μ³, отсечка растяжения `−T(1−D)`, скорость звука — в целом корректны.

## 6. Замечания

1. Скоростной член: при ε̇ < 1 с⁻¹ множитель 1 + C·ln ε̇* < 1 снижает прочность. В статье и в описании Cronin и др. (2003) ограничения для ε̇ < ε̇0 нет, так что код следует оригиналу; но практический вариант — ограничить `ε̇* = max(ε̇/ε̇0, 1)`, иначе квазистатический режим даёт заниженную прочность (это инженерное решение, а не требование модели). Положение ε̇0 = 1 с⁻¹ требует, чтобы время в коде было в секундах.
2. Деформация разрушения `ε_f = D1(P*+T*)^D2` без нижней границы: при P*+T* → 0 деление на малое число, D может мгновенно выскочить к 1. Оригинал и реализация Cronin и др. нижней границы тоже не вводят, так что это замечание о численной устойчивости, а не об отклонении от модели.
3. Строка `const_JH_2[1]` (Al2O3): `T = 0,2 ГПа`, `T_n = 0,137`, `P_hel = 2,626 ГПа`. Для набора AD-995 (J&H 1994, см. [пример в документации Radioss law 79](https://help.altair.com/hwsolvers/rad/topics/solvers/rad/mat_law79_john_holm_starter_r.htm): T = 0,2 ГПа, P_HEL = 1,46 ГПа, A 0,93, B 0,31, K1 131 ГПа) T* = 0,2/1,46 = 0,137, то есть `T_n` взято оттуда, а `P_hel`, `σ_hel`, `G`, `B`, `K1`, `ρ` в строке — из другого, не установленного набора. При P_hel = 2,626 ГПа T* должно быть 0,076. Строка смешанная и требует проверки источника.
4. D накапливается только на шагах с текучестью (`flag_e == false`) — приемлемо, но при уменьшении σ_y из-за падения давления без прироста деформации D не меняется; это соответствует определению (7).
5. `e_pl` (накопленная пластическая деформация) после исправления п. 1 станет физически осмысленной величиной для вывода.

## Предложенный порядок правок
1. Заменить блок вычисления `eps_p*` на формулу `(σ_trial − σ_y)/(3G)` (п. 1).
2. Переписать `du`: `U(D_old) − U(D_new)` по `σ²/(6G)`, убрать условие с `fabs`, обновлять `dp` только если D вырос и `mu ≥ 0` (пп. 2–3).
3. Исправить `sigma_i` для плоского случая (п. 4).
4. Проверочный тест: одноэлементный счёт на 1D-деформацию из статьи (рис. 8 J&H 1999) — после правок кривая «напряжение–объёмная деформация» должна показать излом при HEL и рост давления из-за разрыхления.
