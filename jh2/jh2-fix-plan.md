## Этап C. Разрыхление (`ppochnost.cpp:122-137`)

Вынести расчёт предела в функцию (чтобы вызывать с разными D):
```
// возвращает σ_eq (Па) для заданных P*, D, ε̇ (без ограничения до текучести)
double jh2_strength(const double* c /*const_JH_2[nmat]*/, double P_n, double D, double eps_rate);
```
Использовать в начале функции (для `sigt` с `D_old`) и здесь для `D_new`.

1. Сохранить `D_old` до обновления D (этап B); после обновления `D_new = sys.D[i]`.
2. Если `D_new > D_old` и `mu >= 0` (оставить условие, оно уже есть в коде; в оригинале ограничения по μ нет — зафиксировать как осознанное решение):
   ```
   double s_old = jh2_strength(c, P_n, D_old, eps_i);
   double s_new = jh2_strength(c, P_n, D_new, eps_i);
   double dU = (s_old*s_old - s_new*s_new) / (6.0*gem);   // >= 0
   double K1mu = K1*mu;
   sys.dp[i] = -K1mu + sqrt((K1mu + sys.dp[i])*(K1mu + sys.dp[i]) + 2.0*beta_JH*K1*dU);
   ```
   Условие `fabs(ds_1) >= fabs(ds_2)` убрать. Формула — (14) в J&H 1999 и ΔU по Cronin и др. (2003).
3. Удалить `u0, u1, du`.
4. Порядок вызовов в шаге: сначала D (этап B), затем dp (этап C); в `urs_cem_JH2` (`eos.cpp:76+`) менять ничего не нужно (при D=0 `dp` не используется, а после этапа C без роста D он остаётся 0).

6. `P_n` в `jh2_strength` брать тот же, что в начале шага (`sys.p[i]/P_hel`, включает прежний `dp`).

## Этап D. Прочее (по решению владельца; отдельные коммиты)

- D1. Ограничить `ε̇* = max(ε̇/ε̇0, 1)` (строки 97–100). Не требуется оригиналом, поэтому за флагом/константой `jh2_clamp_low_rate` в `materials.hpp`, по умолчанию выключено — уточнить у владельца.
- D2. Нижняя граница `ε_f` (`EFMIN`) — опционально, по умолчанию 0 (поведение оригинала).
- D3. `materials.hpp`, `const_JH_2[1]` (Al2O3): строка, вероятно, **смешанная из двух наборов**. Литературный набор AD-995 (J&H 1994; пример в документации Altair Radioss law 79: ρ 3700–3890, G 90,16 ГПа, A 0,93, B 0,31, M 0,6, N 0,6, C 0, **T = 0,2 ГПа**, HEL 2,79 ГПа, **P_HEL = 1,46 ГПа**, D1 0,005, D2 1,0, K1 130,95 ГПа, K2 = K3 = 0, β 1) даёт T* = 0,2/1,46 = **0,137** — ровно то значение `T_n`, что стоит в коде. А в коде P_hel = 2,626 ГПа, σ_hel = 3,561 ГПа, G = 116,5 ГПа, B = 0,11, K1 = 169,2 ГПа, ρ = 3555 — их в найденных источниках нет (другой набор, источник не установлен). Итог: `T = 0,2 ГПа` верно для AD-995, а `T_n = 0,137` согласовано с ним только при P_hel = 1,46 ГПа; при P_hel = 2,626 ГПа получится T* = 0,076.
  Действия: (1) выяснить у владельца источник строки `const_JH_2[1]`; (2) если это AD-995 — заменить на проверенный набор целиком; если другой материал — найти его T и пересчитать `T_n = T/P_hel`; (3) в любом случае убрать дублирование: вычислять `T_n` из `T` и `P_hel` в коде, а не хранить вручную.
