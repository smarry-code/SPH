# SPH — Симулятор гидродинамики сглаженных частиц

Вычислительный код на C++20/OpenMP для моделирования ударно-волновых процессов,
высокоскоростного соударения и поведения керамических/металлических материалов
методом сглаженных частиц (SPH).

## Быстрый старт

```bash
# Настройка и сборка (требуется Clang, CMake 3.16+, Ninja)
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build

# Запуск первого расчёта (ударная труба)
./build/SPH
```

Подробности — в [Быстром старте](docs/01-tutorials/01-quick-start.md).

## Документация

Полная документация проекта находится в каталоге [`docs/`](docs/). Локальный
просмотр сайта документации:

```bash
pip install -r requirements-docs.txt
mkdocs serve
```

Сайт будет доступен по адресу <http://127.0.0.1:8000>.

## Структура репозитория

```

├── include/    # Заголовочные файлы (.hpp)

```
