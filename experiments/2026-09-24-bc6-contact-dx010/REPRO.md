## 4. Команды

```bash
# 1. сборка на коммите из п. 2
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target test_e2e_bc6

# 2. три типа на одной машине, по 4 потока
cd experiments/2026-09-24-bc6-contact-dx010
printf '%s\n' "0 1.0e-4" "1 1.0e-4" "2 1.0e-4" > data/todo_local.txt
OMP_NUM_THREADS=4 xargs -P 3 -a data/todo_local.txt -n 2 bash scripts/one.sh

# 3. тип 3 — на второй машине (или там же, последовательно)
OMP_NUM_THREADS=8 bash scripts/one.sh 3 1.0e-4

# 4. график: наложить патч 01, пересобрать, собрать из выгрузок
git apply repro/01-plot-from-delta-x-label.patch
cmake --build build --target test_e2e_bc6
build/test_e2e_bc6 --full --delta-x=1e-4 --plot-from=experiments/2026-09-24-bc6-contact-dx010/data \
    --emit-plot=experiments/2026-09-24-bc6-contact-dx010/bc6_monitor_velocity_dx010.svg

# 5. метрики (сравнение с 0,2 мм требует build/bc6_curves от цели bc6_plot)
python experiments/2026-09-24-bc6-contact-dx010/scripts/metrics.py
```

`scripts/one.sh <тип> <Δx, м>` запускает
`test_e2e_bc6 --full --contact-type=<тип> --delta-x=<Δx> --time-limit=$SPH_TIME_LIMIT
--emit-curve=data/bc6_curve_<тип>.txt` и пишет лог `data/run_bc6_curve_<тип>.log`
со стенным временем, кодом возврата и именем машины в конце. Имена выгрузок
совпадают с теми, что ищет `--plot-from`.

## 6. Проверка повтора

Должно совпасть до десятых (часть кривой до ≈ 1,16 мкс, где реплики при
0,1 мм совпадают): фронт 10–90 % 141,7 нс у типов 0–1, 144,2 у типа 2,
140,3 у типа 3; отход типов 2 и 3 от типа 0 больше 0,1 м/с — при
0,55–0,59 мкс. Пики (достигаются около 0,85 мкс) — тоже.

Повторяться **не обязаны**: всё после ≈ 1,27 мкс, моменты обрыва и сам факт
обрыва — при этой сетке тип 0 в stage A оборвался, а здесь дошёл до конца.
