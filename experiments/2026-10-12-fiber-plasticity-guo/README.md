# Guo 2019, 1T, уровень `scaled`: упругая нить против упруго-пластичной (Т16)

- **Дата:** 2026-10-12. Ветка `plastic` (не закоммичено). Драйвер: `tests/test_fiber_plasticity_guo.cpp`.
- **Важно:** параметры пластики ИЛЛЮСТРАТИВНЫЕ, заданы относительно материала сцены (twaron: E = 85 ГПа, eps_break = 0.03): `SY = 0.2·E·eps_break_сцены = 510 МПа` (ε_y = 0.6 %), `H = 0.1·E = 8.5 ГПа` (SY и H одинаковы в обоих вариантах eps_break, считаются от 0.03). Не откалиброваны. Экспериментальных данных Guo для пластической модели нет, сравнение с опытом не делается; только качественное «упругая против пластичной».
- Постановка сцены -- как в `experiments/2026-10-01-guo2019-1t-scaled/README.md` (шар 6 мм, 1.75 г, V0 = 76 м/с, окно 26x26 нитей). Пластика включена директивой `.fib` (`PLASTIC 0 SY=... H=...`), разобранной `load_fiber_file`.
- Запуск (пара «упругая + пластичная», ~4.5-6 мин на прогон при 6 потоках): `OMP_NUM_THREADS=6 test_fiber_plasticity_guo --config=1T --level=scaled --v0=76 --t-max=5e-4 [--eps-break-p=0.06] [--eps-break-e=0.06] --out=<каталог>`. `--eps-break-p` задаёт eps_break пластичной нити, `--eps-break-e` -- упругой (контроль), `--only=elastic|plastic` -- один прогон из пары (добавлен уже после серии; все прогоны ниже сделаны парами, лишний член пары использован как повтор).
- **Остановка по исходу.** Прогон прерывается при определении исхода (`stop_on_outcome`, пробитие), поэтому у каждого прогона свой `t_end`. **V_R и «KE потеряно» -- значения на момент детектирования пробития**, а не на общий момент времени; для сравнения «кто больше поглотил» они приблизительны (после детектирования шар мог бы ещё терять энергию). Для прогона без пробития (упругая, eps_break = 0.06) приведено состояние на t_max.
- **Разброс OpenMP.** Расчёт с OpenMP побитово не воспроизводится. Повторы одной постановки: упругая 0.03 (3 прогона) V_R = 59.289, 59.073, 59.117 м/с (размах 0.22, 0.4 %); пластичная 0.03 (2) V_R = 64.94, 64.01 (размах 0.93, 1.4 %; разрывов 11 и 9); пластичная 0.06 (2) V_R = 58.49, 58.62 (размах 0.13). Наибольший наблюдаемый размах -- 0.93 м/с по V_R, 0.11 Дж по «KE потеряно», 2 по числу разрывов. Различия порядка 1-3 таких размахов значимыми не считаются («значимость не установлена»); оценка по 2-3 повторам грубая. Сравнения ниже -- только при одинаковом eps_break.

## Выводы

1. Проход работает на боевой сцене; ничего не взорвалось, число шагов выросло на 16-34 % (шар глубже вытягивает ткань, dt не ужесточился).
2. Пиковое напряжение в нити падает в 3.7 раза при eps_break = 0.03 (695 против 2549 МПа) и в 5.5 раза при 0.06 (927 против 5097 МПа); реакция заделки -- в 3.3 и 3.6 раза; W_p > 0 (0.3-0.68 Дж, 6-13 % начальной энергии шара). Это ожидаемо.
3. **При одинаковом eps_break пластичная нить шар задерживает хуже упругой.**
   - eps_break = 0.03: V_R пластичной 64.0-64.9 м/с против 59.1-59.3 у упругой, KE потеряно 1.36-1.47 против 1.98-2.00 Дж; разница V_R 4.7-5.9 м/с в 5-6 раз больше наблюдаемого размаха пластичной (0.93) и более чем в 20 раз -- упругой (0.22), то есть различие превышает разброс; разрывов у пластичной больше (9-11 против 7-8).
   - eps_break = 0.06: упругая нить за 500 мкс шар не пропустила (v_z упал до -10.6 м/с, к t_max потеряно 4.96 Дж = 98 %; пробитие не детектировано), пластичная пробита с V_R = 58.5-58.6 м/с (потеряно 2.05-2.06 Дж на момент пробития, разрывов 4). Прямого V_R для упругой нет, но качественное различие большое. Прогон упругой без пробития один (850 с), повтора нет.
4. **Прежняя формулировка «пластичная с eps_break = 0.06 держит чуть лучше упругой (2.06 против 2.00 Дж)» снята:** она сравнивала разные eps_break (0.06 пластичная против 0.03 упругая); при одинаковом eps_break = 0.06 упругая заметно лучше. Сама разница 58.5 против 59.1-59.3 м/с (пластичная 0.06 против упругой 0.03) лежит внутри размаха разброса, значимость не установлена.
5. Пластичная нить с eps_break = 0.06 держит лучше пластичной с 0.03 (V_R 58.5-58.6 против 64.0-64.9, разница 6-7 размахов; разрывов 4 против 9-11). Практический вывод: при включении PLASTIC `eps_break` нужно пересматривать (дизайн, раздел 6).
6. **Гипотеза (прогонами не проверена):** причина -- меньшая работа до разрыва на единицу объёма. Арифметическая оценка по параметрам (ε_p из формулы возврата, σ = SY + H·ε_p): упругая 0.5·E·eps_break² = 38 МДж/м³ (0.03) и 153 МДж/м³ (0.06), пластичная ~16 и ~40 МДж/м³. Связь этого с V_R не доказана; утверждение, что пластичная нить «рвётся раньше», данными не подтверждается (времён разрывов нет): известно только, что при eps_break = 0.03 разрывов у пластичной больше, при 0.06 -- меньше.
7. Энергетический монитор Guo (`E_tot` в `monitor.csv`) в этих прогонах для пластичной нити непригоден: данные получены до правки `clamp_e2e::bond_energy`, которая раньше считала 0.5·E·A·l0·ε² без вычитания ε_p (U_b завышена). Функция теперь исправлена (вычет ε_p, пружина Максвелла), но баланс монитора по-прежнему не учитывает ΣW_p + ΣW_v (нужна правка `guo2019_monitor.hpp`, отложена до слияния с Guo2T). W_p и KE шара здесь взяты из наблюдателя драйвера и монитора шара; баланс E_tot не анализировался.
