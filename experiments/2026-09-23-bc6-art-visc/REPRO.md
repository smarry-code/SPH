## 4. Команды

```bash
python -m zipfile -e experiments/2026-09-23-bc6-art-visc/repro-diff.zip repro/
git apply repro/01-bc6-alpha-env-override.patch
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target test_e2e_bc6

cd experiments/2026-09-23-bc6-art-visc
OMP_NUM_THREADS=6 xargs -P 2 -a data/todo.txt -n 3 bash scripts/one.sh
cd ../..

git apply -R repro/01-bc6-alpha-env-override.patch
cmake --build build --target test_e2e_bc6

python experiments/2026-09-23-bc6-art-visc/scripts/fig.py
```

`scripts/one.sh <α> <Δx, м> <тег>` запускает
`SPH_BC6_ALPHA=<α> build/test_e2e_bc6[.exe] --full --contact-type=0
--delta-x=<Δx> --time-limit=$SPH_TIME_LIMIT --emit-curve=data/curve_<тег>.txt`,
пишет лог в `data/run_<тег>.log`, дописывает стенное время, код возврата, α и
Δx, и сверяет значение α из лога с заданным как число; без совпадения кривая
переименовывается в `INVALID_curve_<тег>.txt`, код 3.

Кривая α = 1,0 (`data/curve_a100_dx020.txt`) — копия `data/curve_dx020.txt`
из [2026-09-23-bc6-resolution](../2026-09-23-bc6-resolution/).

## 6. Проверка повтора

`python scripts/fig.py` печатает в первой таблице (α, шагов, обрыв, t конца,
фронт 10–90, доля, сдвиг t50, выброс, размах, плато):

```
 1.00    1615     0    4.302          185.5        1.000           0.0   198.2    16.1               190.2
 0.50    1616     0    4.301          166.5        0.897           6.1   200.6    18.5               187.4
 0.25    1618     0    4.302          155.7        0.839           9.6   203.1    21.4               185.8
```

и `q = 0.13`. Эти величины лежат раньше 1,7 мкс, где при α = 1 реплики
совпадают с точностью печати, и должны повторяться до десятых; число шагов —
с точностью до единиц. Столбцы «отход» и всё после 1,7 мкс повторяться не
обязаны.
