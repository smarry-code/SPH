## Вопрос

Сценарий с `contact_force_type = 2` обрывался на шаге 1666 (94,2 % расчёта):

```
int_force: некорректная частица 29 (rho=-81.677053, mass=0.000026, itype=8)
```

Типы 1 и 3 проходили целиком. Требовалось **различить числами** четыре
конкурирующие гипотезы, а не осмотреть код: H1 — осевой член неразрывности,
H2 — несимметричный контакт у оси, H3 — жёсткость Свигла без потолка,
H4 — контакт ни при чём.

## Постановка

Четыре полных прогона с `--keep-workdir`, разбор кадров по частице 29
(приосевой узел полиуретанового ударника, `itype = 8`, граница с летящей
керамикой), офлайн-реконструкция контактных пар по кадру и, поскольку кадров
не хватило, **временная пошаговая инструментация** по `r`, `v_r`, `rho`, вкладу
осевого члена и счётчикам `wb.contact_*`. Инструментация откачена, в
репозиторий не попала.

## Результат

**Подтверждена H3 — храповик штрафной силы Свигла на фиктивном проникании.**
Цепочка, каждое звено измерено:

1. разгрузка полиуретана роняет плотность 640 → 45 кг/м³;
2. `particle_radius = 0,5·(m/ρ)^(1/dim)` раздувает радиус тела
   1,0·10⁻⁴ → 3,8·10⁻⁴ м;
3. «проникание» `p` растёт до 1,66·10⁻⁴ м — **при том что тела расходятся**:
   расстояние между центрами идёт 1,98·10⁻⁴ → 2,86·10⁻⁴ м;
4. `swegle_force` даёт `F1 = m_red·p/dt_ref²` до 4,5·10⁸ Н;
5. гейт `pdot > 0` делает силу односторонней: Δ`v_z` до −34 750 м/с за один шаг,
   `drho` = −7,7·10¹⁰, плотность уходит в минус.

Ограничитель шага у Свигла при активной ветви `f1` **тождественно** равен
`0,8·dt_ref` (из `k_eff = fn/p = m_red/dt_ref²`), то есть от величины силы не
зависит и не защищает.

**Опровергнуты числами:**

| Гипотеза | Чем опровергнута |
|---|---|
| H1 — осевой член неразрывности | `r` частицы только растёт: 9,99·10⁻⁵ → 2,06·10⁻⁴ м, к оси не идёт; осевой член даёт ≤ 1 % от `drho` |
| H2 — несимметричный контакт у оси | радиальная составляющая ~3 % от осевой и знаком **наружу**; зеркальный партнёр ни в одном кадре не попадает в зону контакта, значит коммит `6260128` непричастен |
| H4 — контакт ни при чём | тела действительно расходятся, но контакт всё равно срабатывает 652 раза |

**Раздувание радиуса под разгрузкой общее для всех типов** (max `p`: 7,6·10⁻⁵
тип 1, 1,66·10⁻⁴ тип 2, 5,1·10⁻⁵ тип 3). Типы различает только преобразование
`p` в силу: 1,96 Н / 4,5·10⁸ Н / 1,4·10⁶ Н.

## Вывод

Обрыв к осесимметрии отношения не имеет. Правка должна ограничивать **импульс**
силы типа 2, а не трогать ось. Внесена коммитом `67a04e9` («потолок силы Свигла
и радиуса тела») — после неё все четыре сценария доходят до `t_total`.

## Что осталось неясным

Сам **критерий проникания через `particle_radius`** остаётся сомнительным: под
сильной разгрузкой радиус тела растёт быстрее, чем расходятся центры, и контакт
видит проникание там, где его нет. Потолок это симптоматически лечит, но вопроса
не снимает. В списке кандидатов `contact/10-debug-handoff.md` §6 такого пункта
нет — он добавлен по итогам диагностики.
