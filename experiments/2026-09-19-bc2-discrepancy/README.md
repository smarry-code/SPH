## Вопрос

End-to-end тест расходится с приборным эталоном двумя способами сразу: волна
приходит к монитору **на ~1,09 мкс раньше**, а пик составляет **1002 м/с против
1317,5** (на 24 % ниже). Откуда каждое из двух расхождений и какое из них
объясняется кодом?

## Постановка

Один базовый прогон: `contact_force_type = 0`, `delta_x = 2·10⁻⁴` м,
34 163 частицы, 1575 шагов. Измерения — по кадрам `sph_output_*.txt`, без
изменений кода. Прогон контактной подсистемой не затронут, поэтому результат не
зависит от правок контакта, шедших параллельно.

## Результат

**Что расчёт делает правильно.** Скорость поршня симметричного удара B4C/B4C
получается 1100 м/с против теоретических `2210/2 = 1105`. Ударное состояние
керамики — ρ = 2847, P = 26,3 ГПа, c = 9336 м/с — сходится с полиномом JH-2.
Ударно-волновая часть постановки верна.

**Фазовый сдвиг.** Кодом объясняется только **0,18 мкс из 1,09**: дискретизация
`grid_count` даёт узлы `z_lo + i·Δx`, из-за чего между летящей и покоящейся
керамикой возникает зазор 0,917 мм, а толщина летящей пластины падает с
3,917 до 3,600 мм (−8 %). Оставшиеся ~0,9 мкс кодом не объясняются и, судя по
всему, лежат в начале отсчёта времени эталона.

**Амплитуда.** На тот момент отнесена к недостатку разрешения: фронт
размазывается сильнее, чем длится сам импульс.

## Вывод

Два расхождения имеют **разную природу и разбираются порознь**. Фазовый сдвиг —
дефект переноса геометрии (зазоры и толщина от `grid_count`), он устраним и
позднее устранён сборкой встык. Недобор амплитуды — содержательный, к геометрии
не сводится.

Документ породил список вопросов к статье-источнику (§5) и три проверяемых
следствия (§6) — именно они задали программу следующих экспериментов.

## Что устарело

Главное следствие §6 — «прогон с Δx = 0,1 мм поднимет пик и сократит время
нарастания примерно вдвое» — **опровергнуто** в
[2026-09-22-bc2-resolution-scheme](../2026-09-22-bc2-resolution-scheme/): при
Δx = 0,20 / 0,14 / 0,10 мм пик равен 985,0 / 975,9 / 987,1 м/с, то есть схема
сходится по сетке, и сходится к 0,75 эталона. Объяснение «не хватает
разрешения» из §4 несостоятельно; причину следует искать в передаче волны через
границу B4C/LiF.

Подозрение на приосевую зону, сформулированное здесь и в
`notes/contact/06-e2e-case.md`, для BC2 не подтвердилось (профиль вдоль границы плоский
до края). На BC6 оно какое-то время выглядело подтверждённым — осевой и
радиальный мониторы расходились вдвое, — но и там **закрыто** исправлением
осесимметричных источников импульса в `int_force` и сборкой встык, см.
[2026-09-23-bc6-butt-joint](../2026-09-23-bc6-butt-joint/).

## Что осталось неясным

* ~0,9 мкс фазового сдвига без объяснения; проверяется только по самой статье.
* Вопросы к источнику из §5 (геометрия, конфигурация ударника, точка измерения,
  поправка на показатель преломления LiF, константы материалов) остаются без
  ответов.
