## Вопрос

При каком k ткань kT размером 60×60 мм (рабочее окно 50×50 мм) пробивается стальным шаром 1 г при V0 = 550 м/с,
а (k+1)T уже не пробивается.

## Постановка

**Что меняется по сравнению с последним запуском** (16T, задача `fabric_proj16`, `run_proj16.sh`): только габариты полотна.

| Величина | Было (`base`) | Стало | Как получено |
|---|---|---|---|
| Число нитей в слое, nx = ny | 102 | **43** | (43 − 1)·p = 49,56 мм ≈ 50 мм окна; p = 1,18 мм (пресет `twaron_ct717`) |
| Крайние нити | ±59,59 мм | ±24,78 мм | 21·p |
| Граница зажима c_e (зажаты бусины нитей вдоль y с \|y\| ≥ c_e) | 60 мм | **25 мм** | окно 50 мм; допустимый диапазон генератора [24,975; 29,78] мм |
| Выступ зажатых нитей за крайнюю нить, e_y | 5 мм | **5,22 мм** | конец нити на \|y\| = 30,00 мм, в зажиме ровно 5 мм |
| Размер полотна по y (зажатые стороны) | 129,2 мм | **60,0 мм** | 50 мм окна + 2 × 5 мм зажима |
| Размер полотна по x (свободные кромки) | 120,4 мм | **50,7 мм** | (nx − 1)·p + 2·p/2; концы свободных нитей на середине полуволны, как раньше |
| Зажатые стороны | две (концы нитей вдоль y) | **две, как раньше** | решение владельца 2026-11-14 |

Полотно по x — 50,7 мм, а не 60: нити вдоль x свободны и в зажим не заходят, поэтому полосы под зажим по x нет.
Так же устроен и `base`: окно 120 мм по обеим осям, зажим по 5 мм только по y. **Если по x тоже нужно 60 мм**
(свободные кромки на ±30 мм), это ny = 52 и полотно 60,5 × 60 мм — сказать до запуска.

добавлены ключи-переопределения по образцу `--ball-d/--ball-mass/--ball-dx`:
