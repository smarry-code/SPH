**Статья (Guo 2019):**
- 1T: при 73 м/с не пробит, при 79 м/с пробит с V_R ≈ 20 м/с, V_BL = 76 (+3/−3) м/с, порвано 3 вертикальных / 0 горизонтальных нитей;
- 2T: V_BL = 147 м/с;
- прогиб к первому разрыву нити 25–27 мм для всех слоёв. Это единственный прогиб в статье, итогового (максимального) прогиба там нет, поэтому сравнивать со статьёй — колонку «Прогиб к 1-му разрыву».

**Критерии исхода:**
- **по ≤ 8/0** (1T): «не пробит» = шар остановлен, V_R = 0, порвано не больше 8 вертикальных и ни одной горизонтальной нити;
- **по шару**: «не пробит» = шар остановлен, V_R = 0; разрывы — отдельная метрика. Так считается 2T и серии 1T с выталкиванием при μ = 0,27 и 0,3;
- **оценка**: к t_max |v_z| < 5 % V0 и шар за плоскостью ткани — считается «не пробит».

**Обозначения в таблицах:**
- «Прогиб к 1-му разрыву» — `w_f_at_first_break`;
- «Итоговый прогиб под шаром» — наибольший ход низа шара за начальную плоскость ткани, в скобках момент: остановка шара, выход шара при пробое или конец счёта. `w_f_max` из `shot.txt` не используется: после разрывов в него попадают летящие концы нитей.

|---|---|---|---|---|

| 1T, закон 0, μ 0,3, с повреждённостью | 12 | 28 | 4–6 | 1,1–3,3 |

| 1T, закон 3 + выталкивание, μ 0,25, с повреждённостью | 10 | 36–43 | 0–2 | 2–3,5 |
| 2T, закон 3, μ 0,1, без повреждённости | 19–21 | ~190 | 0 | ~3 |
| 2T, закон 3, с повреждённостью | 26–44 | 108–443 | 0–8 | 1,9–2,5 |

Базовые расчёты без повреждённости на законе 0 считались старой версией кода (E = 85 ГПа, σ_u = 2,55 ГПа), сравнение приблизительное.

Как рвутся нити:
- нити рвутся по одной, но симметричными парами: нити на одинаковом расстоянии от центра (±0,6, ±1,8, ±3,0 мм и т. д.) — в пределах ~2 мкс;
- первыми рвутся 4–6 центральных нитей под шаром, дальше разрыв уходит наружу;
- разупрочнение длится меньше 20 мкс (по кадрам) — по монитору единицы мкс, то есть на фронте удара обрыв почти мгновенный;
- энергия при удалении связи не теряется: `D_break` = 0, без повреждённости было 0,1–0,2 % E0;
- в 2T повреждённость отодвинула первый разрыв (117–180 → 188–253 мкс) и прогиб к нему (15–21 → 23–25 мм) к значениям статьи;
- число разрывов повреждённость не уменьшила.

## Замечания

- Выстрелы у самого порога недетерминированы: при параллельном счёте разные прогоны расходятся из-за различий в округлении. 2T 144 м/с в двух прогонах дал «почти остановлен» и «пробит, V_R 55,6». В серии 2T μ 0,3 с выталкиванием исход немонотонный: 140 и 142 пробиты, 142,5 не пробит, поэтому вместо окна указана область порога 135–144 м/с.
- Без выталкивания на законе 3 нити проходят сквозь друг друга (n_tunnel 34–58, δ/d до 1,0). С выталкиванием n_tunnel = 0, полная энергия не превышала начальную (E_tot_max/E0 = 1).
