Выводы A1:

- Модельная извитость 7.6 % (ломаная k=2 с A = 0.6d) больше деформации разрыва нити (3 %) в 2.5 раза. Ломаная k=2 даёт меньший излишек, чем косинус той же амплитуды (7.58 % против 9.09 %).
- Круглая нить полной площади не может иметь A < d/2 = 0.195 мм: на пересечении центры x- и y-нити разведены по z на 2A, и при 2A < d нити перекрываются. Минимальная достижимая извитость для круглой нити: **5.32 % (ломаная) / 6.43 % (косинус)**. Модель (A = 0.6d) имеет зазор между поверхностями на пересечении 2A - d = 0.078 мм; запас по снижению извитости только 2.3 п.п. (7.58 -> 5.32 %).
- Толщина 0.4 мм из статьи физически невозможна для двух круглых нитей d = 0.39 мм (минимум 2d = 0.78 мм). Значит, в статье нить в ткани сплющена. Оценка: эллипс той же площади при толщине 0.2 мм имеет ширину 0.76 мм (при шаге 1.18 мм помещается). Круглая нить d = 0.39 мм такую толщину воспроизвести не может.
- 280 г/м2 при 8.5 нит/см и 172 текс не воспроизводится даже без извитости: 2·rho·A/pitch = 291.6 г/м2 > 280. Требуемая «извитость» **-4.0 %**, то есть отрицательная. Входные числа не согласованы: для 280 г/м2 при извитости модели нужен либо шаг 1.32 мм (7.6 нит/см), либо 153.6 текс (при нулевой извитости 165.2 текс или шаг 1.229 мм). **Шаг, текс и 280 г/м2 нужно сверить с паспортом ткани** (возможно, 280 г/м2 относится к другой плотности/тексу, либо это номинал без учёта плетения). В модели масса бусин на 12.7 % больше 280 г/м2 в окне.

### A3.2 Поперечная волна (`fig/a3_front.png`, `data/a3_wave.json`)

Фронт прогиба = наибольшее расстояние от оси вдоль центральной нити (ply 1, индекс 50), где сглаженное по периоду извитости |z - z0| > 0.2 мм (одна и та же бусина). Разрешение по времени 20 мкс.
Скорость фронта — линейная подгонка. Смит: c = sqrt(E/rho) = 7683 м/с, при V шара деформация eps и U_lab по формулам из задания; для ткани c/√2 = 5433 м/с. «Геометрическая» оценка (оценка): w = ∫V dt, фронт = w / sqrt(2c + c²), c = 7.58 % (путь нити от оси до фронта выпрямляется на излишек извитости).

## B5. Самопересечение и смятие нитей (`fig/b5_crush.png`, `data/b5_crush.json`, `data/b5_frames_*.csv`)

Кадры: число связей с l < d (0.39 мм) и l < 0.5·l0 (l0 = 0.635 мм) по времени; «виртуальная» энергия Герца для пар бусин одной исходной нити (индексы различаются на 2 и более, расстояние < d),
U = 0.4·K·δ^2.5 (K = 4/3·Es·sqrt(d/4), Es = E/(2(1 - nu²)), nu = 0.3, как в предыдущем разборе, точечная модель бусин). В коде контакта «своих» бусин нет, поэтому эта энергия не учтена.

|---|---|---|---|---|---|
| 1T V65 | 3 / 1 | 0.192 | 0.84 (15, 0.70) | 11 / 6 | 2.48 (16.8 %) |
| 1T V71 | 1 / 0 | 0.550 | 0.84 (10, 0.78) | 44 / 21 | 8.33 (47.2 %) |
| 2T mu0.1 | 20 / 11 | 0.190 | 1.27 (13, 0.73) | 78 / 44 | 9.70 (14.8 %) |
| 2T mu0.9 | 9 / 5 | 0.074 | 0.63 (8, 0.80) | 151 / 81 | 14.1 (21.5 %) |

**Постановка.** Нить (d = 0.39 мм, E = 85 ГПа, rho = 1440, упругая) огибает неподвижный цилиндр радиуса R_c = 2 мм (контактная поверхность) на угол

## Подготовка шага 3: ключи --mu-ff / --mu-fs

## Отклонения от задания и ограничения
