# Демо: снаряд пробивает крестообразную сеть из двух нитей

Постановка — [`fiber/DEMO_VISUALIZATION_TASK.md`](../../fiber/DEMO_VISUALIZATION_TASK.md).
Расчёт идёт через продовый цикл `time_integration(cfg, fiber::Model&, ...)`,
кадры рендерятся в GIF скриптом `scripts/animate.py`.

## Сборка, запуск, визуализация

```
cmake --build build -j8 --target demo_fiber_net
./build/demo_fiber_net.exe experiments/2026-09-26-fiber-net-demo/data/run      # ~2.5-3 мин

cd experiments/2026-09-26-fiber-net-demo
python scripts/animate.py --run-dir data/run --out data/run/anim.gif --color-by speed --fps 12 --snapshot 1,20,24,62
```

Аргумент драйвера — каталог вывода (создаётся при необходимости). Драйвер сам
пишет туда файл сети `net.fib` и загружает его через `fiber::load_fiber_file()`,
затем делает `chdir` в этот каталог: `output()`/`fiber_output()` пишут кадры в
текущий рабочий каталог. Цель `demo_fiber_net` собирается с `SPH_DIM=3` (нити
только в 3D; основной `SPH` собран с `dim=1`), `add_test` нет — это не тест.

**Переменные окружения:**
- `SPH_DEMO_MU_FF` — коэффициент динамического трения нить-нить (Coulomb, >= 0);
  если не задана, используется 0 (без трения). Если задана, пишется седьмым полем
  в строку `MATERIAL` файла сети (формат `src/fiber_input.cpp`).
- `SPH_DEMO_MU_FS` — коэффициент динамического трения нить-Solid (Coulomb, >= 0);
  если не задана, используется 0 (без трения). Если задана, пишется восьмым полем
  в строку `MATERIAL` файла сети. Если задана только `SPH_DEMO_MU_FS` без
  `SPH_DEMO_MU_FF`, то `SPH_DEMO_MU_FF` автоматически выставляется на 0 для
  правильного формата файла.
- `SPH_DEMO_BUDGET_S` — временной бюджет в секундах для `RunGuard` (жёсткий
  wall-clock лимит); если не задана, используется 600 с. Должна быть положительной
  величиной, иначе ошибка и выход с кодом 1.

Параметры `animate.py`: `--color-by {speed,p}`, `--fps`, `--elev/--azim`,
`--max-frames`, `--dpi`, `--snapshot N1,N2,...` (PNG отдельных кадров, номер —
порядковый индекс кадра). MP4 — только если в PATH есть `ffmpeg`, иначе GIF.
`scripts/make_synthetic_frames.py` генерирует синтетические кадры того же
формата (использовались для отладки рендера, физики в них нет).

## Параметры сцены

**Снаряд** — куб 8×8×8 = **512 SPH-частиц**, алюминий (`itype=body=4`),
`dx=1.2 мм`, ρ=2700 кг/м³, **v0 = 30 м/с** вдоль −z; нижняя грань стартует на
4 мм выше сети.

**Сеть** — 2 прямые нити крестом (P вдоль x на z=+0.5 мм, Q вдоль y на
z=−0.5 мм), по **21 бусине**, `l0=2 мм` (длина 40 мм, ~4× снаряда).
Материал: `E=2e7`, `nu=0.3`, `d=1 мм`, `rho=1200`, **`eps_break=0.05`**.
Зазор между осями нитей в центре креста D0 = d = 1 мм — нити касаются без
проникания, контактная сила на старте нулевая.

**Псевдо-анкеры** — концевые бусины (`prev==-1 || next==-1`) утяжелены в
**50 раз** после загрузки; за прогон они сдвигаются < 0.02 мм.

**Конфиг**: `t_total=5e-4 с`, `save_t=8e-6 с` → **63 кадра**,
`contact_force_type=0` (Solid-тело одно), остальное — `apply_defaults()`
(PredictorCorrector, `sle=1`).

Шаг ограничен CFL алюминия (`dt≈2.8e-8 с`), а не жёсткостью нити или
контакта — подстраивать параметры нити под шаг не понадобилось. Итог:
17839 шагов, ~2 мин 45 с.

## Что наблюдается

- **NaN/Inf** нет ни в одном кадре; координаты в пределах сантиметров.
- **Fiber-Fiber-Contact.** Зазор между центральными бусинами (id 10 — центр P,
  id 31 — центр Q) держится ровно 1.000 мм, пока не подлетит снаряд; при
  t≈128 мкс он опускается ниже d (0.997 мм) — контакт включается от удара.
  Во всех кадрах z_P > z_Q: верхняя нить сквозь нижнюю не проходит.
- **Натяжение и разрыв.** Удлинение связей у центра растёт по мере подлёта.
  Разрывы (N_BONDS): 40 → 34 между 152 и 160 мкс, → 32 к 168 мкс, → 30 к
  192 мкс; дальше топология не меняется — **10 из 40 связей порвано**.
  Центральные обрывки нитей улетают вперёд снаряда отдельными объектами
  (новый `object_id`, на анимации — другой цвет бусин).
- **Снаряд** прорезает сеть почти без торможения: средняя vz −30.000 →
  −29.543 м/с (~1.5%). Масса куба (~2.4 г) на порядки больше массы сети, так
  что это ожидаемо; для заметного торможения нужна существенно более тяжёлая
  или жёсткая сеть, чем задаёт постановка.

## Ограничения

- Несколько связей рвутся в пределах одного интервала `save_t`, поэтому
  точный порядок разрывов по кадрам не разрешается; для этого нужен меньший
  `save_t` в окне 150–200 мкс.
- Цветовая шкала скорости узкая (29.5–30 м/с), потому что снаряд почти не
  тормозится; `--color-by p` показывает волну давления в кубе нагляднее.
