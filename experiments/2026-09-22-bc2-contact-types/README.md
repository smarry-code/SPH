| | |
|---|---|
| **Дата** | 2026-09-22 |
| **Кейс** | BC2 — Grady & Moody, SAND96-0551, опыт CE6 |
| **Ветка / коммит** | `BC6` / `3962a5e`, дерево чистое |
| **Прогонов** | 4 (`contact_force_type` = 0, 1, 2, 3) |
| **Статус** | завершён; все четыре дошли до `t_total` |
| **Постановка** | [contact/06-e2e-case.md](../../contact/06-e2e-case.md) |
| **Воспроизведение** | REPRO.md нет — правило введено начиная с развёртки по Kp |

## Вопрос

После снятия зазоров (сборка встык) и правок осесимметрии — что дают четыре
реализованных типа контакта на официальном графике кейса и насколько результат
отстоит от приборного эталона?

## Постановка

Штатная цель сборки `cmake --build build --target bc2_plot`: четыре полных
прогона, по одному на значение `contact_force_type`, каждый выгружает свою
кривую, из выгрузок собирается SVG. В файл попадает ровно тот объект `Curve`,
который проверил компаратор, поэтому картинка не может разойтись с метриками.

Постановка без изменений: Δx = 0,20 мм, 33 944 частицы, `t_total` = 3,5 мкс,
`contact_penalty_scale` на этом прогоне **закомментирован**, то есть действует
умолчание `Kp = 1,0`. Монитор — последний z-узел покоящейся керамики на оси
(`r ≈ 0,1 мм`), граница керамика/окно LiF.

## Результат

Эталон: пик **1317,5 м/с** при 2,2894 мкс; t10/t50/t90 = 1,8736 / 2,0680 / 2,1932 мкс;
фронт 10–90 % = 0,3196 мкс; спад до 70 % = 0,2632 мкс.

| Тип | Шагов | Достигнутое время, мкс | Пик, м/с | Доля эталона |
|---|---|---|---|---|
| 0, выключен | 1499 | 3,50066 | 985,0 | 0,748 |
| 1, Пинбол | 1499 | 3,50066 | 985,0 | 0,748 |
| 2, Свигл | 1573 | 3,50223 | 983,8 | 0,747 |
| 3, импульсный | 1499 | 3,50073 | 984,5 | 0,747 |

Операционные проверки §6 пройдены у типов 1–3: пар B4C ↔ B4C = 0 (ограничение
D2=A — контакт видит только пары с разным `itype`), пар 8 ↔ 10 = 1, то есть
контакт работает между материалами и не работает внутри керамики.

Свод компаратора по типу 0: амплитуда 3,000 при коридоре [0,500; 2,000],
фронт 1,000 — то есть по грубым воротам расчёт проходит, а содержательное
расхождение ворота не ловят.

## Вывод

**Выбор типа контакта на результат BC2 не влияет:** четыре значения пика
укладываются в 0,15 %, вдвое меньше разброса от многопоточности. Тип 2 стоит на
5 % больше шагов (ограничитель `dt`), и это единственное различие, которое видно.

Причина в том, что контактные силы приложены не там, где решается судьба
амплитуды. Удар симметричный, B4C по B4C, и по решению D2=A эта граница для
контакта невидима. Единственная межматериальная граница на пути волны —
B4C/LiF, и на ней контакт лишь слегка демпфирует.

**Все четыре прогона дают 0,748 эталона.** Расчёт правильно воспроизводит
физику **до** границы с окном (скорость поршня 1100 против теоретических 1105,
ударное состояние керамики сходится с JH-2) и неправильно — **на** ней.

## Что изменилось после

Коммит `ed4cd3d` (2026-09-23) переписал **тип 3**: импульсная сила теперь
работает по нормальной составляющей скорости, и появилась доля гашения
`contact_impulse_gamma`. Значение 984,5 м/с в таблице выше измерено **до** этой
правки, на коммите `3962a5e`; для текущего кода его следует перемерить.
На типы 0, 1 и 2 правка не влияет, поэтому остальные три строки таблицы
остаются в силе.

## Что осталось неясным

Ничего нового: открытый вопрос здесь тот же, что и во всех остальных
экспериментах по BC2 — отсутствие импедансного усиления на границе B4C/LiF,
см. [2026-09-22-bc2-resolution-scheme](../2026-09-22-bc2-resolution-scheme/).
