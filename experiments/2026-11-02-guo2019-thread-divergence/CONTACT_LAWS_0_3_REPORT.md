# Законы контакта 0 (Герц) и 3 (импульсный) для нитей: подробное описание для поиска литературы

**Дата:** 2026-11-03. **Код:** ветка `fiber_deterministic_reduce` (коммит `6f1b63f`).
**Сцена, на которой всё проверялось:** Guo 2019, 1T base. Шар 12 мм, 7 г, V0 ≈ 79 м/с; ткань Twaron
CT717, 102 × 102 нити.

Отчёт описывает, как в коде устроены два закона нормальной силы контакта нитей — 0 (Герц) и 3
(импульсный) — вместе с геометрией, массами, схемой по времени и трением. Свойства, выведенные из
формул, отделены от измеренных на сцене. В конце — открытые вопросы и ключевые слова для поиска статей.
Туннелирование подробно разобрано в соседнем отчёте `TUNNELING_REPORT.md`, здесь — только его связь
с законами.

---

## 0. Кратко

| | Закон 0 — Герц | Закон 3 — импульсный |
|---|---|---|
| Формула | F = (4/3)·E\*·√R\*·δ^{3/2} | F = γ·m_red·ṗ/Δt_prev при δ > 0 и ṗ > 0, иначе 0 |
| Тип | упругий (потенциальный), без демпфирования | вязкий за один шаг: абсолютно неупругий удар на каждом шаге |
| Сила в покое под нагрузкой | есть, F = F_H(δ_s) | только пока пара сближается |
| Возврат проникания | да | нет |
| Гладкость | F и dF/dδ непрерывны при δ = 0 | включается скачком при δ → 0⁺, если ṗ > 0; выключается при ṗ ≤ 0 |
| Шаг Δt в формуле | нет | да (∝ 1/Δt), по шагу не сходится |
| Предел шага | 0,8/√(k_eff/m_red), k_eff = 1,5F/δ | фактически не ограничивает |
| Энергия | сохраняет (упругая энергия U_hertz) | только рассеивает |
| Проникание на сцене | δ/d ≤ 0,18–0,21 | до δ/d = 1,0 (проход насквозь) |
| Рост малых возмущений, e-кратное время | 1,3–1,4 мкс | 0,9 мкс |

Главное:
1. **Закон 0** физически осмыслен (контакт Герца упругих тел), параметры задаются без подгонки
   (E, ν, d). Его недостатки:
   - нет диссипации при ударе бусин (абсолютно упругий удар);
   - контактный модуль берётся равным продольному модулю нити E = 80 ГПа, хотя поперечная жёсткость
     арамидной нити, скорее всего, много меньше (§5, вопрос 1);
   - эквивалентный радиус взят как для двух шаров, а не для скрещённых цилиндров (§5, вопрос 2).
2. **Закон 3** — это гашение нормальной скорости пары за один шаг, наследие контакта Solid–Solid. Это
   не проекция в смысле методов на уровне скоростей: сила считается по скорости предиктора и не видит
   других сил того же шага. Поэтому нагрузку он держит только ценой постоянного погружения, и
   проникание накапливается до прохода насквозь. С уменьшением шага он не сходится.
3. **Хаотичность счёта есть при обоих законах.** Закон 3 ускоряет рост возмущений примерно в
   1,5 раза, но не создаёт его (§4.3).

## 1. Общее для обоих законов

### 1.1. Нить, бусины, массы

- Нить — ломаная из бусин (bead-chain). Соседние бусины связаны связями, работающими только на
  растяжение (упругопластические, с повреждённостью).
- Масса бусины сосредоточенная: m_k = ρA(l⁰_{k−1,k} + l⁰_{k,k+1})/2, A = πd²/4.
- Сцена: d = 0,39 мм, ρ = 1440 кг/м³, сегмент ≈ 0,59 мм (2 сегмента на полуволну переплетения при
  шаге 1,18 мм), масса бусины ~1·10⁻⁷ кг. E = 80 ГПа, ν = 0,3.
- Шар — 3 544 SPH-частицы стали на решётке dx = 0,6 мм, контактный радиус частицы r_s = 0,3 мм.
  Частица шара примерно в 18 раз тяжелее бусины. Сталь: E ≈ 205,7 ГПа, ν ≈ 0,286 (из K, G материала).

### 1.2. Геометрия контакта (одинакова для обоих законов)

**Нить–нить: сегмент–сегмент** (`include/interactions/fiber_contact.hpp:467`, `notes/fiber-model/fiber-model-report.md` §6.3).
- Ближайшие точки осей двух сегментов q_A(s), q_B(t) находятся алгоритмом ClosestPtSegmentSegment
  (Ericson, *Real-Time Collision Detection*, §5.1.9). Параметры прижимаются к 0/1 в окрестности 10⁻⁹.
- D = |q_A − q_B|, n = (q_A − q_B)/D, δ = r_a + r_b − D. Нить представлена «оболочкой» радиуса d/2
  вокруг ломаной. Контакт при D < d.
- Если оси пересеклись (D < 10⁻¹²), нормаль строится как e_A × e_B. Если оси ещё и параллельны,
  контакт не формируется.
- **Правило владения:** на одно пересечение осей приходится одна сила. Сегмент, у которого ближайшая
  точка попала на его конец, отдаёт контакт соседнему сегменту. Исключение — несколько локальных
  минимумов («седло»): на сцене в среднем 2,4–2,7 контакта на перекрестье.
- Сила раскладывается на четыре бусины весами (1 − s, s) и (1 − t, t), импульс сохраняется точно.
- Самоконтакт нити не учитывается.

**Нить–шар: частица–сегмент** (`include/interactions/fiber_solid_contact.hpp:520–575`).
- Расстояние от центра SPH-частицы до оси сегмента, δ = r_f + r_s − D, нормаль от нити к частице.
  Правило владения то же.
- Поверхность шара — дискретный набор сфер радиуса 0,3 мм на решётке 0,6 мм, то есть «шероховатая».

### 1.3. Схема по времени (`include/ode/ode_solver.hpp:211–426`)

Явный предиктор-корректор из SPH-кода (Liu & Liu). На шаге n:
1. **Предиктор скорости на полшага:** ṽ = vⁿ + (Δt_prev/2)·aⁿ⁻¹. Координаты не меняются: xⁿ.
2. **RHS** по (xⁿ, ṽ): связи, контакты нить–нить и нить–шар, SPH шара → aⁿ без трения.
3. **Трение** (отдельная стадия, §1.4) → добавка к aⁿ.
4. **Корректор:** vⁿ⁺¹ = vⁿ + Δt·aⁿ, затем xⁿ⁺¹ = xⁿ + Δt·vⁿ⁺¹.
5. **Постобработка:** пластичность и разрыв связей.

Шаг: минимум из пределов связей (осцилляторный критерий, без CFL для нитей), контактов и CFL шара,
умноженный на `dt_scale`. На сцене dt ≈ 9,2·10⁻⁹ с при `dt_scale` = 0,5, это ~3·10⁵ шагов на 3 мс.

### 1.4. Трение (одинаково для обоих законов; `include/interactions/fiber_friction.hpp:174`, `fiber-model-report.md` §8)

Проекция импульса на уровне скоростей:
- пробная скорость с учётом всех сил шага, кроме трения: ṽ_k = v_k^base + h·a_k;
- касательная относительная скорость точек контакта u_t;
- обратная эффективная масса W = Σ c_k·α_k²/m_k (c_k — **целое число** активных контактов бусины:
  разделение массы, mass splitting);
- импульс J = min(μNh, |u_t|/W) против u_t.

Свойства:
- выполняется предел Кулона;
- нет перескока через ноль;
- точное прилипание при μNh ≥ |u_t|/W;
- трение только рассеивает энергию;
- один проход Якоби по всем контактам.

Нормальная сила N берётся из закона контакта. Если N = 0 (у закона 3 при ṗ ≤ 0), слот трения не
заводится, и трения на этом шаге нет. На сцене μ_ff = μ_fs = 0,27.

## 2. Закон 0: Герц

### 2.1. Формула и код

$$
F=\tfrac43E^\ast\sqrt{R^\ast}\,\delta^{3/2},\qquad
\frac1{E^\ast}=\frac{1-\nu_1^2}{E_1}+\frac{1-\nu_2^2}{E_2},\qquad
R^\ast=\frac{r_1r_2}{r_1+r_2}.
$$

- Нить–нить: `fiber_contact.hpp:582–597`. Для одинаковых нитей E\* = E/(2(1 − ν²)) и R\* = d/4 — это
  формула Meyer для контакта бусин-шаров.
- Нить–шар: `fiber_solid_contact.hpp:560–566`. E_s, ν_s стали берутся из K, G материала SPH, R\* —
  как у двух шаров радиусов r_f и r_s.
- Сила зависит только от геометрии (xⁿ), не от скорости. Демпфирования нет.
- Упругая энергия ведётся в логе: U_hertz = Σ (2/5)·F·δ (`include/energy_log.hpp:27`).

### 2.2. Числа для сцены

| | нить–нить | нить–шар |
|---|---|---|
| E\* | 44 ГПа | 63 ГПа |
| R\* | d/4 = 0,0975 мм | r_f·r_s/(r_f + r_s) = 0,118 мм |
| k_H = (4/3)E\*√R\* | 5,8·10⁸ Н/м^{3/2} | 9,2·10⁸ Н/м^{3/2} |
| статическое проникание при N = 25 Н, δ_s = (N/k_H)^{2/3} | 0,012 мм ≈ 0,03 d | 0,009 мм ≈ 0,02 d |

N ≈ 25 Н — оценка нагрузки на одну бусину от нити с натяжением ~240 Н, огибающей шар
(`fiber-model-report.md` §9.4).

### 2.3. Предел шага

Δt ≤ 0,8/ω, ω = √(k_eff/m_red), k_eff = dF/dδ = 1,5·F/δ (`contact_force.hpp:71–72`). Жёсткость растёт
как δ^{1/2}, поэтому при сильном ударе предел шага падает.

### 2.4. Свойства (из формул)

- **Потенциальная сила.** Контакт сохраняет энергию: удар бусины о бусину или о шар абсолютно
  упругий, коэффициент восстановления e = 1. Рассеяние идёт только через трение, пластичность связей
  и SPH шара.
- **Гладкость.** F(0) = 0 и dF/dδ(0) = 0, включение без скачка. Негладкость остаётся в другом:
  - контакты появляются и исчезают при поиске;
  - правило владения перекидывает контакт между соседними сегментами;
  - трение переключается между прилипанием и скольжением;
  - c_k в трении меняется скачком.
- **Держит нагрузку в покое**, а значит питает трение: предел μN не обнуляется.
- **Шаг в формуле не участвует.** Сходимость по шагу в принципе возможна; на сцене не проверялась
  отдельно (§4.3: при шаге ×1 и ×0,5 рост возмущений одинаков).

### 2.5. Что измерено на сцене

- Проникание нить–нить ≤ 0,18–0,21 d, нить–шар ≤ 0,09 d, бусин внутри шара 0
  (`experiments/2026-10-16-guo2019-1t-contact-types-friction/README.md`, параметры той серии:
  E = 85 ГПа, σ_u = 2,3 ГПа, μ = 0,1).
- Исходы 1T с повреждённостью нити (`experiments/2026-10-26-guo2019-damage-summary/README.md`):

  | μ | V0, м/с | Исход | V_R, м/с | Разрывы в/г | 1-й разрыв, мкс |
  |---|---|---|---|---|---|
  | 0,2 | 73 | пробит | 32,5 | 10/1 | 431 |
  | 0,2 | 79 | пробит | 38,3 | 10/1 | 395 |
  | 0,3 | 73 | остановлен | 0 | 12/0 | 430 |
  | 0,3 | 79 | остановлен | 0 | 12/0 | 394 |

  Статья: при 73 м/с не пробит, при 79 м/с пробит с V_R ≈ 20 м/с, 3/0 разрывов, V_BL = 76 (+3/−3) м/с.
  Закон 0 даёт резкую зависимость исхода от μ и больше разрывов, чем в статье.
- Прогиб к первому разрыву 26,6–26,7 мм, в статье 25–27 мм. Совпадает при любом законе.

## 3. Закон 3: импульсный

### 3.1. Формула и код

$$
F=\begin{cases}\gamma\,\dfrac{m_{red}\,\dot p}{\Delta t_{prev}}, & \delta>0,\ \dot p>0,\\[4pt] 0, & \text{иначе,}\end{cases}
\qquad \gamma=1 .
$$

- `impulse_force`, `include/contact_force.hpp:161–179`. Вызов для нитей: `fiber_penalty_force`,
  `include/interactions/fiber_contact_law.hpp:181`.
- **ṗ** — скорость сближения точек контакта, ṗ = −n·(v_A − v_B), где v_A = (1 − s)·v_{a0} + s·v_{a1}.
  Скорости берутся **предикторные**, ṽ = vⁿ + (Δt_prev/2)·aⁿ⁻¹ (`fiber_contact.hpp:674`).
- **m_red** по эффективным массам точек контакта: 1/m_A = (1 − s)²/m_{a0} + s²/m_{a1}. Для нить–шар
  вторая масса — масса SPH-частицы.
- **Δt_prev** — шаг прошлого цикла: новый шаг в момент RHS ещё не известен.
- Происхождение: формула (2.10) штрафных законов контакта Solid–Solid (ADR-007). В проекте введены
  два отступления от буквальной формулы:
  1. вместо полной относительной скорости |v_ij| берётся её нормальная часть ṗ. Иначе сила скачком
     включалась при сколь угодно малом сближении, и на тесте BC6 был сильный дребезг;
  2. добавлена доля гашения γ.

### 3.2. Что закон делает за шаг

При одном контакте и Δt = Δt_prev приращение относительной нормальной скорости от контакта:
$$
\Delta\dot p=-\Delta t\,F\Big(\frac1{m_A}+\frac1{m_B}\Big)=-\gamma\,\tilde{\dot p},
$$
где $\tilde{\dot p}$ — скорость сближения по предиктору. То есть закон снимает предикторную скорость
сближения целиком (γ = 1): **абсолютно неупругий удар пары на каждом шаге**.

Но итоговая скорость сближения в конце шага
$$
\dot p^{\,n+1}=\dot p^{\,n}-\gamma\tilde{\dot p}+\Delta t\cdot(\text{нормальная часть остальных ускорений шага}),
\qquad \tilde{\dot p}=\dot p^{\,n}+\tfrac{\Delta t_{prev}}2\,\dot{(\cdot)}^{\,n-1},
$$
в общем случае не равна нулю, потому что:
- **закон не видит остальных сил того же шага** — натяжения связей, других контактов, давления шара;
  они снова разгоняют пару навстречу;
- в $\tilde{\dot p}$ входит половина ускорения прошлого шага, включая прошлую контактную силу. Получается
  обратная связь между соседними шагами;
- **разделения массы для нормальной силы нет.** Каждый контакт бусины считает силу так, будто он
  единственный. Трение такое разделение делает (c_k), нормальная сила закона 3 — нет. При нескольких
  контактах одной бусины суммарный импульс может превысить нужный. Это видно из кода; отдельно на сцене
  не измерялось.

Поэтому закон 3 — не проекция скорости на допустимое множество (как трение в §1.4 или как
velocity-level контакт в схемах Моро–Жана), а **одношаговый регулятор по предикторной скорости**.
В проекте уже предложено исправление «закон по пробной скорости, как трение»
(`fiber-model-report.md` §9.8, решение 1, ключ `fiber_*_contact_predictor`). Оно не реализовано.

### 3.3. Свойства (из формул)

- **Нет восстанавливающей силы.** При ṗ ≤ 0 сила 0, накопленное проникание не возвращается.
  Под постоянной нагрузкой N_s пара держится только при среднем погружении ~N_s·Δt/(2m_red). На сцене
  это ~1 м/с, так что d набирается за ~0,4 мс при длительности удара 0,4–1,5 мс. Отсюда проходы
  насквозь (`TUNNELING_REPORT.md` §3).
- **Не сходится по шагу.** Приращение скорости за шаг dv = γ(m_red/m)·ṗ от Δt не зависит, потому что
  F ∝ 1/Δt (`contact_force.hpp:154–160`). При уменьшении шага сила растёт, а воздействие за шаг не
  уменьшается. На сцене: 1T 73 м/с с выталкиванием, шаг ×1 — пробит с 5,8 м/с, шаг ×0,5 — не пробит
  (`experiments/2026-10-22-guo2019-law3-summary/README.md` §5.2).
- **Релейность.**
  - По скорости сила непрерывна: ṗ → 0⁺ ⇒ F → 0.
  - По прониканию разрывна: при δ → 0⁺ и ṗ > 0 сила сразу конечна, m_red·ṗ/Δt, — это и есть
    «удар за шаг».
  - Включение и выключение (ṗ ≷ 0) идёт каждые несколько шагов. Вместе с этим включается и
    выключается трение, так как N = 0 ⇒ трения нет: дребезг трения (`fiber-model-report.md` §9.5).
- **Только рассеивает:** каждое срабатывание снимает ½·m_red·ṗ² энергии относительного движения.
  Восстановления (e > 0) нет. Исключение: в тесте «нить падает на пластину» импульсный тип отскочил
  (E_end/E0 = 0,66). Это не разобрано — видимо, из-за распределения на бусины сегмента.
- **Предел шага** 2·0,8·Δt_prev/γ, делённый на `dt_scale`. При γ ≤ 1,6 он не ограничивает никогда.
  При γ > 1,6 возникает петля «жёсткость → шаг → жёсткость», и такой γ вне рабочего диапазона.

### 3.4. Вариант с выталкиванием (запрещён для расчётов с 2026-10-21)

При δ > 0,1·(r_a + r_b) к ṗ добавляется (δ − 0,1r)/τ, τ = 0,5 мкс (стабилизация Баумгарте на уровне
скоростей; `fiber_contact_law.hpp:63–80, 184–194`).
- Проходы насквозь исчезают: δ/d ≤ 0,16.
- Но контакт становится источником энергии: разводит пару, прижатую натяжением, и совершает работу
  против натяжения. Выбросы −5,6…−37,5 % E0, пачки ложных разрывов. Предел скорости выталкивания
  20 м/с не помогает.
- Подробно: `TUNNELING_REPORT.md` §3.2.

### 3.5. Что измерено на сцене

| Серия (1T, повреждённость, шаг ×0,5) | Результат |
|---|---|
| без выталкивания, μ = 0,25 | окно пробития [72; 73] м/с; при 75 «проползание» с 5,3 м/с, при 79 остановлен (10/0) — немонотонно |
| с выталкиванием, μ = 0,27 | окно [79; 80,5] м/с |
| с выталкиванием, μ = 0,3 | окно [82; 85] м/с |
| без выталкивания, μ = 0,27, V0 = 79·(1 + k·10⁻¹²), k = 0…3 (2026-11-03) | остановлен; пробит 12,1; пробит 12,9; пробит 23,7 м/с |

- Проникание до δ/d = 1,0, бусин в шаре до 36–87.
- Энергия к концу удара (`law3-summary` §4): трение 48–71 % E0, контакт 18–31 %, пластичность связей
  0,5–1,8 %.

## 4. Сравнение 0 и 3

### 4.1. По формулам

| Свойство | 0 Герц | 3 импульсный |
|---|---|---|
| От чего зависит сила | δ (положение) | ṗ (скорость предиктора), Δt_prev |
| Механическая аналогия | нелинейная пружина | вязкий демпфер с c = γm_red/Δt; удар с e = 0 за шаг |
| Коэффициент восстановления | 1 | 0 |
| Статическое равновесие под нагрузкой | δ_s = (N/k_H)^{2/3} | нет: дрейф проникания |
| Энергия | сохраняет | рассеивает |
| Сходимость по Δt | возможна | нет |
| Ограничивает шаг | да, через k_eff | нет |
| Включение | гладкое, F ∝ δ^{3/2} | разрывное по δ |
| Связь с трением | N > 0 всё время контакта | N = 0 на шагах с ṗ ≤ 0 |

### 4.2. По исходам

Сравнивать исходы напрямую нельзя: серии различаются μ, выталкиванием и шагом. Общее у всех законов:
- прогиб к первому разрыву 25–27 мм;
- первыми рвутся 4–6 центральных нитей под шаром;
- исход решается после первых разрывов.

## 5. Открытые вопросы (для литературы)

1. **Контактный модуль нити.** В законе 0 E\* считается из продольного модуля E = 80 ГПа. Арамидная
   нить — пучок из сотен филаментов, и в поперечном направлении она сжимается намного легче: модуль
   филамента поперёк волокна, по справочным данным, порядка единиц ГПа, а пучок ещё мягче из-за
   уплотнения. Значения нужно проверить по литературе. Какие поперечные (transverse compression) модели
   нитей используют в моделях ткани на уровне нитей? Насколько это меняет δ, площадь контакта, предел μN
   и шаг?
2. **Эквивалентный радиус.** Код берёт R\* = d/4, как для двух шаров диаметра d (Meyer). Для двух
   скрещённых под прямым углом цилиндров радиуса R контакт Герца эквивалентен контакту шара радиуса
   √(R₁R₂) = R = d/2 с плоскостью (Johnson, *Contact Mechanics*). Сила при том же δ тогда в √2 раз
   больше. Какая постановка правильна для сегментной модели нити? Какое R\* для почти параллельных
   нитей, для контакта нити со сферой шара и с «шероховатой» SPH-поверхностью?
3. **Демпфирование и восстановление в контакте нить–нить и нить–шар.** Закон 0 абсолютно упругий,
   закон 3 абсолютно неупругий. Какие значения коэффициента восстановления или вязкого демпфирования
   (Кельвин–Фойгт, Хант–Кроссли) используют для арамидных нитей при ударе 50–500 м/с? В проекте есть
   закон 4 (Герц + односторонний демпфер c = K_p·m_red/Δt_ref), но выбор K_p не обоснован физически.
4. **Контакт на уровне скоростей.** Как правильно строить импульсный контакт в явной схеме, чтобы он
   держал статическую нагрузку и не давал дрейфа проникания? Варианты:
   - проекция по пробной скорости с учётом всех сил шага;
   - схемы Моро–Жана, Анитеску–Потры (LCP/NCP);
   - нелинейный Гаусс–Зейдель вместо одного прохода Якоби;
   - split impulse или проекция положений вместо Баумгарте.

   Как в таких схемах делят массу при нескольких контактах (mass splitting)?
5. **Сходимость по шагу.** Законы с Δt в знаменателе силы не сходятся. Какие формулировки контакта
   сходятся по шагу в явных схемах, и как это проверяют для систем с тысячами контактов?
6. **Хаотичность.** Рост возмущений с e-кратным временем ~1 мкс есть при обоих законах. Известны ли
   оценки показателей Ляпунова для DEM, гранулярных систем и моделей ткани, их зависимость от закона
   контакта, жёсткости и трения? Как в литературе ставят численный V50 при такой чувствительности:
   ансамбли прогонов, вероятность пробития?
7. **Сравнение с другими моделями ткани.** Какие законы контакта нитей используют в DEM/bead-chain
   моделях баллистической ткани (Wang и Sun — digital element; работы по yarn-level FE и DEM с
   LS-DYNA, Abaqus/Explicit)? Penalty, kinematic constraint, их параметры? Как влияет закон контакта
   на V50 и V_R?
