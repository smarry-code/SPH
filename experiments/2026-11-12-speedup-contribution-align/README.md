# Выравнивание `ContributionBuffer` по кэш-линии (2026-11-12)

Пункт 2 аудита производительности после правок A–D: `class alignas(64) ContributionBuffer` в `include/rhs/contributions.hpp`.

## Зачем

- Буферы вкладов лежат в `std::vector`, по одному на каждый из 64 отрезков (`kDetSegments`). Соседние отрезки заполняют разные потоки.
- Без выравнивания заголовки `std::vector` (по 24 Б) у соседних буферов попадают в одну кэш-линию. Каждый `push_back` гоняет эту линию между ядрами — ложное разделение (false sharing).
- Признак в профилях 8t: регион связей нитей занимает 2,8 % шага на 1 потоке и 10 % на 8 потоках.
- Порядок вкладов и результат выравнивание не меняет.
