# Дребезг силы трения нить–нить при законах pinball / Swegle / импульсный

Проверка замечания из `notes/contact/12-fiber-contact-types.md`: в `test_e2e_cross_types` (крест двух
нитей, μ = 0.2, v_t0 = 0.05 м/с) у типов 1–3 было 11–23 смены знака относительной касательной
скорости центров против 4 у Герца. Тогда без проверки предполагалось, что причина в шагах с
fn = 0. Продовый код не менялся.

**Код:** ветка `fiber_contact_types` @ `97c8f74`.
**Программа:** `friction_chatter.cpp`, сцена и PC-драйвер из `tests/test_e2e_fiber_contact.cpp`
плюс запись по шагам. Сборка и запуск из корня репозитория:

```
clang++ -std=c++20 -O2 -fopenmp -DSPH_DIM=3 -DNOMINMAX -Iinclude \
  experiments/2026-10-16-fiber-contact-types-friction-chatter/friction_chatter.cpp -o friction_chatter.exe
OMP_NUM_THREADS=1 ./friction_chatter.exe <каталог_csv>
python sign_runs.py   # из каталога CSV: длины серий одного знака силы трения
```

Вывод — `summary.txt`. CSV по шагам (2.9 МБ) в репозиторий не кладутся, они
воспроизводятся командой выше.

**Сверка драйвера.** У Герца первые шаги контакта совпадают с выборкой `[diag c]` теста до
7 значащих цифр (шаги 229–232 и далее). Тест обрывается на отскоке и насчитывает 1 смену знака.
Здесь прогон идёт все 8 мс и захватывает второй эпизод контакта около 3.9 мс, отсюда 4 смены.

## Что измерялось

Горизонт 8 мс, `Kp = 1`, `γ = 1`, μ = 0.2. Рассматривались два окна: весь прогон и первые
K = 85 шагов контакта. K — это полная длительность контакта у Герца, то есть сравнение при
равной экспозиции. Сила трения меряется импульсом трения на нить Q за шаг (`impulse_y_on_Q`), а
не скоростью центров. Режим **hold** — контрфакт для H1: на шаге, где геометрический контакт
есть, а fn = 0, слот трения заполняется последним ненулевым N этого контакта.

Смен знака силы трения нет ни у одного типа ни в одном режиме (`summary.txt`).

## Выводы по гипотезам

- **H4, экспозиция: подтверждена, это основной вклад.** У типов 1–3 нет отскока, поэтому нити
  остаются в контакте 7 мс против 0.37 мс у Герца, в 19 раз дольше. В окне равной экспозиции
  (85 шагов) сила трения меняет знак: Герц 1, pinball 5, Swegle 0, импульсный 0.
- **H1, выпадение трения на шагах с fn = 0: для pinball и Swegle опровергнута.** Удержание N
  смены знака не убирает (pinball 155 → 151, Swegle 103 → 133). На шаги с fn = 0 и сразу после
  них приходится 0–6 % смен. У импульсного типа удержание N сокращает смены с 382 до 291, а долю
  коротких серий с 81 % до 54 %: вклад есть, но не главный.
- **Характер смен у pinball и Swegle — медленное колебание, а не пошаговый дребезг.** Медиана
  серии одного знака 7–9 шагов. Касательная скорость точки контакта после первой смены доходит
  до 0.18 м/с, это в 3.6 раза больше v_t0. Значит, трение отвечает на колебания самих нитей при
  длительном контакте, а не на ошибку проекции. Скорость центров нитей этого не показывает: она
  совпадает по знаку с силой трения только в 50–66 % шагов, потому что на пересечении почти
  всегда 2 контакта. Поэтому метрика по центрам из `test_e2e_cross_types` для дребезга не годится.
- **Импульсный тип: настоящий пошаговый дребезг, связанный с H3.** Медиана серии 1 шаг, 81 %
  серий не длиннее 2 шагов. N включается и выключается 705 раз за 1596 шагов контакта: импульс
  гасит сближение за шаг, на следующем шаге pdot ≈ 0 и fn = 0. Это релейный режим из шапки
  `impulse_force`, он передаётся в предел трения μN. Удержание N его ослабляет, но не убирает.
- **H2, фоновый дребезг проекции Якоби:** у Герца при той же сцене его практически нет
  (1 смена). Основной механизм не этот.

## Итог для правила остановки §6

Заметный пошаговый дребезг силы трения есть только у **импульсного** типа (тип 3). У pinball и
Swegle смены знака — это колебательное скольжение в длительном неупругом контакте, а не дребезг.
Сам длительный контакт — следствие отсутствия силы в покое (§0 п.3). Решение по упругому остатку
или удержанию N остаётся за владельцем. Режим hold реализован только в этой диагностике.
