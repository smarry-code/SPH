# Guo 2019: законы контакта нитей pinball / Swegle / импульсный (smoke, 20 мкс)

Шаг 2.5 плана `fiber/plan-fiber-contact-types.md`. Каждый ключ проверяется по отдельности
(типы 1–3), остальное по умолчанию (Герц). Критерий шага 2.5: нет NaN и нет обрыва по `ρ < 0`.
Физический результат относительно Guo здесь не интерпретируется.

**Код:** ветка `fiber_contact_types` (этап 2), сборка `clang-windows`.
**Команда:** `run.sh` в этом каталоге:
`guo2019_shot --config=<cfg> --level=smoke --v0=150 --t-max=2e-5 --frames=off --threads=4 [--fs-contact=N | --ff-contact=N]`.
**Сырые данные:** `shots_raw.txt` (строка `shot.txt` каждого прогона).

## Итог

- Все 28 прогонов завершились с `rc = 0` и дошли до `t = 2·10⁻⁵ с` (`guard_reason = Monitor`
  после `t_max`). NaN/Inf в `monitor.csv` нет. Аварий по плотности нет.
- **Сработало правило остановки §6 плана:** в 1T_A у Fiber–Fiber `max δ/d` равно 0.62 у pinball
  и 0.53 у Swegle, это больше порога 0.5. У Fiber–Solid pinball и Swegle дают 0.42–0.46
  (1T, 1T_A) против 0.06–0.25 у Герца. Проникание глубже ожидаемо: законы 1–3 мягче Герца
  (`F2/F_Hertz = 3(1−ν)/8`) и не дают силы в покое. Нужен ли упругий остаток, решает владелец.
- В конфигурации A нитей нет, поэтому все варианты совпадают с base.
- `dt_min` уменьшается только у Swegle, на 14–20 %. У остальных вариантов отличие от base
  меньше 1 %.
- В 1T_A при `fs = 3` разорвались 2 вертикальные связи, в остальных прогонах разрывов нет.
