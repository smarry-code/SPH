## Вопрос

При каком k шахматная ткань kT останавливает шар 1 г при 550 м/с. Сравнить со сплошной тканью (k = 20 пробит, 21 нет),
стёжкой и мозаикой на том же полотне.

## Ткань (решения владельца 2026-11-21)

- Слой i разбит на два подслоя: i − h (к лицу) и i + h (к тылу).
- Кусочки — шахматная доска: ядро 5×5 нитей по линиям шва от центра (как у стёжки `--stitch-patch=5`: 4 + 7·5 + 4),
  кусочек 7×7 — ядро плюс по одной нити с каждой стороны, которая ложится на крайнюю нить ядра соседа.
- Через каждое пересечение перекрытия идёт стяжка между верхним и нижним кусочком.
- Расстояние от подслоя i + h до (i + 1) − h — шаг слоёв исходной серии D = 2A + d + 1 мкм = 0,859 мм.
- Два режима (переключатель `--chess`):
  - `flip` — у слоя i + 1 чётность доски обратная;
  - `same` — у всех слоёв одна доска.

Выбрано при реализации (геометрия, не решение владельца):

- 2h = D: в перекрытии одно пересечение лежит над другим, ближе нельзя — нити войдут друг в друга. Все подслои
  идут с шагом D, слой занимает 2D, пакет kT вдвое толще сплошного (20T: тыл −34,4 мм против −17,2 мм).
- Углы, где сходятся четыре кусочка: квадрат 2×2 пересечений принадлежит только кусочку, в ядро которого входит
  (иначе нити диагональных соседей одного подслоя совпали бы). Полоса перекрытия у внутренних кусочков — 3 нити.
- Нить кусочка — участок нити полного полотна генератора (те же бусины), обрезанный на середине полуволны за крайним
  пересечением; у краёв полотна сохраняется выступ (зажатые нити — 5,22 мм в зажим, как в серии w50).
- Стяжка — связь материала 1 от нижней нити верхнего кусочка к верхней нити нижнего, длина d + 1 мкм; материал —
  умолчания стёжки (E = 8,5e10 Па, d = 0,2 мм, ε_b = 3 %), ключи `--stitch-E/-d/-eps-break`.

## Код

- `include/fiber/plain_weave_chess.hpp` — генератор `build_plain_weave_chess` (режимы `ChessMode::Flip/Same`).
- `cases/guo2019/experiment/guo2019_scene.hpp` — `ChessSpec`, ветка сцены; тыл z_b по нижнему подслою; зазор слоёв по
  вершинам не считается (у слоя нет сетки пересечений).
- `cases/guo2019/experiment/guo2019_monitor.hpp` — для шахматной ткани проверки порядка слоёв нет (как у мозаики).
- `cases/guo2019/experiment/guo2019_shot.cpp` — ключи `--chess=none|flip|same`, `--chess-patch=P`; каталог `_ch<f|s>P<P>`,
  `chess=` в `scene_id.txt`, `chess*` и `n_stitch` в `shot.txt`.
- `tests/test_plain_weave_chess.cpp` (`plain_weave_chess_test`) — оси кусочков, бусины = участки полотна (побитово),
  подслои flip/same, 864 пересечения перекрытия и 864 стяжки на слой, зажим, расстояние осей разных нитей ≥ d.

Пример (2T, сцены для проверки геометрии):

```
guo2019_shot --config=2T --level=base --v0=550 --out=flip --mu=0.27 --threads=8 --max-steps=2 --frames=off \
  --fabric-n=43 --fabric-clamp-edge=25e-3 --fabric-overhang-y=5.22e-3 \
  --ball-d=6.253e-3 --ball-mass=1e-3 --ball-dx=3e-4 --chess=flip
```

## Проверка (claude-compute-8t, сборка рабочего дерева на `b2931cd`, gcc 15.2, Release, `SPH_ENERGY_LOG=ON`)

- `test_plain_weave_chess`: 0 ошибок; наименьшее расстояние осей разных нитей 0,391 мм (d = 0,39 мм) в обоих режимах.
- Сцена 2T, оба режима: бусин 25 716, связей 23 592, зажатых бусин 2124 — совпадают с формулами сцены;
  нитей-кусочков 2124 (81 кусочек на слой), стяжек 1728 (864 на слой), z_b = −3,435 мм (4 подслоя).

## Что осталось неясным

- Режим (flip или same), с которого начинать, и порядок поиска k — решает владелец.
- Пакет вдвое толще и тяжелее сплошного (кусочки 7×7 вместо 5×5 — нитей почти вдвое больше): сравнение по числу слоёв
  со сплошной тканью не равно сравнению по массе.
