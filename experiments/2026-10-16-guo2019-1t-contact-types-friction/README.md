# Законы контакта нитей 1–3 (pinball, Swegle, импульсный) и сила трения: итоговый отчёт

Ветка `fiber_contact_types`. Сводит всё, что сделано по законам нормальной силы 1–3 для контактов
нить–нить и нить–Solid: реализацию, тестовые сцены, разбор «дребезга» трения и серию на боевой
сцене Guo 2019 1T base. Подробности реализации — в `contact/12-fiber-contact-types.md`, формулы — в
`fiber/SPH.md` (подразделы «Законы нормальной силы»).

## Кратко

1. **Законы 1–3 реализованы и проверены.** Тип 0 (Герц) побитово прежний. Сила 1–3 считается той же
   функцией `contact::penalty_force`, что у Solid–Solid.
2. **Нормальная сила 1–3 обнуляется в покое и при разлёте** (ṗ ≤ 0). Это свойство законов, а не ошибка.
   На боевой сцене от этого нормальная сила оказывается в сотни раз меньше Герца: на нить–нить
   0,08–0,13 %, на нить–Solid 0,7–2 % от силы Герца при той же геометрии.
3. **Следствие — нити проходят друг сквозь друга, а бусины уходят внутрь шара:** δ/d нить–нить = 1,0
   против 0,21 у Герца, `n_tunnel` 55–81 против 0. Правило остановки §6 плана (δ/d > 0,5) превышено.
4. **Сила трения у pinball и Swegle почти исчезает** вместе с N: предел трения μN в сотни раз меньше,
   чем у Герца. Прилипания при μ = 0,1 нет ни у одного закона, включая Герца.
5. **«Дребезг» трения** в тестовой сцене оказался в основном артефактом метрики и длительности
   контакта. Удержание N (контрфакт) дребезг не лечит, а на боевой сцене усиливает его в 10 раз.
   Пошаговый дребезг надёжно есть у импульсного типа; у pinball на боевой сцене тоже появляются
   короткие серии.
6. **При 73 м/с все пять прогонов серии пробиты** — расхождение со статьёй, где при 73 м/с не пробито.
   Для Герца причина, видимо, в параметрах серии (σ_u = 2,3 ГПа, μ = 0,1). Для pinball и Swegle
   добавляется прохождение шара сквозь ткань.

## 1. Что реализовано

| Ключ | Значения | Смысл |
|---|---|---|
| `fiber_solid_contact_type`, `fiber_fiber_contact_type` | 0..3 | 0 = Герц (не «выключено»), 1 pinball, 2 Swegle, 3 импульсный |
| `*_penalty_scale` | 1.0 | Kp (типы 1, 2) |
| `*_impulse_gamma` | 1.0 | γ (тип 3), рабочий диапазон (0; 1,6] |

Основные решения:
- **опорный шаг нити** dt_ref = предел шага связей у бусин сегмента; у изолированной бусины —
  виртуальная связь длины d;
- **тип 3** строит силу по шагу прошлого цикла;
- **g.r = r₁ + r₂**, чтобы Swegle не отключался при пересечении осей (D = 0);
- **предел шага** берётся из слота на primitive — тот же расчёт, что и сила.

Свойства, важные для этого отчёта:
- **ноль в покое и при разлёте:** при ṗ ≤ 0 сила всех типов 1–3 равна нулю (у pinball F1 = 0,
  значит min(F1, F2) = 0). Слот трения при fn = 0 не заводится, трения на этом шаге нет;
- **pinball мягче Герца:** для одного материала F2 / F_Hertz = 3(1 − ν)/8 ≈ 0,26.

Проверки: `ctest` 96/96. При ключах = 0 Guo A, 1T_A и `guo2019_shot` побитово равны базе.

## 3. Разбор «дребезга» трения в кресте

Исходное наблюдение: в кресте с трением (μ = 0,2, v_t0 = 0,05 м/с) у типов 1–3 относительная
касательная скорость центров нитей меняла знак 11–23 раза против 4 у Герца. Отдельная диагностика
(`experiments/2026-10-16-fiber-contact-types-friction-chatter/`) мерила знак самой **силы трения**.
Гипотезы:

| гипотеза | суть | итог |
|---|---|---|
| H1 | трение пропадает на шагах с fn = 0 | для pinball и Swegle **опровергнута**: удержание N не убирает смены (155 → 151, 103 → 133); на шаги с fn = 0 и сразу после них приходится 0–6 % смен |
| H2 | фоновый дребезг проекции Якоби | у Герца почти нет (1 смена) — не основной механизм |
| H3 | скачет сам N | у импульсного типа **подтверждена**: N включается и выключается 705 раз за 1596 шагов |
| H4 | контакт без отскока дольше, поэтому смен больше | **подтверждена**: контакт в 19 раз дольше; при равной экспозиции 85 шагов смен силы: Герц 1, pinball 5, Swegle 0, импульсный 0 |

Характер смен:
- **pinball и Swegle** — медленное скольжение туда-обратно, медиана серии одного знака 7–9 шагов;
- **импульсный** — пошаговый дребезг, 81 % серий не длиннее 2 шагов.

Метрика по скорости центров для дребезга не годится: на пересечении почти всегда два контакта.

## 4. Боевая сцена: Guo 2019 1T base

Постановка:
- **удар и трение:** V0 = 73 м/с, μ = 0,1 на обоих контактах, t_max = 1,5 мс;
- **нить:** упругопластичная без вязкости и скоростной зависимости (`twaron_plastic_s23.fib`:
  `PLASTIC SY=2.04e9 H=100e9`, `FAILURE SIGMA_U=2.3e9`), E = 85 ГПа, страховочный `eps_break = 0.05`;
- **закон:** один и тот же на обоих контактах. «Удержание N» — контрфакт: на шаге с геометрическим
  контактом, но fn = 0, слот трения получает последнее ненулевое N (только диагностика);
- **статистика:** диагностическая сборка `-DSPH_CONTACT_STATS=ON`, без `--hold-n` траектория
  побитово та же.

### Выводы по гипотезам

- **G1, выпадение нормальной силы — подтверждено.** На нить–нить fn = 0 на 16–33 % контакт-шагов,
  на нить–Solid на 37–50 %. Удержание N эту долю не меняет: оно заполняет слоты трения, а не
  нормальную силу.
- **G2, потолок трения — подтверждено, но в другом виде, чем ожидалось.** Главное не пропуски шагов,
  а то, что и на шагах с силой N в сотни раз меньше Герца, так что предел трения μN почти нулевой.
  Сравнить прилипание нельзя: при μ = 0,1 его нет даже у Герца (меньше 0,01 % слотов), идёт
  сплошное скольжение.
- **G3, сила следует за скоростью проникания, а не за нагрузкой — подтверждено.** Pinball почти всё
  время на вязкой ветке F1 = m·ṗ/dt_ref. У Swegle почти всё время работает потолок m·ṗ/dt_ref,
  корреляция N с ṗ 0,93. С силой Герца, то есть с прижимом, корреляция слабая (0,04–0,57).
- **G4, дребезг — у pinball и Swegle на боевой сцене пошаговый.** 92 % серий одного направления
  длиной в 1 шаг, у Герца серии в основном длиннее 30 шагов. Смены направления на 0,4–0,5 %
  активных шагов против 0,2 % у Герца. **Удержание N вредно:** смены растут в 5–10 раз, и 93–98 % из
  них приходятся на шаги без силы. Удержанная N тормозит контакт, который уже расходится, и
  разворачивает скольжение.
- **G5, проникание — порог превышен.** δ/d нить–нить = 1,0, бусины уходят в шар (`n_tunnel` 55–81).
  Шар продавливает ткань при разрывах в допуске (8 вертикальных): после первого разрыва (~443 мкс)
  ткань его почти не тормозит.

Для сравнения: в отдельной серии подбора окна (pinball, нить σ_u = 2,5 ГПа, E = 97 ГПа, μ = 0,1)
скорость шара v_z ни разу не меняет знак. До ~600 мкс она падает от −70 до −39 м/с, а дальше за
~800 мкс — лишь до −32 м/с; пробой при 70 и 76 м/с.

## 5. Итог и открытые вопросы

- **В нынешнем виде законы 1–2 для нитей на боевой сцене непригодны:** нормальная сила слишком мала,
  ткань не удерживает шар, нити проходят друг сквозь друга. Дребезг трения на этом фоне вторичен.
  Тип 3 даёт пошаговый релейный дребезг N и необъяснённый отскок в тестовой сцене.
- **Возможная правка — «упругая часть + демпфер» (Кельвин — Фойгт / Хант — Кроссли):**
  F = F_упр(δ) + c·max(ṗ, 0). Упругая часть — Герц нитей или F2 pinball, c = Kp·m_red/dt_ref. Сила
  в покое остаётся, демпфирование только на сближении, при ṗ → 0 сила меняется непрерывно.
  Не реализовано, решение за владельцем.
- **Не проверено:**
  - контрольный выстрел Герца в новой постановке подбора окна (σ_u = 2,5, E = 97);
  - зависимость от μ при законах 1–2 (подбор окна идёт);
  - причина отскока у импульсного типа;
  - сходимость по шагу и разрешению.
- **Разброс OpenMP:** у порога 8 и 4 потока могут дать разные исходы (серия Guo2T), прогоны одиночные.

## Воспроизведение

- Сборка: `cmake --preset clang-windows -B build-cs -DSPH_CONTACT_STATS=ON`, цель `guo2019_shot`
  (на сервере: `-G Ninja -DCMAKE_BUILD_TYPE=Release -DSPH_DIM=3 -DSPH_CONTACT_STATS=ON
  -DCMAKE_CXX_FLAGS="-include cmath"`).
- Выстрел: `guo2019_shot --config=1T --level=base --v0=73 --mu=0.1 --t-max=1.5e-3 --n-mon=10
  --n-diag=100 --frames=off --fiber-inelastic=twaron_plastic_s23.fib --eps-break=0.05
  --contact-stats=10 --threads=4 --fs-contact=k --ff-contact=k [--hold-n]`.
- Сводки `contact_stats_summary.txt` и `shot.txt` пяти прогонов — в `data/`. CSV по шагам и кадры
  в репозиторий не входят: сервер `~/ct1T/`, локально scratchpad.
