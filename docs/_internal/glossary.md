# Глоссарий

Двуязычный словарь терминов проекта SPH. Русский — основной язык; английские
эквиваленты приведены для формул, идентификаторов кода и поиска по литературе.

## Основные термины

| Термин (RU) | Термин (EN) | Определение |
|---|---|---|
| Метод сглаженных частиц | Smoothed Particle Hydrodynamics (SPH) | Бессеточный численный метод, в котором среда дискретизируется набором частиц, переносящих физические свойства. |
| Частица | Particle | Расчётная точка, представляющая конечный объём среды и несущая массу, плотность, скорость, давление, тензор напряжений и т. д. |
| Ядро сглаживания | Smoothing kernel ($W$) | Весовая функция, определяющая вклад соседей в аппроксимацию поля в данной точке. Радиус действия — длина сглаживания $h$. |
| Длина сглаживания | Smoothing length ($h$) | Характерный радиус взаимодействия частицы с соседями (`hsml` в коде). |
| Соседние частицы | Neighbors | Пары частиц, расстояние между которыми не превышает $\kappa h$. Их список строится методами поиска соседей (`nnps`). |
| Уравнение состояния | Equation of State (EOS, УРС) | Соотношение $p = f(\rho, u)$, связывающее давление, плотность и внутреннюю энергию. |
| Ударная адиабата | Shock adiabatic (УА Тэта, Hugoniot) | Зависимость давления от сжатия на фронте ударной волны. |
| Псевдовязкость | Artificial viscosity | Член Монагана ($\alpha$, $\beta$), стабилизирующий распространение ударных волн в SPH. |
| Девиатор напряжений | Stress deviator | Симметричная бесследовая часть тензора напряжений ($s_{ij}$); описывает сдвиговые напряжения. |
| Интенсивность напряжений | Equivalent (von Mises) stress ($\sigma_i$) | Скалярная мера напряжённого состояния для критерия пластичности Мизеса. |
| Повреждённость | Damage ($D$) | Скаляр $D \in [0,1]$, описывающий накопление микротрещин (модель JH-2). |
| Виртуальные частицы | Virtual / ghost particles | Граничные частицы, отражающие реальные для учёта границ расчётной области. |

## Архитектурные термины

| Термин (RU) | Термин (EN) | Определение |
|---|---|---|
| SoA | Structure-of-Arrays | Представление данных, при котором каждый атрибут хранится в отдельном непрерывном массиве (`ParticleSystem`). |
| AoS | Array-of-Structures | Представление данных массивом структур `Particle` (исторический вариант, упразднён). |
| Поиск соседей | Neighbor search (`nnps`) | Построение списка пар взаимодействия. Исторически `direct_find`, `link_list`, `tree_search`; в текущем коде — `rhs::SpatialIndex<Dim>` (`include/rhs/spatial_index.hpp`), ключ `nnps` в конфигурации сохранён. |
| Конфигурация симуляции | SimulationConfig | Объект, инкапсулирующий runtime-параметры расчёта (CFL, $\alpha$, $\beta$, шаги вывода и т. д.). |
| Материалы | Materials | Подобъект `SimulationConfig`, хранящий материальные константы (УРС, прочность) по индексу `itype`. |
| ADR | Architecture Decision Record | Запись архитектурного решения в стандартной форме (контекст → решение → последствия). |
| Diátaxis | Diátaxis | Модель организации документации по четырём режимам: tutorial, how-to, reference, explanation. |
| Docs-as-Code | Docs-as-Code | Подход, при котором документация живёт в репозитории и проходит тот же процесс ревью, что и код. |

## Схема RHS и параллелизм

| Термин (RU) | Термин (EN) | Определение |
|---|---|---|
| RHS | Right-hand side | Правая часть уравнений движения за шаг: ускорения Solid и нитей, сведённые из всех взаимодействий. |
| Primitive | Primitive | Набор частиц/сегментов, на котором считается одно взаимодействие (пара частиц, пара сегментов, бусина + частица Solid и т. д.). Строится из результата поиска, во время RHS только читается. |
| Interaction kernel | Interaction kernel | Функция, превращающая primitive в вклады (contributions); без `#pragma omp`, mutex и atomic. |
| Вклад | Contribution (`ContributionWriter`) | Запись «частица, приращение, метаданные» в thread-local буфер (`rhs/contributions.hpp`). |
| Reduce по шардам | Owner-computes reduce | Суммирование вкладов: диапазон индексов частиц делится на шарды, каждый шард суммирует только свои частицы; порядок детерминирован и не зависит от числа потоков. |
| Исполнитель CPU | `CpuExecutor` | Обёртка над OpenMP (`parallel_for`, `parallel_reduce`, ...) — единственный способ параллелизма в kernels (`rhs/cpu_executor.hpp`). |
| Решатель ODE | ODESolver | `PredictorCorrectorSolver` (по умолчанию) и `EulerSolver`; ключ `ode_solver = 0 \| 1` (`include/ode/ode_solver.hpp`). |
| Множитель шага | `dt_scale` | Множитель общего шага $\Delta t$, допустимо $(0;1]$; нужен для проверки сходимости по шагу. |
| Чекпоинт | Checkpoint | Файл состояния для остановки и продолжения расчёта (`checkpoint_file`, `restart_file`, `--force`); см. [how-to](../02-how-to/05-restart-checkpoints.md). |

## Контакты

| Термин (RU) | Термин (EN) | Определение |
|---|---|---|
| Контакт Solid-Solid | Solid-Solid-Contact | Штрафная сила между частицами разных тел (`contact_force_type`: 0 выкл., 1 пинбол, 2 Свигл, 3 импульсный); [описание](../04-explanation/architecture/contact-particle-particle.md). |
| Тело | Body (`body[]`) | Номер тела частицы: `itype` для встроенных генераторов, PID детали для k-файла. Контакт Solid-Solid — между частицами с разными `body`. |
| Пинбол | Pinball (тип 1) | Сила $K_p\min(F_1,F_2)$: вязкая ветка и ветка Герца. |
| Свигл | Swegle (тип 2) | Сила $K_p\max(F_1,F_2)$ с потолком $m_{ij}\dot p/\Delta t_{\mathrm{ref}}$. |
| Импульсный контакт | Impulse (тип 3) | Сила гасит долю $\gamma$ нормальной скорости сближения за шаг; $\gamma$ — `contact_impulse_gamma`, рабочий диапазон $(0;1.6]$. |
| $K_p$ | Penalty scale | Безразмерный масштаб штрафной силы (`contact_penalty_scale`, `fiber_*_contact_penalty_scale`). |
| Закон контакта нитей | Fiber contact law | Закон нормальной силы Fiber-Solid / Fiber-Fiber, ключи `fiber_solid_contact_type`, `fiber_fiber_contact_type`: 0 Герц, 1 пинбол, 2 Свигл, 3 импульсный, 4 Герц + демпфер. Тип 0 — **не** «выключено». |
| Push (выталкивание) | Impulse push | Добавка к скорости сближения в законе 3 при глубоком проникании: $(p-\mathrm{depth}\cdot r)/\tau$ (`*_impulse_push_tau`, `push_depth`, `push_vmax`). В расчётах не используется (источник энергии), ключи сохранены для воспроизведения серий. |
| Герц + демпфер | Hertz + damper (закон 4) | $F=F_H+c\max(\dot p,0)$, $c=K_p m_{ij}/\Delta t_{\mathrm{ref}}$; упругая часть работает и в покое. |
| Fiber-Bond | Fiber-Bond | Связь между соседними бусинами нити: только растяжение, разрыв при $l>(1+\varepsilon_b)l^0$ в Postprocessing. |
| Fiber-Fiber-Contact | Fiber-Fiber-Contact | Контакт пар сегментов осей разных нитей, нормальная сила по Герцу или одному из законов 1-4. |
| Правило владения узлом | Node ownership rule | Правило, по которому контакт у узла нити достаётся ровно одному из двух соседних сегментов. |
| Трение нитей | Fiber friction | Проекция на уровне скоростей (не закон Кулона в RHS): импульс трения ограничен $\mu N h$ и точным прилипанием; коэффициенты `mu_ff` (нить-нить), `mu_fs` (нить-Solid). |
| Mass splitting | Mass splitting | Деление эффективной массы бусины/частицы на число активных контактов в проекции трения. |
| Зажим | Clamp | Кинематическое закрепление частиц Solid и бусин: $x(t)=x(0)$, $v=0$ для выбранных компонент; реализуется проекцией ускорений (`interactions/clamp.hpp`). |
| Изоляция по телам | `sph_same_body_only` | При `1` SPH-суммы Solid не связывают частицы разных тел; тела взаимодействуют только через контакт. |

## Модели и режимы

| Термин (RU) | Термин (EN) | Определение |
|---|---|---|
| XSPH | XSPH | Поправка скорости $\varepsilon\,\overline{\delta v}$ (`epsilon`, `av`). `xsph_mode = velocity` (по умолчанию) — поправка входит в скорость и позицию; `position` — классический XSPH Монагана, только в перенос позиции. |
| Модель Джонсона-Кука | Johnson-Cook (JC) | Модель прочности и разрушения; материалы `itype` 12-15, `strength/johnson_cook.hpp`; нагрев `jc_heating` (`energy` или `taylor_quinney`, доля `jc_chi`); [ADR-009](../04-explanation/decisions/adr-009-johnson-cook.md). |
| Осесимметрия | Axisymmetry (`axis_sim`) | Двумерная постановка в $(r,z)$; частицам у оси соответствуют зеркальные (ghost) частицы. |
| Зеркальные частицы | Ghost particles (`GhostSet`) | Образы реальных частиц у оси симметрии; с индексами `>= nreal`, контактов не образуют. |
| Энергетическая масса | `energy_mass` | В осесимметрии масса кольца $2\pi r_0 m$ для лога энергии; в 1D/3D равна $m$. |
| Лог энергии | Energy log | CSV баланса механической энергии (`energy_log_every`, `energy_log_file`); сборка `-DSPH_ENERGY_LOG=ON`. |
| Статистика контактов нитей | Contact stats | Диагностика (`contact_stats_every`); сборка `-DSPH_CONTACT_STATS=ON`. |
| Импорт `.k` | LS-DYNA `.k` import | Чтение входных данных LS-DYNA (`k_file`, `k_mode = solid \| solid_fiber`, `k_parts_file`). |
