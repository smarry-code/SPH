# ADR-001: Выбор метода SPH для моделирования ударно-волновых процессов

**Статус:** Принято
**Дата:** Этап миграции Fortran → C++

## Контекст

Проект моделирует высокоскоростное соударение, ударные волны и поведение
хрупких керамических материалов. Требуется численный метод, способный:

- корректно обрабатывать сильные разрывы (ударные волны);
- отслеживать большие деформации и фрагментацию без искажения сетки;
- работать с разнородными материалами (металлы, полимеры, керамика) и моделями
  прочности/повреждаемости (Мизес, JH-2).

Сеточные методы (Euler/Lagrange) плохо переносят фрагментацию и сильные
искажения сетки. Бессеточный лагранжев метод SPH естественно подходит к этой
задаче.

## Решение

Принят метод сглаженных частиц (SPH) с дискретизацией среды частицами,
переносящими физические свойства. Исходная реализация на Fortran мигрирована
на C++20 с OpenMP (её текст удалён из репозитория, доступен в истории git до коммита удаления).

## Последствия

**Положительные:**

- Естественная обработка больших деформаций и фрагментации;
- Единый лагранжев подход для металлов, полимеров и керамики;
- Возможность связывания с моделями прочности (Мизес) и повреждаемости (JH-2).

**Отрицательные:**

- Требуется псевдовязкость для стабилизации ударных волн (см. [главу 1](../models/01-sph-core.md#7-искусственная-вязкость-монагана));
- Чувствительность к числу соседей и длине сглаживания $h$;
- Вычислительная стоимость поиска соседей.

## Связанные файлы

- [`param.hpp`](../../../include/param.hpp): константы метода, размерность `dim`.
- [`kernel.hpp`](../../../include/kernel.hpp): ядра сглаживания.

## Актуальное состояние (2026-11)

Решение остаётся в силе. Отличия реализации от момента принятия:

- Прежние модели прочности (Мизес, JH-2) дополнены моделью Джонсона-Кука для
  металлов ([ADR-009](adr-009-johnson-cook.md),
  [`johnson_cook.hpp`](../../../include/strength/johnson_cook.hpp)).
- К SPH-частицам (Solid) добавлены нити из бусин (Fiber) с собственными контактами;
  архитектура правых частей описана в [ADR-008](adr-008-rhs-architecture-fiber.md).
- Контактные силы между частицами разных тел: [ADR-007](adr-007-contact-force-types.md).
- Шаг расчёта теперь собирается в
  [`single_step.cpp`](../../../src/single_step.cpp) и
  [`time_integration.cpp`](../../../src/time_integration.cpp) поверх
  [`include/rhs/`](../../../include/rhs/) и [`include/ode/ode_solver.hpp`](../../../include/ode/ode_solver.hpp).
