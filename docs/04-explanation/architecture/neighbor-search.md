# Методы поиска соседних частиц

> продового пути: `direct_find()/link_list()/FlatGrid` больше не собираются и не вызываются
> (`ctest`-набор их тоже не содержит). Их заменил единый механизм
> `CpuExecutor` + `SpatialIndex<Dim>` + `ContributionWriter`/reduce по
> шардам — см. `fiber/SPH.md`, раздел «CPU», и
> [ADR-008](../decisions/adr-008-rhs-architecture-fiber.md). Текст ниже

Поиск соседей (neighbor search, параметр `nnps` в
[`SimulationConfig`](../../../include/simulation_config.hpp:29)) строит список
пар взаимодействия — основу всех парных вычислений SPH. Диспетчеризация
выполняется в [`single_step()`](../../../src/single_step.cpp:108).

## Доступные методы

| `nnps` | Метод | Функция | Сложность | Назначение |
|---|---|---|---|---|
| `1` | Прямой поиск | [`direct_find()`](../../../src/direct_find.cpp:7) | $O(N^2)$ | Малые задачи, эталон |
| `2` | [Связный список (сетка)](linked-list.md) | [`link_list()`](../../../src/linked_list.cpp) | $O(N)$ | Регулярные/большие задачи |
| `3` | Дерево | `tree_search()` | $O(N \log N)$ | Неоднородные распределения (заглушка) |

## Общие выходы

Все методы заполняют единый набор массивов пар:

| Массив | Содержание |
|---|---|
| `pair_i[k]`, `pair_j[k]` | Индексы частиц пары $k$ (0-базовые) |
| `w[k]` | Значение ядра $W(r_{ij}, h)$ |
| `dwdx[k][d]` | Градиент ядра $\nabla W$ по компоненте $d$ |
| `countiac[i]` | Число соседей частицы $i$ |
| `niac` | Общее число пар |

## Построение графа пар

После поиска соседей [`single_step()`](../../../src/single_step.cpp:135)
строит [`PairGraph::build()`](../../../include/pair_graph.hpp:53) и выполняет
[окраску графа конфликтов](parallelism.md). `PairGraph` переиспользуется всеми
потребителями пар (`int_force`, `density`, `art_visc`, `av_vel`).

## Выбор метода

- **`nnps = 1` (по умолчанию):** для текущих кейсов ($N \le 5000$) прямой поиск
  прост, не требует сетки и используется как baseline.
- **`nnps = 2`:** при росте $N$ связный список даёт линейное время за счёт
  разбиения пространства на ячейки сетки размера $\sim 2h$. Подробное устройство
  метода (сетка `FlatGrid`, парный цикл, сложность) — в разделе
  [Поиск соседей методом связного списка](linked-list.md).
- **`nnps = 3`:** для сильно неоднородных распределений (адаптивное разрешение).
