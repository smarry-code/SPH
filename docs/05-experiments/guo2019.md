# Guo 2019 — стальной шар по ткани и Al-пластине

Карточка кейса — [`cases/guo2019/README.md`](../../cases/guo2019/README.md), ТЗ —
[`notes/guo2019/guo2019-experiments-tz.md`](../../notes/guo2019/guo2019-experiments-tz.md),
полный справочник ключей утилиты — [`guo2019_shot`](../03-reference/guo2019-shot.md).

## Опыт

Guo et al., IJIE 127 (2019) 1–16. Стальной шар (D = 12 мм, m = 7 г) бьёт по мишени
поперёк. Мишень — алюминиевая пластина 6061-T6 толщиной 1,6 мм, слои ткани Twaron CT 717 или
их сочетание. Пластина и ткань зажаты по краям |y| ≥ 60 мм, окно 120 мм. Опыт даёт
баллистический предел $V_{BL}$ — скорость, выше которой шар пробивает мишень. Модель ищет
его серией выстрелов. Расчёт трёхмерный: шар и пластина — частицы SPH (Solid), ткань — нити
из бусин (Fiber).

| Конфигурация (`--config`) | Мишень | $V_{BL}$ статьи, м/с |
|---|---|---|
| `A` | одна Al-пластина | 128 (+4 / −1) |
| `1T` | один слой ткани | 76 ± 3 |
| `1T_A` (`1T/A`) | ткань спереди, пластина сзади | 178 (+6 / −8) |
| `A_1T` (`A/1T`) | пластина спереди, ткань сзади | 148 ± 3 |
| `2T` | два несклеенных слоя ткани | 147 ± 3 |
| `4T` | четыре слоя ткани | 258 (+8 / −5) |
| `<k>T`, k = 1…64 | k слоёв ткани без пластины | нет в статье (оценка) |

Числа опыта, скорости выстрелов статьи и допуски —
[`cases/guo2019/experiment/guo2019_case.hpp`](../../cases/guo2019/experiment/guo2019_case.hpp),
построение сцены — [`guo2019_scene.hpp`](../../cases/guo2019/experiment/guo2019_scene.hpp),
монитор исхода — [`guo2019_monitor.hpp`](../../cases/guo2019/experiment/guo2019_monitor.hpp).

### Уровни разрешения (`--level`)

| Уровень | Шар D, мм / Δx, мм | Пластина: окно, слоёв по толщине | Ткань: нитей, сегментов на полуволну | Назначение |
|---|---|---|---|---|
| `smoke` | 4 / 0,8 (масса по объёму) | 14 × 14 мм, 2 | 12 × 12, 2 | Проверка запуска, секунды–минуты |
| `base` | 12 / 0,6 | 120 мм, 3 | 102 × 102, 2 | Основной уровень серий |
| `fine` | 12 / 0,4 | 120 мм, 4 | 102 × 102, 4 | Проверка сходимости |
| `scaled` | 6 / 0,3, плотность ×2 (1,75 г) | 30 мм, t = 0,8 мм, 3 | 26 × 26, 2 | Уменьшенная постановка (решение владельца 2026-10-01, отступление от ТЗ); `t_max` ×0,5 |

## Запуск

Утилита [`guo2019_shot`](../../cases/guo2019/experiment/guo2019_shot.cpp) собирается из
экспериментальной копии постановки и всегда с `SPH_DIM=3`.

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --target guo2019_shot
```

Обязательны `--config`, `--level`, `--out` и ровно одно из `--v0`, `--v0-list`,
`--paper-shots`. Примеры:

```bash
# Один пробный выстрел: 1 слой ткани, грубая сцена, 147 м/с
OMP_NUM_THREADS=4 ./build/guo2019_shot --config=1T --level=smoke --v0=147 \
    --out=runs/guo-1T-smoke --threads=4

# Серия по скоростям статьи для пластины + поиск V_BL (бисекция и повторы включаются сами)
OMP_NUM_THREADS=4 ./build/guo2019_shot --config=A --level=base --paper-shots \
    --out=runs/guo-A-base --threads=4 --checkpoint-every=5000

# Свои скорости, другое трение и кадры для ParaView
OMP_NUM_THREADS=4 ./build/guo2019_shot --config=2T --level=base --v0-list=140,150,160 \
    --mu=0.27 --frames=camera --out=runs/guo-2T-mu027 --threads=4

# Пакет из 6 слоёв, стальной шар 1 г (D = 6,253 мм), 550 м/с, слои сшиты сеткой 3 × 3 патча
OMP_NUM_THREADS=4 ./build/guo2019_shot --config=6T --level=base --v0=550 \
    --ball-d=6.253e-3 --ball-mass=1e-3 --ball-dx=3e-4 \
    --stitch=grid --stitch-tile=3 --out=runs/kT-6T --threads=4

# Мозаика: 2 слоя, по своей раскройке на 7 фрагментов на каждый слой, поле 50 × 70 мм
OMP_NUM_THREADS=4 ./build/guo2019_shot --config=2T --level=base --v0=147 \
    --random-cut=7 --cut-seed=1 --layers-per-cut=1 --cut-size=0.05x0.07 --cut-clamp-edge=0.025 \
    --out=runs/guo-2T-mosaic --threads=4

# Расчёт оборвался — продолжить с последнего чекпоинта (те же ключи физики + --restart)
OMP_NUM_THREADS=4 ./build/guo2019_shot --config=A --level=base --paper-shots \
    --out=runs/guo-A-base --threads=4 --checkpoint-every=5000 --restart
```

`--help` печатает справку. Код выхода 2 — ошибка в ключах. Код 0 возвращается и тогда,
когда отдельный выстрел упал с исключением: ищите в выводе `ОШИБКА`.

### Что получается

Каждый выстрел считается в своей свежей сцене, в каталоге
`<out>/<cfg>_<level>[теги]_v<V0>_r<повтор>/` (например, `runs/guo-1T-smoke/1T_smoke_v147.0_r0/`):

| Файл | Содержимое |
|---|---|
| `shot.txt` | Строка `ключ=значение`: `outcome` (пробит / не пробит), остаточная скорость `V_R`, поглощённая энергия `e`, `t_end`, порванные нити, прогиб, баланс энергии, затраты времени |
| `monitor.csv` | Монитор по шагам |
| `sph_output_*.txt`, `fiber_output_*.txt` | Кадры Solid и нитей (с `--frames=camera` или `--save-t`) |
| `guo2019_fabric.fib`, `guo2019_fabric_layout.txt` | Сгенерированная ткань и раскладка нитей |
| `checkpoint.ckpt`, `.prev` | Чекпоинты (с `--checkpoint`) |
| `log.txt` | Журнал конвейера |

В `<out>` после каждого выстрела обновляются сводки серии `shots.csv` (строка на выстрел) и
`vbl.txt` (интервал «не пробит / пробит», средняя энергия, $V_{BL}$ модели и статьи).
Подробно — [«Выходные файлы»](../03-reference/guo2019-shot.md#выходные-файлы).

!!! warning "Стёжки нет в имени каталога"
    Варианты с разной `--stitch*` получают одно имя каталога выстрела и перезаписывают друг
    друга. Запускайте их в разные `--out`.

## Ключи эксперимента

Ниже — основные ключи по группам. Полные таблицы с диапазонами, правилами совместимости и
форматом `shot.txt` — в [справочнике `guo2019_shot`](../03-reference/guo2019-shot.md#ключи).

### Мишень и серия

| Ключ | По умолчанию | Описание |
|---|---|---|
| `--config=` | обязателен | `A`, `1T`, `1T_A`, `A_1T`, `<k>T` (k = 1…64) |
| `--level=` | обязателен | `smoke`, `base`, `fine`, `scaled` |
| `--v0=` / `--v0-list=a,b,c` / `--paper-shots` | одно обязательно | Одна скорость, список скоростей (м/с) или скорости опытов статьи (+ `--bracket`, `--repeat=2`) |
| `--out=` | обязателен | Каталог серии |
| `--bracket` / `--no-bracket` | вкл. с `--paper-shots` | До 6 выстрелов бисекции границы «пробит / не пробит», пока интервал больше 5 м/с |
| `--repeat=` | 1 (2 с `--paper-shots`) | Повторы для скоростей вблизи $V_{BL}$ модели |
| `--t-max=` | по конфигурации: `A` 600 мкс, `1T` 1000, `1T_A`/`A_1T`/`2T` 800, `4T`/`<k>T` 600 | Потолок времени выстрела, с |
| `--plate-nz=` | по уровню | Число слоёв пластины по толщине |
| `--no-body-isolation` | изоляция вкл. | Выключить `sph_same_body_only` (шар «приваривается» к пробке) |

### Шар и ткань

| Ключ | По умолчанию | Описание |
|---|---|---|
| `--ball-d=`, `--ball-mass=`, `--ball-dx=` | по уровню | Диаметр (м), масса (кг), шаг решётки шара (м); плотность выводится |
| `--fabric-n=`, `--fabric-clamp-edge=`, `--fabric-overhang-y=` | по уровню | Число нитей, граница зажима, выступ нитей; только `<k>T` |
| `--eps-break=`, `--fiber-E=` | из сцены (0,03; 85 ГПа) | Предельная деформация и модуль нити |
| `--fiber-inelastic=<файл>` | — | Пластичность, вязкость, разрушение нити (директивы формата `.fib`) |

### Трение и контакт нитей

| Ключ | По умолчанию | Описание |
|---|---|---|
| `--mu=` | 0,3 | Трение нить–нить и нить–Solid одновременно |
| `--mu-ff=`, `--mu-fs=` | из `--mu` | Трение по отдельности |
| `--ff-contact=`, `--fs-contact=` | 0 (Герц) | Закон нормальной силы, 0…4 ([контакт нитей](../04-explanation/models/05-fiber-contact.md)) |
| `--ff-contact-predictor=`, `--fs-contact-predictor=` | 0 | Законы 1–3 как проекция скорости |
| `--contact-proj-iters=`, `--contact-proj-warm=` | 8; 1 | Итерации Якоби и тёплый старт проекции |
| `--impulse-gamma=`, `--impulse-push-tau=`, `--impulse-push-depth=`, `--impulse-push-vmax=` | 1; 0; 0,1; 0 | Параметры импульсного закона 3 и выталкивания |
| `--dt-scale=` | 1 | Множитель шага по времени |

### Стёжка и мозаика

| Ключ | По умолчанию | Описание |
|---|---|---|
| `--stitch=` | `none` | `grid` — стежки между слоями по линиям патчей (≥ 2 слоёв), `seam` — шов в плоскости слоя |
| `--stitch-tile=` / `--stitch-patch=` | 3 / — | Сетка N × N патчей или патчи по P нитей от центра |
| `--stitch-lines=`, `--stitch-every=` | `xy`; 1 | Какие линии шва и шаг проколов |
| `--stitch-E=`, `--stitch-d=`, `--stitch-eps-break=` | 85 ГПа; 0,2 мм; 0,03 | Материал стежка |
| `--random-cut=N` | — | Мозаичная ткань из N фрагментов раскройки Вороного |
| `--cut-seed=`, `--layers-per-cut=`, `--cut-gap=`, `--cut-rot-max=`, `--cut-stitch-step=` | 1; 0 (весь пакет); d нити; 25°; p | Зерно, слоёв на раскройку, зазор, поворот фрагментов, шаг стежков по шву |
| `--cut-size=WxH`, `--cut-clamp-edge=` | габарит и зажим уровня | Своё поле мозаики по центру (м) и граница его зажима |

Устройство одеяла и мозаики — [«Ткани»](../04-explanation/models/07-fabrics.md).

## Изменение постановки

Под расчёт правится только [`cases/guo2019/experiment/`](../../cases/guo2019/experiment/).
Копию в `regression/` берёт `ctest`: смоук-прогоны `e2e_guo2019_smoke_A`, `_1T`, `_1T_A`,
`_A_1T`, `_2T`, `_4T`, а также `test_energy_log`, `test_fiber_plasticity_guo` и
`test_plain_weave_quilt`. Копия заморожена
([правила](../../cases/README.md#роли-постановок)). Расхождение копий показывает
`diff -r cases/guo2019/regression cases/guo2019/experiment`.

На той же экспериментальной копии работают ещё две утилиты:

- [`tools/fabric_checks`](../../tools/fabric_checks/fabric_checks.cpp) — проверочные сцены
  ткани: `strip` (растяжение полоски), `capstan` (тест Эйлера), `drum` (колебания лоскута);
- [`fiber_t0_dump`](../../cases/guo2019/experiment/fiber_t0_dump.cpp) — дамп нитей после N
  шагов для побитового сравнения деревьев (`--target fiber_t0_dump`, не собирается по
  умолчанию).
