# Керамика: кейсы без постановки

Кейсы BC1, BC3–BC5, BC7–BC10 (карбид бора) и AO1 (оксид алюминия) достались из архива
расчётов старого кода. От них сохранились только параметры решателя и эталонные кривые
скорости. Геометрии, материалов, скорости удара и места монитора в архиве нет, источник
опытов не установлен. Поэтому **запустить эти кейсы сейчас нельзя**: в коде нет их
постановки, и программы для них нет.

В каталоге каждого кейса лежат:

- `source/initial-conditions.txt` — параметры решателя старого кода в формате
  `Initial_Conditions.txt`; у AO1 этого файла нет;
- `source/reference-curve.txt` — две колонки: время, с; скорость, м/с;
- `source/reference-curve.jpg` — график (у всех, кроме BC1).

У AO1 есть ещё одно препятствие: строка констант JH-2 для Al₂O₃ (`itype` 11) не
проверена, и проверенных констант не будет (решение владельца). Расчёт AO1 на ней даёт
лишь неподтверждённую оценку, см. [реестр материалов](../03-reference/materials/registry.md).

## Как превратить кейс в запускаемый

По образцу [BC2](ceramics-bc2.md) и [BC6](ceramics-bc6.md):

1. Найти источник опыта: толщины и радиусы слоёв, материалы, плотности, скорость удара,
   точку измерения. Записать его в п. 2 карточки `cases/<кейс>/README.md`.
2. Завести `cases/<кейс>/experiment/`:
   - `<кейс>_case.hpp` — числа опыта;
   - `<кейс>_geometry.hpp` — построение частиц (общее правило ячеек —
     [`cases/common/lattice.hpp`](../../cases/common/lattice.hpp));
   - `initial_conditions.txt` — из `source/initial-conditions.txt`;
   - `reference.txt` — из `source/reference-curve.txt`, если нужна сверка.
3. Добавить программу запуска и цель CMake с `SPH_DIM=2` и
   `sph_case(<цель> <кейс> experiment)`, как у `test_e2e_bc6`.
4. Если кейс нужен в `ctest`, заморозить копию в `regression/`
   ([правила ролей](../../cases/README.md#роли-постановок)).
