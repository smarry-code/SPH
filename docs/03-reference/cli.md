# Параметры запуска

Исполняемый файл `SPH` (на Windows — `SPH.exe`) не принимает аргументов командной
строки. Вся конфигурация берётся из файлов и compile-time констант.

## Каталог запуска

Программа использует **текущий рабочий каталог** для размещения входных и
выходных файлов:

| Файл | Роль | Создаётся/читается |
|---|---|---|
| `Initial_Conditions.txt` | Входная конфигурация | Читается в `input()` |
| `sph_output_NNNNN.txt` | Кадры состояния | Создаётся в `output()` |
| `sph_gp.csv` | Накопительный дамп | Дозаписывается в `output()` |
| `log.txt` | Журнал | Создаётся в `main()`, дозаписывается |
| `../data/particles.dat` | Загрузка конфигурации | Читается при `config_input=true` |

## Консольный вывод

В процессе расчёта выводится прогресс (шаг, время, шаг по времени `dt`), а при
сохранении кадра — имя выходного файла. При сборке с `-DSPH_PROFILE=ON`
дополнительно накапливается `force_timing.csv` с замерами фаз.

## Сценарии расчёта

Сценарий задаётся compile-time флагами в [`param.hpp`](../../../include/param.hpp):

| Флаг | Описание |
|---|---|
| [`shocktube`](../../../include/param.hpp:275) | Тест «ударная труба» (по умолчанию `true`) |
| [`shearcavity`](../../../include/param.hpp:276) | Тест «сдвиговая каверна» |
| [`dim`](../../../include/param.hpp:8) | Размерность задачи (1/2/3) |
| [`config_input`](../../../include/param.hpp:251) | Загрузка из `../data/particles.dat` |
