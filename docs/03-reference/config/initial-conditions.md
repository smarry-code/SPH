# Формат `Initial_Conditions.txt`

Текстовый файл конфигурации расчёта. Разбирается функцией
[`parse_sph_config()`](../../../src/input.cpp:245) (объявление — в
[`input.hpp`](../../../include/input.hpp:13)) и заполняет поля
[`SimulationConfig`](../../../include/simulation_config.hpp:25).

## Общие правила синтаксиса

- Одна директива на строку в формате `ключ = значение`.
- Пробелы вокруг `=` и по краям строки игнорируются.
- Пустые строки пропускаются.
- Строки, начинающиеся с символа `*`, трактуются как **комментарии** и игнорируются.
- Строки без знака `=` пропускаются.
- Ключи, отсутствующие в файле, сохраняют значения по умолчанию из
  [`SimulationConfig::apply_defaults()`](../../../include/simulation_config.hpp:68).
- Неизвестные ключи игнорируются.

## Поддерживаемые ключи

| Ключ | Тип | Значение по умолчанию | Поле `SimulationConfig` | Описание |
|---|---|---|---|---|
| `pa_sph` | int | `2` | `pa_sph` | Метод аппроксимации давления (1/2) |
| `nnps` | int | `1` | `nnps` | Метод поиска соседей (1 = direct_find, 2 = link_list, 3 = tree_search) |
| `sle` | int | `1` | `sle` | Алгоритм обновления длины сглаживания |
| `skf` | int | `1` | `skf` | Тип ядра сглаживания |
| `CFL` | double | `0.1` | `CFL` | Число Куранта |
| `epsilon` | double | `0.3` | `epsilon` | Усреднение скоростей (Monaghan 1992) |
| `alpha` | double | `1.0` | `alpha` | Линейный коэффициент псевдовязкости |
| `beta` | double | `1.0` | `beta` | Квадратичный коэффициент псевдовязкости |
| `etq` | double | `0.01` | `etq` | Параметр отсечки псевдовязкости |
| `density_method` | int | `1` | `density_method` | Метод расчёта плотности (1/2/3) |
| `coloring_niac_threshold` | int | `0` | `coloring_niac_threshold` | Порог включения graph coloring (0 = всегда atomic) |
| `t_total` | double | `3e-6` | `t_total` | Полное время расчёта, с |
| `save_t` | double | `2.5e-8` | `save_t` | Интервал сохранения кадров, с |
| `print_step` | int | `50` | `print_step` | Шаг вывода прогресса на экран |
| `contact_force_type` | int | `0` | `contact_force_type` | Контакт «частица-частица» (ADR-007): 0 — выключен, 1 — пинбол Белицко, 2 — Свигл, 3 — импульсный. Значение вне 0..3 откатывается к 0 |
| `contact_penalty_scale` | double | `1.0` | `contact_penalty_scale` | Масштабный коэффициент $K_p$ штрафной силы (типы 1-2) |

!!! warning "Параметры вне файла"
    Поля `maxn`, `max_interaction` вычисляются в `main()` после инициализации
    (`ntotal * 1.4` и `100 * maxn`) и **не** задаются в файле конфигурации.
    Размерность `dim` и логические флаги (`shocktube`, `visc_artificial`, ...)
    — compile-time константы в [`param.hpp`](../../../include/param.hpp) и
    требуют перекомпиляции.

## Пример файла

```text
* Конфигурация расчёта: ударная труба, 5000 частиц
* Поиск соседей: direct_find (1)
nnps = 1
skf = 1
sle = 1

* Псевдовязкость Монагана
alpha = 1.0
beta  = 1.0
etq   = 0.01

* Временной цикл
CFL       = 0.1
t_total   = 3e-6
save_t    = 2.5e-8
print_step = 50

* Параллелизм
coloring_niac_threshold = 0
```

## Проверка

Файл загружается в начале [`input()`](../../../src/input.cpp:626). При
некорректном числовом значении `std::stod`/`std::stoi` выбросит исключение
`std::invalid_argument`, которое прервёт запуск с понятным сообщением.
