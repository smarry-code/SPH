# Справочник `SimulationConfig`

Объект [`SimulationConfig`](../../../include/simulation_config.hpp:25)
инкапсулирует runtime-параметры расчёта. Значения по умолчанию задаются в
[`apply_defaults()`](../../../include/simulation_config.hpp:68) и могут быть
переопределены в [`Initial_Conditions.txt`](initial-conditions.md).

## Поля

### SPH-метод и алгоритмы

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `pa_sph` | int | `2` | Метод аппроксимации давления (1/2) |
| `nnps` | int | `1` | Метод поиска соседей (1=direct, 2=link_list, 3=tree) |
| `sle` | int | `1` | Алгоритм обновления длины сглаживания |
| `skf` | int | `1` | Тип ядра сглаживания |
| `density_method` | int | `1` | Метод расчёта плотности (1/2/3) |
| `coloring_niac_threshold` | int | `0` | Порог graph coloring (0 = всегда atomic) |

### Шаг по времени и вывод

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `CFL` | double | `0.1` | Число Куранта |
| `t_total` | double | `3e-6` | Полное время расчёта, с |
| `save_t` | double | `2.5e-8` | Интервал сохранения кадров, с |
| `print_step` | int | `50` | Шаг вывода прогресса |

### Вязкость / диффузия / усреднение

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `alpha` | double | `1.0` | Линейный коэффициент псевдовязкости |
| `beta` | double | `1.0` | Квадратичный коэффициент псевдовязкости |
| `etq` | double | `0.01` | Параметр отсечки псевдовязкости |
| `epsilon` | double | `0.3` | Усреднение скоростей |
| `xi` | double | `0.001` | Интенсивность диффузии плотности |
| `epsilon_h` | double | `0.01` | Регуляризатор знаменателя `psi_ij` |

### Параллелизм

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `num_threads` | int | `7` | Число потоков OpenMP |

### Runtime-размеры (вычисляются в `main`)

| Поле | Тип | Назначение |
|---|---|---|
| `maxn` | size_t | Ёмкость под частицы (`ntotal * 1.4`) |
| `max_interaction` | size_t | Ёмкость под пары (`100 * maxn`) |
| `moni_particle` | size_t | Индекс мониториируемой частицы |
| `mats` | `Materials` | Материальные константы (см. [реестр](../materials/registry.md)) |
