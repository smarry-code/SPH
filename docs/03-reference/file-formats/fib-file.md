# Файл нитей `.fib` и вывод нитей

Файл `.fib` описывает ломаные нити и их материалы. Он читается функцией
[`load_fiber_file`](../../../src/fiber_input.cpp) и требует сборки с `SPH_DIM=3`. Директива `MATERIAL` разбирается
общей функцией `parse_material_directive` (та же строка есть в [таблице деталей `.k`](k-parts.md)); директивы
неупругости из этой страницы поддерживает только `.fib`.

Формат текстовый, разделители - пробелы, комментарий начинается с `#`, пустые строки игнорируются.

## Основные директивы

| Директива | Назначение |
|---|---|
| `MATERIAL <id> <E> <nu> <d> <rho> <eps_break> [mu_ff [mu_fs]]` | материал нити: модуль Юнга, коэффициент Пуассона, диаметр, плотность, деформация разрыва, необязательные трения нить-нить и нить-Solid |
| `FIBER <material_id> <N>` + `N` строк `x y z` | одна ломаная в ненагруженной конфигурации, `N >= 2` |
| `CLAMP_BOX <xmin> <ymin> <zmin> <xmax> <ymax> <zmax> [mask]` | закрепление бусин в боксе |
| `BOND <bead_i> <bead_j> <material_id>` | связь-стежок между двумя бусинами (глобальные индексы с нуля, в порядке блоков `FIBER`). Обычно бусины разных нитей, но загрузчик это не проверяет; требуется только `i != j`. `l0` — расстояние между бусинами в начальной конфигурации, `l_break = (1 + eps_break)·l0` по материалу связи. Только растяжение. Жёсткость и диаметр берутся из материала `<material_id>`. `prev`/`next` и `object_id` не меняются; масса бусин не меняется (масса швейной нити не учитывается) |

Материал должен быть объявлен до первой ссылки на него из `FIBER`. Материал, на который ссылается `BOND`, может быть объявлен в любом месте файла (до или после `BOND`). Без директив из следующего раздела связь
упругая: сила $F = EA\,\max(\varepsilon, 0)$, $\varepsilon = l/l_0 - 1$, разрыв при $\varepsilon > \varepsilon_{break}$.

Ошибки `BOND` (`std::runtime_error` с номером строки): неверный формат или лишние токены после `material_id`; индекс бусины вне диапазона `[0, N)` (проверяется после чтения всех `FIBER`); `bead_i == bead_j`; материал не объявлен `MATERIAL`; `l0 = 0` (совпадающие бусины).

## Неупругость связи

Директивы `PLASTIC`, `PLASTIC_TABLE`, `RATE`, `VISCO`, `FAILURE` включают для материала с данным `id`
пластичность, скоростную зависимость, вязкоупругость и дополнительные критерии разрыва. Модель
(реологическая схема, возврат на поверхность текучести, устойчивость шага) описана в
[`fiber/fiber-plasticity-design.md`](../../../fiber/fiber-plasticity-design.md). Без этих директив результат расчёта
не меняется (все параметры выключены).

Общие правила:

- формат `КЛЮЧ=значение`, ключи в любом порядке, регистр ключей и имён моделей не важен, пробелов вокруг `=` нет;
- числа должны быть конечными;
- директивы можно ставить до и после `MATERIAL` и `FIBER`: ссылка на `id` проверяется после чтения всего файла, но
  материал с этим `id` должен быть объявлен где-нибудь в файле;
- каждая директива может встретиться для одного `id` не более одного раза;
- повторный `MATERIAL` с тем же `id` заменяет упругие параметры (действует последнее определение), а параметры
  неупругости из директив сохраняются и применяются к последнему определению;
- ключевые слова директив (`PLASTIC`, `RATE`, ...) пишутся заглавными, как и `MATERIAL`/`FIBER`; файлы с окончаниями
  строк CRLF читаются;
- ошибка - `std::runtime_error` с именем директивы, причиной и номером строки.

### `PLASTIC` - предел текучести и упрочнение

```text
PLASTIC <id> SY=<Па> [H=<Па>]            # линейное: σ_s = SY + H·ε_p
PLASTIC <id> SY=<Па> K=<Па> N=<число>    # степенное: σ_s = SY + K·ε_p^N
```

| Ключ | Условие | Смысл |
|---|---|---|
| `SY` | обязателен, `> 0` | начальный предел текучести $\sigma_{y0}$ |
| `H` | `>= 0` | модуль линейного упрочнения; не задан - идеальная пластичность |
| `K` | `>= 0` | коэффициент степенного упрочнения |
| `N` | `0 < N <= 1` | показатель степенного упрочнения |

`H` несовместим с `K`/`N`; `K` и `N` задаются только вместе.

### `PLASTIC_TABLE` - табличное упрочнение

```text
PLASTIC_TABLE <id> <N>
<eps_p> <sigma_s>      # N строк
```

Кусочно-линейная кривая $\sigma_s(\varepsilon_p)$; за последней точкой значение постоянно. Условия: `N >= 2`;
первая точка имеет `eps_p = 0`; `eps_p` строго возрастает; `sigma_s > 0` и не убывает. В строках таблицы допустимы
комментарии и пустые строки (они не считаются). `PLASTIC` и `PLASTIC_TABLE` для одного `id` вместе задавать нельзя.

### `RATE` - зависимость предела текучести от скорости

Требует `PLASTIC` или `PLASTIC_TABLE` для того же `id`.

```text
RATE <id> CS      C=<1/с> P=<число>          # Cowper-Symonds: R = 1 + (ε̇_p/C)^(1/P)
RATE <id> JC      C=<число> EDOT0=<1/с>      # Johnson-Cook:  R = 1 + C·ln(max(ε̇_p/EDOT0, 1))
RATE <id> PERZYNA ETA=<Па·с^M> M=<число>     # Perzyna: σ_y = σ_s + ETA·ε̇_p^M
```

| Модель | Условия |
|---|---|
| `CS` | `C > 0`, `P >= 1`, оба обязательны |
| `JC` | `C > 0`, `EDOT0 > 0`, оба обязательны |
| `PERZYNA` | `ETA > 0`, `M > 0`, оба обязательны |

### `VISCO` - вязкоупругость

```text
VISCO <id> [ETA=<Па·с>] [XI=<число>] [E1=<Па> TAU=<с>]
```

| Ключ | Условие | Смысл |
|---|---|---|
| `ETA` | `>= 0` | вязкость демпфера Кельвина, $\sigma_\eta = \eta\dot\varepsilon$ |
| `XI` | `>= 0` | то же через долю критического демпфирования связи (не зависит от числа бусин) |
| `E1` | `>= 0` | модуль ветви Максвелла |
| `TAU` | `> 0` | время релаксации ветви Максвелла |

`ETA` и `XI` одновременно с ненулевыми значениями задавать нельзя. `E1 > 0` требует `TAU`; `TAU` без `E1 > 0`
- ошибка. Должен быть задан хотя бы один ключ. Демпфер Кельвина ужесточает ограничение шага по времени (раздел 5
дизайна).

`VISCO` с нулевыми `ETA`/`XI` (и без `E1 > 0`) допустима, но неупругости не включает: материал остаётся упругим
(`FiberMaterial::inelastic() == false`), расчёт и формат вывода прежние.

### `FAILURE` - критерии разрыва

```text
FAILURE <id> [EPS_P=<число>] [SIGMA_U=<Па>]
```

| Ключ | Условие | Критерий |
|---|---|---|
| `EPS_P` | `> 0` | разрыв, когда накопленная пластическая деформация $\varepsilon_p \ge$ `EPS_P` |
| `SIGMA_U` | `> 0` | разрыв, когда упругое напряжение $\sigma_{ep} = E(\varepsilon - \varepsilon_p) \ge$ `SIGMA_U`, Па |

Нужен хотя бы один ключ. Критерий `eps_break` из `MATERIAL` ($l > l_{break}$) продолжает действовать; связь рвётся
при срабатывании **любого** из включённых критериев. Критерии проверяются после обновления внутренних переменных
связи на шаге (проход Postprocessing), то есть по конечному состоянию шага: связь рвётся на том шаге, на котором
$\varepsilon_p$ или $\sigma_{ep}$ достигли порога (равенство тоже разрыв). Состояние уцелевших связей разрыв не
меняет.

`FAILURE` работает и без `PLASTIC`/`VISCO`: материал с одним `SIGMA_U` - хрупкий упругий ($\sigma_{ep} = E\varepsilon$,
разрыв при $E\varepsilon \ge$ `SIGMA_U`), силы и ограничение шага при этом остаются упругими (побитово прежними).
`EPS_P` без пластики не срабатывает никогда ($\varepsilon_p \equiv 0$). Для связей с вязким членом $\sigma_{ep}$ не
включает ветвь Максвелла и демпфер Кельвина (только упругая часть последовательно с пластикой).

Если `EPS_P > 0` задан для материала без `PLASTIC`/`PLASTIC_TABLE`, загрузчик печатает предупреждение в `std::cerr`
(«Предупреждение: FAILURE EPS_P ... критерий EPS_P никогда не сработает»). Это не ошибка: файл загружается, расчёт
идёт, а критерий `EPS_P` просто не срабатывает. `SIGMA_U` без пластики предупреждения не вызывает -- он работает.

### Пример

```text
# Капрон с упрочнением, скоростной зависимостью и релаксацией
MATERIAL 0 2.0e9 0.35 1.0e-4 1140.0 0.40
PLASTIC  0 SY=60e6 H=0.4e9
RATE     0 CS C=40 P=5
VISCO    0 E1=0.5e9 TAU=1e-5 XI=0.05
FAILURE  0 EPS_P=0.25 SIGMA_U=90e6

FIBER 0 3
0.00 0.0 0.0
0.01 0.0 0.0
0.02 0.0 0.0
CLAMP_BOX 0.0 -0.01 -0.01 0.0 0.01 0.01
```

Табличное упрочнение:

```text
MATERIAL 1 2.0e9 0.35 1.0e-4 1140.0 0.40
PLASTIC_TABLE 1 4
0.000  60e6
0.020  72e6
0.100  95e6
0.300 120e6
```

### Ошибки разбора

К каждому сообщению добавляется `fiber::load_fiber_file: <ДИРЕКТИВА>: ` в начале и `в строке <n>` в конце (кроме
проверок после чтения файла).

| Условие | Текст |
|---|---|
| неизвестный ключ | `неизвестный ключ '<КЛЮЧ>'` |
| токен без `=` | `ожидалось КЛЮЧ=значение, получено '…'` |
| значение не число или не конечное | `значение ключа <КЛЮЧ> не конечное число: '…'` |
| ключ повторён в строке | `ключ <КЛЮЧ> повторяется` |
| нет обязательного ключа | `не задан обязательный ключ <КЛЮЧ>` |
| значение вне диапазона | `<КЛЮЧ> должен быть > 0` / `>= 0` / `>= 1` / `в (0, 1]` |
| неизвестная модель `RATE` | `неизвестная модель '…' (допустимы CS, JC, PERZYNA)` |
| повтор директивы для `id` | `повторная директива для этого материала (первая в строке <n>)` |
| `PLASTIC` и `PLASTIC_TABLE` вместе | `PLASTIC и PLASTIC_TABLE для одного материала несовместимы` |
| `H` вместе с `K`/`N`; `K` без `N` | `линейное (H) и степенное (K, N) упрочнение несовместимы`; `степенное упрочнение требует оба ключа K и N` |
| таблица: `N < 2`; не хватает строк; битая строка | `число строк таблицы должно быть >= 2`; `неожиданный конец файла: ожидалось …`; `строка таблицы k из N: ожидалось 'eps_p sigma_s'` |
| таблица: первая `eps_p`, возрастание, убывание, `sigma_s` | `первая точка таблицы должна иметь eps_p = 0`; `eps_p должен строго возрастать`; `sigma_s не должен убывать`; `sigma_s должен быть > 0` |
| `ETA` и `XI` вместе | `ETA и XI одновременно задавать нельзя (выберите одно)` |
| `E1 > 0` без `TAU`; `TAU` без `E1` | `E1 > 0 требует TAU`; `TAU задан без E1 > 0` |
| `RATE` без пластики | `RATE (строка <n>) для материала <id> требует PLASTIC или PLASTIC_TABLE` |
| `id` не объявлен в `MATERIAL` | `директива неупругости (строка <n>) ссылается на неопределённый материал <id>` |

Неизвестное первое слово строки по-прежнему даёт `неизвестное ключевое слово '<слово>' в строке <n>`.

## Выходной файл нитей `fiber_output_NNNNN.txt`

Пишется функцией [`fiber_output`](../../../src/fiber_output.cpp) в те же шаги, что и кадр частиц
(`sph_output_NNNNN.txt`, см. [Выходные файлы](dat-output.md)).

```text
TIME <t> STEP <шаг> N_PARTICLES <n> N_BONDS <nb>
# id object_id material_id x y z vx vy vz
PARTICLES
<n строк>
# i j l0 l l_break elongation [eps_p sigma w_p w_v]
BONDS
<nb строк>
```

Колонки `BONDS` для упругих материалов:

| Колонка | Единицы | Описание |
|---|---|---|
| `i`, `j` | - | индексы бусин связи (0-based, как `id` в `PARTICLES`) |
| `l0`, `l` | м | исходная и текущая длина |
| `l_break` | м | длина, при которой связь рвётся по `eps_break` |
| `elongation` | - | $(l - l_0)/l_0$ |

Если у модели есть хотя бы один неупругий материал (включены `PLASTIC`/`PLASTIC_TABLE`, ветвь Максвелла или демпфер
Кельвина; одного `FAILURE` недостаточно), строки связей и строка-заголовок получают ещё четыре колонки **в конце**:

| Колонка | Единицы | Описание |
|---|---|---|
| `eps_p` | - | пластическая деформация связи |
| `sigma` | Па | напряжение связи, то же выражение, что в силовом ядре: $\max\bigl(E(\varepsilon-\varepsilon_p)+q+\eta\dot\varepsilon,\,0\bigr)$, сила в связи $F = A\sigma$, $A=\pi d^2/4$ |
| `w_p` | Дж | накопленная пластическая работа в связи |
| `w_v` | Дж | накопленная вязкая диссипация в связи (Максвелл и Кельвин) |

Напряжение считается по сохранённому состоянию связи и текущим положениям и скоростям бусин на момент вывода
($\dot\varepsilon = ((v_j - v_i)\cdot n)/l_0$). Силовое ядро берёт скорости предиктора, поэтому вязкий вклад в
`sigma` может отличаться от использованного в шаге на величину порядка $dt$. Для упругих связей смешанной модели
выводятся `eps_p = 0`, $\sigma = E\max(\varepsilon, 0)$, `w_p = w_v = 0`.

Эти четыре колонки печатаются с 17 значащими цифрами (малые `eps_p` и разности не теряются); прежние шесть колонок -- с
точностью потока по умолчанию (6 цифр), как раньше.

!!! note "Совместимость"
    Новые колонки стоят в конце и появляются только для моделей с неупругими материалами. Для упругих нитей формат
    остаётся прежним (6 колонок). Читатели, которые разбирают строки позиционно (`tools/paraview/sph2vtk.py`,
    `tools/clamp_animate.py`, скрипты анимации в `experiments/`), берут первые шесть полей и лишние колонки
    игнорируют. Читатель тестов `tests/e2e_fiber_frames.hpp` жёстко проверяет 6 полей и предназначен только для
    упругих нитей.
