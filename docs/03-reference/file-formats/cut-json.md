# Файл раскройки `.cut.json`

Файл `.cut.json` (формат `random_cut_v1`) описывает мозаичную ткань: раскройки Вороного, поворот и фазу каждого фрагмента, диапазоны нитей и бусин, стежки и диагностические контакты. Это сопровождающий файл к `.fib`; расчёту он не нужен, сцена его не читает.

Кто пишет (функция `write_random_cut_json` в [plain_weave_random_cut.hpp](../../../include/fiber/plain_weave_random_cut.hpp)):

- `plain_weave_gen --random-cut` — файл `<out>.cut.json` (например, `rc.fib.cut.json`);
- `guo2019_shot --random-cut` — файл `guo2019_fabric.cut.json` в каталоге выстрела.

Кто читает: [random_cut_plot.py](../../../tools/plain_weave/random_cut_plot.py) (графики раскройки, бусин и стежков). Модель мозаики — в [руководстве по генератору](../../02-how-to/02-plain-weave-generator.md#случайная-раскройка) и на странице [«Ткани»](../../04-explanation/models/07-fabrics.md).

Общие правила: текстовый JSON; числа с 17 значащими цифрами; длины в метрах, углы в радианах (кроме `rot_max_deg`, градусы); индексы бусин и нитей глобальные, с нуля, как в `.fib`; точка `[x, y]` — плоскость ткани.

## Поля верхнего уровня

| Поле | Тип | Единицы | Смысл |
|---|---|---|---|
| `format` | строка | — | всегда `"random_cut_v1"` |
| `size` | `[W, H]` | м | размеры прямоугольника ткани по x и y |
| `origin` | `[x, y]` | м | левый нижний угол прямоугольника: `(cx − W/2, cy − H/2)` |
| `seed` | целое | — | зерно генератора случайных чисел |
| `n_frag` | целое | — | число фрагментов на раскройку |
| `gap` | число | м | зазор между фрагментами (с подставленным умолчанием `d`) |
| `p` | число | м | шаг нитей |
| `d` | число | м | диаметр нити |
| `amp` | число | м | амплитуда волны A |
| `seg` | целое | — | число хорд на полуволну k |
| `profile` | строка | — | `"cos"` или `"arcs"` |
| `rot_max_deg` | число | град | максимальный поворот сетки фрагмента |
| `stitch_step` | число | м | шаг стежков вдоль шва (0 — стежков нет) |
| `rc` | число | м | радиус контакта для списка `contacts` |
| `layers` | целое | — | число слоёв L |
| `layers_per_cut` | целое | — | слоёв на раскройку k (с подставленным умолчанием L) |
| `ply_pitch` | число | м | шаг слоёв по z (умолчание генератора $2A+d+10^{-6}$ м; сцена Guo передаёт свой $\Delta_\mathrm{ply}$) |
| `n_beads` | целое | — | число бусин во всех слоях |
| `n_fibers` | целое | — | число нитей во всех слоях |
| `plies` | массив | — | слои, см. ниже |
| `cuts` | массив | — | раскройки, см. ниже |
| `ranges` | массив | — | диапазоны нитей и бусин по слою и фрагменту |
| `stitch_columns` | массив строк | — | имена столбцов строк `stitches` |
| `stitches` | массив массивов | — | стежки |
| `contacts` | массив пар | — | диагностика контактов |

## `plies[]`

По одному элементу на слой, слой 0 — верхний.

| Поле | Тип | Единицы | Смысл |
|---|---|---|---|
| `cut` | целое | — | номер раскройки слоя в `cuts`, `g = l / k` |
| `cz` | число | м | координата `c_z` слоя, `c_z − l·ply_pitch` |
| `bead_first` | целое | — | глобальный индекс первой бусины слоя |

## `cuts[]`

Элемент — одна раскройка: объект с полями `fragments` и `seams`.

### `fragments[]`

| Поле | Тип | Единицы | Смысл |
|---|---|---|---|
| `id` | целое | — | номер фрагмента внутри раскройки |
| `center` | `[x, y]` | м | центр ячейки после итерации Ллойда, начало решётки фрагмента |
| `theta` | число | рад | поворот сетки нитей |
| `phase` | `[fx, fy]` | доли `p` | сдвиг фазы сетки, в [0, 1) |
| `area` | число | м² | площадь рабочего многоугольника |
| `polygon` | массив `[x, y]` | м | рабочий многоугольник (биссектрисы сдвинуты на `gap/2`) |
| `cell` | массив `[x, y]` | м | ячейка Вороного без зазора |

### `seams[]`

| Поле | Тип | Единицы | Смысл |
|---|---|---|---|
| `i`, `j` | целые | — | номера фрагментов, `i < j` |
| `a`, `b` | `[x, y]` | м | концы отрезка шва (общая граница ячеек без зазора) |
| `length` | число | м | длина шва |
| `points` | массив `[x, y]` | м | точки стежков: середины `ns = max(1, floor(length/stitch_step))` равных частей |

## `ranges[]`

Диапазон нитей и бусин одного фрагмента в одном слое (глобальные индексы). Записи есть только для фрагментов, у
которых в слое остались нити (у фрагмента с пустым рабочим многоугольником `polygon` пуст и диапазона нет).

| Поле | Тип | Смысл |
|---|---|---|
| `ply` | целое | слой |
| `frag` | целое | фрагмент |
| `fiber_first`, `fiber_count` | целые | первая нить и число нитей |
| `bead_first`, `bead_count` | целые | первая бусина и число бусин |

## `stitch_columns` и `stitches`

`stitch_columns` всегда равен `["a", "b", "through", "ply_a", "ply_b", "frag_a", "frag_b", "cut", "seam"]`. Каждый элемент `stitches` — массив из девяти целых в этом порядке:

| Столбец | Смысл |
|---|---|
| `a`, `b` | глобальные индексы бусин (пара `BOND a b 1` в `.fib`) |
| `through` | 0 — стежок через шов в слое, 1 — сквозной между слоями |
| `ply_a`, `ply_b` | слои бусин; для сквозного `ply_b = ply_a + 1` |
| `frag_a`, `frag_b` | фрагменты бусин (внутри раскройки своего слоя) |
| `cut` | раскройка, которой принадлежит шов |
| `seam` | номер шва в `cuts[cut].seams` |

Порядок: сначала стежки в слоях, затем сквозные. Порядок совпадает с порядком `BOND` в `.fib`. При `stitch_step = 0` массив пуст.

## `contacts`

Массив пар `[a, b]` глобальных индексов бусин разных фрагментов одного слоя, трёхмерное расстояние между которыми меньше `rc`. Это диагностика; в `.fib` контакты не пишутся, их считает ядро.

## Пример структуры

```json
{
  "format": "random_cut_v1",
  "size": [0.05, 0.05], "origin": [-0.025, -0.025],
  "seed": 3, "n_frag": 9, "gap": 0.00039, "p": 0.00118, "d": 0.00039, "amp": 0.000195, "seg": 4,
  "profile": "cos", "rot_max_deg": 25, "stitch_step": 0.0024, "rc": 0.0009,
  "layers": 1, "layers_per_cut": 1, "ply_pitch": 0.0, "n_beads": 0, "n_fibers": 0,
  "plies": [{"cut": 0, "cz": 0.0, "bead_first": 0}],
  "cuts": [{"fragments": [{"id": 0, "center": [0, 0], "theta": 0.1, "phase": [0.3, 0.7], "area": 0.0,
                           "polygon": [[0, 0]], "cell": [[0, 0]]}],
            "seams": [{"i": 0, "j": 1, "a": [0, 0], "b": [0, 0], "length": 0.0, "points": [[0, 0]]}]}],
  "ranges": [{"ply": 0, "frag": 0, "fiber_first": 0, "fiber_count": 0, "bead_first": 0, "bead_count": 0}],
  "stitch_columns": ["a", "b", "through", "ply_a", "ply_b", "frag_a", "frag_b", "cut", "seam"],
  "stitches": [[0, 1, 0, 0, 0, 0, 1, 0, 0]],
  "contacts": [[0, 1]]
}
```

Значения в примере условные: показаны только имена и вложенность полей.
