# Реестр материалов

Соответствие индекса материала `itype` частицы физическим константам. Источник
данных — [`Materials`](../../../include/materials.hpp:136).

## Индексация

Индекс материала — поле `itype` частицы. Массивы металлов/полимеров индексируются
через смещение [`n_Me = 3`](../../../include/materials.hpp:136): для
`itype >= n_Me` индекс в массивах `G`, `sigy`, `aa`, `zz` равен `itype - n_Me`.
Набор констант JH-2 (`const_JH_2`) индексируется отдельно: `0` — B₄C, `1` — Al₂O₃.

JC-материалы (itype 12–15) хранятся в отдельном векторе `Materials::jc` (структура
`JcMaterial`, [`include/materials.hpp`](../../../include/materials.hpp), функция
`make_jc_library`); индекс = `itype − n_JC`, где `n_JC = 12`.

## Замечания по JH-2

- Строка `const_JH_2[1]` (Al₂O₃) **не проверена**: она, вероятно, смешана из двух наборов
  ($T=0{,}2$ ГПа и $T_n=0{,}137$ отвечают AD-995 при $P_{HEL}=1{,}46$ ГПа, остальное — из
  неустановленного набора; при $P_{HEL}=2{,}626$ ГПа было бы $T^*=0{,}076$). Источник не
  установлен, проверенных констант Al₂O₃ не будет (решение владельца): строку использовать
  только как неподтверждённую (`jh2/jh2-code-review.md`, п. 6.3). Строка B₄C — смешанный набор
  (врезка выше): упругие константы по Grady & Moody, прочностные прежние, поэтому HEL
  (σ_hel ≈ 17,3 ГПа по расчёту модели вместо 19 ГПа в J&H 1999) известен и без источника не меняется.
- `e_pl` — накопленная эквивалентная пластическая деформация (сумма приращений
  радиального возврата), повреждение растёт как $\Delta D = \Delta\varepsilon^{pl}/\varepsilon_f$.
  Давление разрыхления `dp` растёт только вместе с $D$ (потеря упругой энергии).
- Необязательные флаги в `Materials` (по умолчанию поведение оригинала J&H 1999):
  `jh2_clamp_low_rate` (`false`) — $\dot\varepsilon^* = \max(\dot\varepsilon/\dot\varepsilon_0, 1)$;
  `jh2_efmin` (`0`) — нижняя граница $\varepsilon_f$.
  Это только поля `Materials` в коде: ключа в `Initial_Conditions.txt` нет, при рестарте они
  не сверяются (проверяются `G`, `sigy`, `aa`, `zz`, `gamm`, `const_JH_2`).
- Исправление и его последствия — [ADR-010](../../04-explanation/decisions/adr-010-jh2-fix.md).

- Для всех материалов: ε̇0 = 1 с⁻¹, форма скорости «1st Order».
- STEEL 4340: p_min = −5,5 ГПа (нижний предел давления, аналог Autodyn Hydro Pmin) —
  откольная прочность 4340 RC30 по Bless 1981 (AFWAL-TR-81-4040, DTIC ADA112445).

Источники:

- A, B, n, C, m, T_m — Autodyn (скриншоты 27.10.2026); для 4340, 1006 и 7039 совпадают с
  Johnson & Cook 1983 (Proc. 7th Int. Symp. Ballistics).
- STEEL 4340 целиком, включая разрушение JC (D1–D5, T_m = 1793 К и ε̇0 = 1 с⁻¹ в разделе
  Failure) — библиотека Autodyn, скриншоты 15.11.2026
  ([`fiber/steel-4340-autodyn-constants.md`](../../../fiber/steel-4340-autodyn-constants.md));
  D1–D5 совпадают с Johnson & Cook 1985 (Eng. Fract. Mech. 21(1)).
- AL5083H116 — Grytten et al. 2006 (9th LS-DYNA Conf.), модифицированный критерий Børvik,
  скоростной множитель (1+ε̇*)^D4.

Не сверено (`TODO(verify)` в [`include/materials.hpp`](../../../include/materials.hpp)):

- T_r и c_p STEEL 1006 (JC 1983);
- Γ0, c0, S1 для STEEL 1006 и AL 7039 (Steinberg, литературные);
- плотность AL 7039 (JC 1983).
