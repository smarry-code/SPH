# Реестр материалов

Соответствие индекса материала `itype` частицы физическим константам. Источник
данных — [`Materials`](../../../include/materials.hpp:20).

## Индексация

Индекс материала — поле `itype` частицы. Массивы металлов/полимеров индексируются
через смещение [`n_Me = 3`](../../../include/materials.hpp:23): для
`itype >= n_Me` индекс в массивах `G`, `sigy`, `aa`, `zz` равен `itype - n_Me`.
Набор констант JH-2 (`const_JH_2`) индексируется отдельно: `0` — B₄C, `1` — Al₂O₃.
