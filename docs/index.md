# SPH — Документация

Добро пожаловать в документацию проекта **SPH** — вычислительного кода для
моделирования динамических процессов в сплошных средах методом сглаженных частиц
(*Smoothed Particle Hydrodynamics*, SPH).

Проект написан на **C++20** (компилятор Clang), использует **OpenMP** для
параллелизма и собирается через **CMake 3.21+**. Домен — вычислительная механика
сплошных сред: ударно-волновые процессы, высокоскоростное соударение, поведение
керамики (модель **JH-2**) и металлов (УРС Ми–Грюнайзена, УА Тэта, модель
прочности и разрушения **Джонсона–Кука**).

## Возможности

- **Сплошная среда (Solid).** SPH-частицы с прочностью по Мизесу, JH-2 для
  керамики и Джонсона–Кука для металлов (`itype` 12–15, нагрев по энергии или по
  Тейлору–Куинни); размерность 1, 2 или 3 выбирается при сборке (`SPH_DIM`),
  в 2D доступна осесимметричная постановка; XSPH в режимах `velocity` и `position`;
  искусственное напряжение Монагана (по умолчанию выключено).
- **Нити и ткани (Fiber).** Нити из бусин со связями и пластичностью, генератор
  полотняного переплетения, файл нитей `.fib`; пакеты слоёв kT, стёганое одеяло
  (патчи и стежки) и мозаичная ткань (случайная раскройка) —
  [глава «Ткани»](04-explanation/models/07-fabrics.md); только `SPH_DIM=3`.
- **Контакты.** Частица–частица (пинбол, Свигл, импульсный закон), нить–тело и
  нить–нить с трением; законы 1–3 нитей — также как проекция скорости с тёплым стартом;
  типы и параметры задаются ключами `Initial_Conditions.txt`.
- **Закрепления (Clamp).** Кинематическое закрепление частиц и бусин (`CLAMP_BOX`
  в `.fib`).
- **Ввод геометрии.** Импорт LS-DYNA `.k` (режимы `solid` и `solid_fiber`) с
  таблицей деталей.
- **Интегрирование.** Предиктор-корректор (рабочая схема) и явный Эйлер
  (ключ `ode_solver`); расчёт правых частей параллелен и детерминирован (вклады пишутся в буферы
  и сводятся reduce по шардам, без раскраски графа пар).
- **Чекпоинты и рестарт.** Бинарные снимки состояния и продолжение расчёта
  (`--checkpoint`, `--restart`).
- **Диагностика и вывод.** Лог механической энергии (`SPH_ENERGY_LOG`), статистика
  контактов нитей (`SPH_CONTACT_STATS`), конвертация кадров в VTK для ParaView.

## Структура документации

Документация построена по модели **Diátaxis** и разделена на четыре режима в
зависимости от цели читателя:

- **Обучение** (`01-tutorials/`) — пошаговые руководства «от нуля до результата».
- **Практика** (`02-how-to/`) — рецепты решения конкретных задач.
- **Справка** (`03-reference/`) — API, конфигурация, форматы файлов, материалы.
- **Теория и Архитектура** (`04-explanation/`) — физические модели, обоснование
  алгоритмов, записи архитектурных решений (ADR).

## Технологический стек документации

Проект использует подход **Docs-as-Code**: документация живёт в репозитории
рядом с кодом, проходит тот же процесс ревью и контроля версий. Технологический
стек — **минимальный вариант (B)** из архитектурного плана:

- **MkDocs Material** — статический генератор сайта документации.
- **Doxygen** — автогенерация API-документации из C++ кода (отдельный HTML-сайт).
- **KaTeX** — рендеринг математических формул.
- **Mermaid** — диаграммы архитектуры.

Связь между MkDocs и Doxygen осуществляется ссылкой на отдельный Doxygen-сайт.
