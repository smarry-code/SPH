# SPH — Документация

Добро пожаловать в документацию проекта **SPH** — вычислительного кода для
моделирования динамических процессов в сплошных средах методом сглаженных частиц
(*Smoothed Particle Hydrodynamics*, SPH).

Проект написан на **C++20** (компилятор Clang), использует **OpenMP** для
параллелизма и собирается через **CMake 3.16+**. Домен — вычислительная механика
сплошных сред: ударно-волновые процессы, высокоскоростное соударение, поведение
керамики (модель **JH-2**) и металлов (УРС Ми–Грюнайзена, УА Тэта).

## Структура документации

Документация построена по модели **Diátaxis** и разделена на четыре режима в
зависимости от цели читателя:

- **Обучение** (`01-tutorials/`) — пошаговые руководства «от нуля до результата».
- **Практика** (`02-how-to/`) — рецепты решения конкретных задач.
- **Справка** (`03-reference/`) — API, конфигурация, форматы файлов, материалы.
- **Теория и Архитектура** (`04-explanation/`) — физические модели, обоснование
  алгоритмов, записи архитектурных решений (ADR).

## Технологический стек документации

Проект использует подход **Docs-as-Code**: документация живёт в репозитории
рядом с кодом, проходит тот же процесс ревью и контроля версий. Технологический
стек — **минимальный вариант (B)** из архитектурного плана:

- **MkDocs Material** — статический генератор сайта документации.
- **Doxygen** — автогенерация API-документации из C++ кода (отдельный HTML-сайт).
- **KaTeX** — рендеринг математических формул.
- **Mermaid** — диаграммы архитектуры.

Связь между MkDocs и Doxygen осуществляется ссылкой на отдельный Doxygen-сайт.
