# Запуск тестов и бенчмарков

В проекте настроены тесты через CTest (см. [`CMakeLists.txt`](../../../CMakeLists.txt:38)).

## Запуск всех тестов

```bash
ctest --test-dir build --output-on-failure
```

## Состав тестов

| Тест | Исполняемый файл | Что проверяет |
|---|---|---|
| `flat_grid_test` | `test_flat_grid` | Сеточный поиск соседей |
| `pair_graph_test` | `test_pair_graph` | Графовую раскраску пар (с OpenMP) |
| `particle_system_test` | `test_particle_system` | Тождество моста AoS↔SoA (точность 1e-12) |
| `contact_test` | `test_contact` | Контактные силы «частица-частица» (ADR-007): аналитика типов 1-3, баланс импульса, ограничитель шага |
| `e2e_bc1_smoke_test` | `test_e2e_bc1` | Сквозной прогон кейса BC1 на огрублённой сетке: геометрия, живучесть конвейера, сверка с эталоном |
| `e2e_bc1_full_test` | `test_e2e_bc1 --full` | Тот же кейс на рабочей сетке. Метка `slow`, по умолчанию **не регистрируется** |

!!! note "Где лежат исходники тестов"
    Юнит-тесты — в корне репозитория (`test_*.cpp`), сквозной тест — в
    [`tests/`](../../../tests/), его эталонные данные — в
    [`tests/data/`](../../../tests/data/). Путь к данным передаётся в тест
    макросом `SPH_TEST_DATA_DIR` из CMake и не зависит от рабочего каталога.

### Полный прогон BC1

Регистрируется только при явном включении, потому что считает минуты:

```bash
cmake -S . -B build -DSPH_E2E_SLOW_TESTS=ON
cmake --build build -j8
ctest --test-dir build -L slow --output-on-failure
```

Тест ограничен по времени: `--time-limit=СЕК` (по умолчанию 600). При исчерпании
бюджета расчёт обрывается и сообщает, что именно произошло — не хватило времени
при здоровом шаге или расчёт перестал продвигаться (коллапс шага).

## Бенчмарк

`bench_color` сравнивает последовательный (atomic) и параллельный (coloring)
пути обхода пар. Собирается отдельно и запускается вручную:

```bash
cmake --build build --target bench_color
./build/bench_color
```
