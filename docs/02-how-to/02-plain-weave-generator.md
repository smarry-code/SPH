# Генератор полотняного переплетения

Генератор `plain_weave_gen` создаёт ткань полотняного переплетения в формате файла нитей (`.fib`), который загружается в симулятор как отдельная геометрия.

## Сборка

```bash
cmake --build <build> --target plain_weave_gen
```

Например:

```bash
cmake --build build --target plain_weave_gen
```

## Основные концепции

Генератор строит ткань в плоскости x–y с толщиной по оси z. **Основа** (warp) идёт вдоль оси x, **уток** (weft) вдоль оси y. В каждом пересечении нити контактируют волнистостью — основа и уток чередуют верхнее и нижнее положение.

Сгенерированный файл содержит:
- **`.fib`** — координаты нитей (бусин и связи между ними)
- **`.layout.txt`** — раскладка: метаданные о каждой нити

## Таблица параметров CLI

Все значения в СИ (метры, паскали, килограммы на кубический метр). Без пресета действуют значения пресета `test`. Пресет применяется первым, явный параметр его переопределяет независимо от порядка ключей; `--overhang-x` и `--overhang-y` переопределяют `--overhang=`.

| Ключ | Тип | Умолчание | Смысл |
|---|---|---|---|
| `--out=<файл.fib>` | обязателен | — | Выходной файл нитей |
| `--layout=<файл>` | строка | `<out>.layout.txt` | Раскладка |
| `--preset=<имя>` | строка | — | Пресет: `test`, `circle_draw`, `twaron_ct717` |
| `--d=<м>` | число | 0.5e-3 | Диаметр нити |
| `--pitch=<м>` | число | 1e-3 | Шаг между осями нитей (полуволна) |
| `--amp=<м>` | число | 0.25e-3 | Амплитуда волнистости по z |
| `--nx=<n>` | целое | 4 | Число нитей основы (вдоль x) |
| `--ny=<n>` | целое | 4 | Число нитей утка (вдоль y) |
| `--seg=<k>` | целое | 4 | Число сегментов (связей) на полуволну, ≥ 2 |
| `--overhang=<м>` | число | p/2 | Выступ за крайнюю поперечную нить (оба направления) |
| `--overhang-x=<м>` | число | p/2 | Выступ основы (сильнее `--overhang=`) |
| `--overhang-y=<м>` | число | p/2 | Выступ утка (сильнее `--overhang=`) |
| `--profile=cos\|arcs` | строка | `cos` | Профиль нити (косинус или дуги) |
| `--center=cx,cy,cz` | число | 0,0,0 | Центр полотна |
| `--clamp=none\|x\|y\|xy` | строка | `none` | Какие нити зажимаются |
| `--clamp-edge=<м>` | число | — | Граница зажима c_e (обязателен при `--clamp ≠ none`) |
| `--E=<Па>` | число | 5e7 | Модуль Юнга |
| `--nu=<>` | число | 0.3 | Коэффициент Пуассона |
| `--rho=<кг/м³>` | число | 1200 | Плотность материала |
| `--eps-break=<>` | число | 0.15 | Деформация разрыва связи |
| `--mu-ff=<>` | число | 0 | Коэффициент трения нить–нить |
| `--mu-fs=<>` | число | 0 | Коэффициент трения нить–Solid |
| `--allow-penetration` | флаг | — | Превратить ошибки `p < d` и `2A < d` в предупреждения |
| `--help` | флаг | — | Справка |

## Дискретизация

Бусины ставятся точно в каждое пересечение, между пересечениями — равные хорды:

- **На полуволне:** ровно **k** сегментов (связей) одинаковой длины, бусины стоят в вершинах (пересечениях).
- **Выступ:** делится на `max(1, round(e/(p/k)))` сегментов, отдельно по направлениям.
- Длины связей l₀ в пределах полуволны (и выступа) совпадают до ~10⁻¹⁵ относительно. Это равные хорды, а не равные дуги: в модели связь — хорда.

## Зажим (CLAMP_BOX)

Параметр `--clamp` задаёт, какие нити закреплены с обоих концов:

- `--clamp=x` — нити вдоль x (горизонтальные)
- `--clamp=y` — нити вдоль y (вертикальные)
- `--clamp=xy` — обе группы
- `--clamp=none` — нет зажима (по умолчанию)

При `--clamp ≠ none` **обязателен** параметр `--clamp-edge=<м>` (граница зажима c_e). Генератор пишет две директивы `CLAMP_BOX` в `.fib`, по одной на каждый конец, с полным охватом по осям (допуск d).

Допустимый диапазон c_e:
- Нижняя граница: `c_e ≥ (n_поперечных - 1) / 2 · p + d/2` (не попасть в пересечения)
- Верхняя граница: `c_e ≤ (n_поперечных - 1) / 2 · p + e` (хотя бы одна зажатая бусина на конце)

Если бусина попадает в зажим близко к границе c_e (в пределах 10⁻⁹·p), печатается предупреждение.

## Формат раскладки

Файл `<out>.layout.txt` содержит одну строку на нить:

```
object_id direction index offset clamped first_bead last_bead n_clamp_lo n_clamp_hi
```

- `object_id` — номер нити (0..nx-1 основа, nx..nx+ny-1 уток)
- `direction` — `x` (основа) или `y` (уток)
- `index` — индекс в направлении (0..nx-1 или 0..ny-1)
- `offset` — координата, перпендикулярная направлению (м)
- `clamped` — 1 если нить зажата, иначе 0
- `first_bead`, `last_bead` — глобальные индексы первой и последней бусин в файле `.fib`
- `n_clamp_lo`, `n_clamp_hi` — число зажатых бусин у начала и конца нити

## Известные ограничения

1. **Толщина полотна:** круглое сечение даёт толщину ≈2A + d, не реальную. Для пресета `twaron_ct717` это ≈0,78 мм против 0,4 мм в статье.

2. **Контакт в узлах при касании:** при 2A = d оси нитей в модели — хорды соседних бусин, а не гладкие кривые, и у узла хорды сближаются меньше чем на d. На исходной геометрии уже есть контакты: на геометрии Twaron 4 контакта (пары сегментов) на пересечение, проникание ≈9,6% d при k=2 и ≈3,8% d при k=4. При A = 0,6·d контактов на исходной геометрии нет (проверки 7/7б в `tests/test_plain_weave.cpp`).

3. **Плотность twaron_ct717:** 0,327 кг/м² против номинала 0,292 (статья: 0,28). Превышение складывается из удлинения нити волнистостью (хорды полуволны на ≈6% длиннее p) и выступов утка по 5 мм (+0,015 кг/м², ≈5%).

## Примеры

### Генерация тестовой ткани (быстро)

```bash
./build/plain_weave_gen --preset=test --out=test.fib
```

Результат:
- 8 нитей (4×4)
- 136 бусин
- Время: несколько мс

### Генерация ткани Twaron с зажимом

```bash
./build/plain_weave_gen --preset=twaron_ct717 --out=twaron.fib
```

Результат:
- 204 нити (102×102)
- 86496 бусин, 3264 из них зажаты
- Толщина полотна: 0,78 мм
- Поверхностная плотность: 0,327 кг/м²
- Время: ≈0,1 с

### Свободная ткань с собственными параметрами

```bash
./build/plain_weave_gen --d=0.3e-3 --pitch=1.5e-3 --amp=0.15e-3 \
                        --nx=50 --ny=50 --seg=4 \
                        --out=custom.fib
```

Генератор выведет в `stdout` сводку: число нитей, бусин, связей, min/max l₀, толщину и поверхностную плотность.
