# Данные для тестов модели Джонсона-Кука

## `taylor_4340_autodyn.txt` — эталон теста Тейлора (E4)

Файл создаёт и кладёт сюда владелец (результат расчёта в Autodyn, SPH или
Lagrange, STEEL 4340, та же постановка: Ø 7.62 мм, L0 = 25.4 мм, 200 м/с в
жёсткую стенку). В репозитории его пока нет. Пока файла нет, тест
`test_e2e_jc_taylor` печатает «нет эталона Autodyn» и проверяет только
качественные ворота; когда файл появится, добавляются ворота 5 % по `L_final`
и `R_max`.

### Формат

Текст UTF-8, одна пара `ключ=значение` на строку. Всё после `#` — комментарий,
пустые строки и строки без `=` игнорируются. Числа в обычной записи
(`0.0231`, `2.31e-2`). **Единицы СИ: метры, без процентов.**

| Ключ | Что | Единицы | Ворота |
|---|---|---|---|
| `L_final` | конечная длина стержня по оси (полный стержень, не пара половин) | м | 5 % |
| `R_max` | максимальный радиус на ударном торце | м | 5 % |
| `e_pl_axis` | эффективная пластическая деформация на оси у торца | — | только печать |

Лишние ключи тест игнорирует; отсутствующий ключ даёт предупреждение и
пропуск соответствующей сверки.

### Пример

```
# Autodyn 2D axisymmetric, SPH, STEEL 4340, 0.1 мм
L_final=0.02300
R_max=0.00460
e_pl_axis=0.45
```

### Как SPH-тест определяет те же величины

Тест считает половину z > 0 симметричной пары стержней (середина — гладкая
жёсткая стенка), поэтому:

* `L_final` — длина половины по осевому столбцу частиц (две ближайшие к оси
  колонки): `z_тыл − z_торец + dx`, в момент, когда кинетическая энергия
  половины упала ниже 1 % начальной;
* `R_max` — максимум по времени величины «наибольший r частиц в приторцевом
  слое (z до z_торца + 1.01·dx) + dx/2»;
* `e_pl_axis` — `e_pl` осевой частицы первого слоя (центр на dx/2 от стенки в
  начальный момент); значение зависит от разрешения, поэтому ворот нет.

Те же ключи тест пишет в свою сводку `jc_taylor_<тег>_summary.txt` (формат
совпадает с форматом эталона), так что результат SPH можно сравнить с
Autodyn глазами или подставить как новый эталон.
